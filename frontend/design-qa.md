## 全视图与重点区域对照

- 通知页全视图：标题、说明、连接状态、刷新操作、通知行高、分隔节奏、类型标签、时间和关联内容入口均保持设计源结构。主导航把“通知与订阅”拆为“通知”“订阅”，属于本次明确要求；设计源中的装饰性 `Intelligence` 标签在当前实现中未保留，属于不影响任务完成的 P3 差异。
- 订阅页重点区域：原有 `Delivery`、报告订阅说明、新建订阅按钮、发送图标、空态标题与说明全部保留；区域从长通知列表底部提升为独立页面首屏，并使用页面级一级标题。
- 对话框重点区域：报告周期、交付方式、邮箱、监控 ID、发送时间、时区和取消/创建操作均能打开并保持原有视觉与焦点行为。

## 五类视觉表面

- 字体与层级：继续使用项目现有 Geist / 中文系统无衬线回退；通知页层级无漂移，订阅页标题从混合页二级标题升级为独立页面一级标题。
- 间距与布局：复用 `app-page` 与 `PageHeader`；桌面操作位于标题右侧，390px 下新建订阅按钮扩展为整行，空态保持居中且无横向溢出。
- 颜色与令牌：继续使用现有中性背景、前景、弱化文字和主按钮令牌，没有新增颜色体系、边框风格或阴影。
- 图像与资产：没有新增位图或自绘资产；品牌标识、通知、RSS、发送、刷新及外链图标均来自项目现有资产与 lucide-react。
- 文案与内容：通知与订阅文案保持不变；导航名称按信息架构改为“通知”“订阅”，没有丢失原有提示或业务状态。

## 响应式、交互与可访问性

- 1440px/1686px 桌面导航同时展示“通知”“订阅”，当前页面下划线只命中一个入口。
- 390 × 844 订阅页首屏可见标题、说明、新建订阅和空态；移动抽屉包含两个独立入口并正确标记“订阅”为当前页。
- 通知页不再挂载报告订阅；订阅页不再挂载通知列表。打开通知页仍会标记当前通知已读。
- “新建订阅”对话框可以打开和取消；标题为语义化 `h1`，区域与导航均有可读名称。
- 最终页面控制台无 `error` 或 `warn` 日志。

## React 质量检查

- 两个路由页保持无状态 Server Component，只组合对应业务组件，没有新增客户端边界或序列化负担。
- `ReportSubscriptions` 继续复用原数据加载、分页和变更逻辑；页面拆分没有引入请求瀑布、重复订阅、派生状态 Effect 或内联组件。
- 直接复用既有 `PageHeader`、图标和 UI 组件；未发现需要为性能或可访问性追加修改的问题。
