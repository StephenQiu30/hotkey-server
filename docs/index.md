## 维护方式

Obsidian直接打开`ripplesight-server/docs/`，通过[文档视图](views/文档.base)按目录和编号浏览。新增需求接续当前最大编号，同时维护同编号、同名称的design和plan；增删或更名同步修正三目录与引用。prd独立编号，从00开始。

项目文档仅用Markdown/Git，不维护统一正文或历史归档副本。可使用templates可选模板，不强制frontmatter；共享.obsidian配置保留，个人布局、缓存和凭据留本机。业务报告Obsidian导出独立于项目文档。

仓库根目录BACKLOG（进度）、PROJECT（技术架构）、AGENTS（工程规范）不在vault内复制。

## 检查

在frontend/执行`pnpm docs:check`检查链接和锚点；工具回归为`pnpm test tests/docs/documents.test.ts`。同时核对三目录文件名集合和H1一致、编号从00连续。当前只整理文档，不运行文档站或发布流程。
