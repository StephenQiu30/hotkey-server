# 部署、升级与回滚

## 适用边界

MVP 使用根目录 `docker-compose.yml` 或 `docker-compose-prod.yml` 部署 PostgreSQL、Redis、MinIO、Go 服务与 Next.js Web。生产发布必须使用已评审的 Git 提交；当前 Schema 采用完整性校验，不允许未设计的数据定义变更在原库就地执行。

## 发布前门禁

```bash
git status --short
git rev-parse --verify '<已评审提交>'

cd backend
make ci
cd ../frontend
npm ci
npm run openapi:check
npm run typecheck
npm run test:unit
npm audit --omit=dev --audit-level=high
npm run build
cd ..

docker compose -f docker-compose.yml config --quiet
docker compose --env-file .env.prod -f docker-compose-prod.yml config --quiet
```

只有工作树范围明确、两端质量门禁通过、`.env.prod` 六个必填值均为非默认安全值且 [最近一次备份恢复演练](002-备份恢复与密钥轮换.md)通过时才发布。命令不得打印 `.env.prod`。

## 生产升级

1. 在变更单记录旧提交、目标提交、镜像 ID、操作人、开始时间与回滚窗口。
2. 先执行备份手册；若本次改变任务生产者，先在治理界面停用相关来源，等待正在运行的任务结束。
3. 检出已评审提交并重新运行 Compose 配置检查。
4. 构建镜像，再以健康等待模式更新服务：

```bash
git switch --detach '<已评审提交>'
docker compose --env-file .env.prod -f docker-compose-prod.yml build
docker compose --env-file .env.prod -f docker-compose-prod.yml up --detach --wait --wait-timeout 240
docker compose --env-file .env.prod -f docker-compose-prod.yml ps
```

5. 从受信任管理网络验证：

```bash
curl --fail --silent https://<API域名>/healthz
curl --fail --silent https://<API域名>/readyz
curl --fail --silent https://<API域名>/metrics | grep 'hotkey_runtime_metrics_collection_success'
curl --fail --silent https://<Web域名>/
```

6. 使用 Admin 账户验证登录、来源列表、治理运行状态、监控、事件、告警和报告各一次；确认队列滞后回落后再恢复来源。

## 回滚

满足任一条件立即回滚：readiness 持续失败、登录或主要读路径不可用、任务失败率持续超过阈值、发现凭据/内容泄露，或新版本无法在回滚窗口内恢复。

1. 记录故障时间与请求 ID；停用相关来源，避免继续生产新任务。不要删除事实、任务、审计或卷。
2. 确认旧提交仍可验证，并确认变更未包含不兼容 Schema；若不兼容，转入独立环境恢复，不得强行覆盖生产库。
3. 检出旧提交并重建、启动：

```bash
git switch --detach '<上一个已验收提交>'
docker compose --env-file .env.prod -f docker-compose-prod.yml build
docker compose --env-file .env.prod -f docker-compose-prod.yml up --detach --wait --wait-timeout 240
```

4. 重复 health/readiness、主路径和指标验证。确认旧版本稳定后再逐个启用来源。

回滚不运行 `down --volumes`、不删除对象存储、不清空队列。若旧版本无法读取新事实，按恢复手册在新项目中恢复发布前备份并进行切流评审。

## 发布记录最小字段

- 变更单、Git 提交、镜像 ID与 Compose 文件哈希
- 备份位置和恢复演练结果
- health/readiness、浏览器主路径、队列滞后与失败率结果
- 操作人、复核人、发布时间、回滚时间和结论
