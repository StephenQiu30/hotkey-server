# 自动决策质量、模型成本与来源权利

## 适用边界

本手册冻结 032 自动决策上线的三道独立门禁：时间隔离质量评测、AI 模型成本/降级、来源权利决策。任一道门禁缺失时都必须 fail closed：保持 `review`、`metadata_only` 或显式 degraded，不得伪造语义分、正文、事件合并或热点告警。

这些门禁只判断“系统是否可自动执行某个算法决策”，不判断报道真假、来源可信度或事件是否已被证实。

## 时间隔离质量门禁

版本化 fixture 位于 `backend/test/fixtures/quality/time-isolated/acceptance-dataset.json`，标注规范位于同目录 `annotation-guide.md`。当前 `decision-quality-time-isolated-v1` 使用 `2026-01-01T00:00:00Z` 作为时间边界，包含 1,860 条不含正文的标注样本，双人复核，Cohen's kappa 为 0.98。

| 模块 | profile | 样本 | 激活门槛 | 2026-08-10 结果 |
| --- | --- | ---: | --- | --- |
| 内容家族 | `content-family-conservative-v1` | 400（200/200） | Precision ≥ 99.5%，Recall ≥ 90%，Wilson 下界 ≥ 96.5%，错误合并率 < 0.5% | Precision/Recall 100%，Wilson 98.12%，通过 |
| 微事件聚类 | `same-event-cold-start-v1` | 400（200/200） | Pairwise Precision ≥ 95%，Wilson 下界 ≥ 92%，B-Cubed F1 ≥ 90% | 均为 100%，Wilson 98.12%，通过 |
| 引用定位 | `w3c-text-quote-position-nfc-utf8-v1` | 240 | 定位准确率/出处完整率均为 100% | 100% / 100%，通过 |
| 证据关系 | `claim-evidence-relation-v1` | 420（7 类各50） | 每类 ≥ 50，Macro F1 ≥ 90% | Macro F1 100%，通过 |
| 热点发现 | `event-heat-v2` | 400（200/200） | Precision ≥ 80%，Wilson 下界 ≥ 77%，中位发现延迟 < 300s | Precision 100%，Wilson 98.12%，中位 120s，通过 |

执行命令：

```bash
cd backend
go run ./cmd/hotkey quality evaluate \
  --dataset test/fixtures/quality/time-isolated/acceptance-dataset.json

# 只有全部指标与必需切片通过时才允许持久化并激活。
go run ./cmd/hotkey quality evaluate \
  --dataset test/fixtures/quality/time-isolated/acceptance-dataset.json \
  --actor-user-id '<active_admin_user_id>' --activate
```

评测 run、slice 与 profile 都是 append-only 事实；激活需要持久化 active admin。ContentFamily、MicroEvent、证据关系和热点告警的生产组装都在自动执行前读取 exact active profile。数据集不足、必需切片未达标、profile 不存在、读取失败或版本不匹配均禁止自动决策。

## 模型、成本与降级

- Embedding 维度固定为 1024。本地默认能力是 Ollama `qwen3-embedding:0.6b`；也可使用带 SHA-256 manifest 和 tokenizer 上限的本地 ONNX profile。
- 外部生成/向量 provider 必须由持久化 `ai_model_profiles` 显式启用；运行时不从环境临时猜测 profile。`max_cost`、可选 `daily_budget`、预留、结算和超额阻断由 PostgreSQL budget ledger 在同一事务中约束。
- 发送正文/摘录到外部模型还必须有 exact `send_external_model=allow` RightsDecision；只有 `embed_local=allow` 不能扩大为外发授权。
- provider 未配置、超时、费用耗尽、输出 Schema 失败、维度不符或 Rights 撤回时，必须返回稳定 reason code，语义召回通道为 unavailable/degraded，继续仅使用已授权词法/结构信号，决策保持 `review`。
- Prompt、正文、raw bytes、Token 或凭据不得进入日志、队列载荷、指标标签或验收记录。

## 七类 Connector 权利门禁

每个 SourceConnection 都必须为 `fetch`、`store_raw`、`store_derived`、`display_private`、`redistribute`、`quote`、`embed_local`、`send_external_model`和 `retain` 分别保存单动作 Decision。无决策、同级冲突、过期或输入摘要不匹配一律视为 deny，只有读取投影可以聚合 matrix。

2026-08-10 验收环境的安全基线如下：

| Connector | 状态 | 动作基线 |
| --- | --- | --- |
| RSS/Atom/RDF | 启用 | 允许 fetch/raw/derived/private display/quote/local embed/retain；拒绝 redistribute/external model |
| Hacker News | 停用 | 九个动作全部 deny，批准后才能逐项放行 |
| X | 停用 | 九个动作全部 deny |
| Bing Grounding | 停用 | 九个动作全部 deny |
| Bilibili | 停用 | 九个动作全部 deny |
| Weibo | 停用 | 九个动作全部 deny |
| Google Agent Search | 停用 | 九个动作全部 deny |

七类 Connector 都已能把官方/授权 API 响应建模为带 collector profile 的 raw EvidenceSnapshot 和 locator，且只保存上游显式给出的 publisher/content-origin/distributor assertion。它们不得绕过付费墙、登录、验证码或平台限制；停用/未批准时不调用 Connector，不归档正文。搜索摘要始终是 `summary_only`/`metadata_only`，不会被展示为发布站全文。

## 变更与回滚

1. 新模型/profile 先以 disabled/shadow 建立，完成时间隔离评测后再由 active admin 激活。
2. 新来源先保存九个单动作 Decision，默认全 deny；审批只改变 exact scope/action，不修改历史决策。
3. 指标回归、预算异常、provider 故障或权利撤回时，停止新的自动执行，保留不可变历史，切回上一个已审计 active profile/Decision。
4. 回滚不删除 evaluation run、AI run、RightsDecision、EvidenceSnapshot 或已产生的 DocumentVersion；按各自 retention 与 tombstone 契约处理。
