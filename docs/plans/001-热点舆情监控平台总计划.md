# 热点舆情监控平台总计划

日期：2026-09-25。本计划是 v2.0 唯一的执行计划，取代原 001—047 逐项 Plan（原文见 Git 提交 `3a72611a`）。目标是第 2 周末收到第一份真实日报，第 6 周末交付日报、周报和知识库。工期按 1 名全职工程师加 AI 辅助粗估，每阶段结束时按实际进度重排。

## 1. 工作方式

- **进度标准**：每周至少一次用真实数据演示；文档数量不作为进度。
- **功能说明**：每个任务开工前在本文对应任务下补一段说明（做什么、改哪些文件、怎么验收），不再单独建 Research/PRD/Design/Plan/Acceptance。架构或数据库变化才更新 Design 001。
- **测试**：保留现有门禁：Ruff、mypy、pytest、OpenAPI 漂移、前端 lint/build，以及真实 PostgreSQL/Kafka 集成测试。新增代码按"失败测试 → 实现"推进，但不再为单个任务设 G0—G6 检查点。
- **验收记录**：阶段验收通过后，在 `docs/acceptance/` 写一份简短记录（场景、结果、证据链接）。
- **状态文件**：BACKLOG.md 只放阶段和任务状态，HANDOVER.md 只放当前快照，各 ≤ 5 KB。
