## 1. 目标、角色和差距

通过 OpenRouter、Vercel 支持的联网检索组合发现有引用的线索，按成本与覆盖边界补充热点研究。

责任角色：来源接入＋后端＋前端＋质量验证；归属 P1 / M6，开工时登记人员与实际日期。官方文档确认搜索工具，但尚无满足全部条件的真实组合和运行证据。 只交付本项范围，不以此关闭原生平台搜索/评论/作者追踪验收。

## 4. 实施规格

| ID | 规格 |
|---|---|
| SPEC-045-API-001 | GET /api/model-search-capabilities；POST /api/model-search-runs 受理 202，GET 进度/结果及 POST cancel；范围/组合校验、幂等、分页与脱敏错误经唯一契约生成。 |
| SPEC-045-DATA-001 | 不可变检索/模型配置关联；run/attempt/tool step、引用 hit、原文和 synthesis 分离；实际模型/引擎/费用未知明确，不造原生 ID 或发布时间。 |
| SPEC-045-JOB-001 | 推理＋工具整体准入，原子预留请求/搜索次数；供应商硬上限必须实测；固定引擎及活动截止；结果未知不自动重发，取消保留消耗。 |
| SPEC-045-UI-001 | 联网检索补充入口；组合/费用/外发预览、任务状态、引用/摘录/原文/归纳分层；费用条件不足显示不可用，不要求充值。 |
| SPEC-045-SEC-001 | 复用 043 凭据与当前权限；只允许明确只读工具，引用 URL 再校验；查询和上下文最小外发，模型不能扩展工具、登录或发帖。 |
| SPEC-045-OBS-001 | 真实搜索调用、模型/API/引擎、每步次数/费用/部分原因可查；无搜索证据不显示联网成功；日志不含秘密或原始查询。 |
| SPEC-045-OPS-001 | 受控验证后仅对满足零付费条件的实际组合启用；到期自动停用且无收费回退；无可用组合维持显式禁用与免费直接源路径。 |

顺序：字段/状态/权限冻结 → 必要迁移 → 领域服务/Worker → FastAPI/Pydantic → OpenAPI/生成客户端 → 页面 → 环境/浏览器及真实来源证据。无变更层说明 N/A，不增加旁路。
