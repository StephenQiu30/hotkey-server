# 全局异常与响应契约前置计划

日期：2026-09-21。状态 completed，S00—S03 及 AC-046-001—008 已按 [046 Acceptance](../acceptance/046-全局异常与响应契约验收.md) 通过。依据 [046 Design](../design/046-全局异常与响应契约设计.md) 与 [PROJECT](../../PROJECT.md)。这是全部实现计划的技术前置，不新增第 44 项产品需求，也不改变 34 项 P0 分母。

## 1. 目标、开始条件与责任

修复已有请求标识丢失、5xx detail 外泄、校验 schema 漂移和 Web details 解析问题，建立统一响应家族、错误注册、传输分类和持续契约检查。建议主责后端，Web/验证参与；真实执行人和提交版本在开工记录，不编造负责人或工期。

G0 要求完成 046 Design、PROJECT、AGENTS 的一致性复核；G1 使用已有应用骨架和锁文件，隔离环境不接触旧 PostgreSQL 数据；G2 核实本计划文件、协议矩阵与验证入口。无需先完成 042 S01、001 全部来源准入、031 持久任务或 Flutter 初始化。未完成 G0—G2 不进入本计划代码修改；其他计划只可做设计准备，直到本计划 S03 通过。已有 042 in_progress 保留历史状态，不授权继续实现。

| AC-046-001 | 200/404/422/应用异常/未知异常均有合法非 unknown UUID；错误 body/header 与访问日志相同，并发不串号 | 真实 ASGI 应用和捕获日志 |

## 5. 验证、停止与回退

后端执行既有 `uv run ruff format --check .`、`uv run ruff check .`、`uv run mypy`、`uv run pytest`；前端执行 `pnpm openapi:generate`（连接同提交运行 API）、`pnpm lint`、`pnpm typecheck`、`pnpm format:check`、`pnpm build`，以及 S00/S02 建立并登记的契约测试命令。生成后再生成一次检查无漂移，负向检查在隔离副本进行，不污染工作树。运行 API 不连接旧库；ready 使用隔离依赖或明确受控失败，不能据此宣称真实数据库就绪。

发现泄露、契约与客户端不一致、代理吞头或文件异常时，停止放行下游。回退后端契约、客户端及代理为同一验证版本；本计划不变更数据库，无数据迁移。失败证据保留，相关检查取消通过状态，046 S03 门禁重新关闭。版本提交及推送按当前会话授权和仓库规则执行。

完成定义：八项 AC 全部有证据，CI 契约检查可阻断回退，真实 Acceptance 与交接已建立。当前仅有设计和编排，代码缺陷仍待修复；不得将本计划写为 completed。
