| SPEC-005-DATA-001 | 保存实际查询、通道、排序意图、采样范围、分页停止原因和作品发现关系；同帖跨通道不重复实体。 |

| SPEC-005-UI-001 | 在 frontend/src/app/features/discovery/ 实现本项已有 PRD 流程；桌面与窄屏同时覆盖正常、空、加载、部分、错误和无权限状态，调用生成客户端，不复制服务端业务规则。 |
| SPEC-005-SEC-001 | 先检查当前身份及资源权限；配置版本不能绕过撤权、删除、停用和更严格预算。秘密不可回读，正文与外部输入只作数据。关键变更留操作者、对象、时间与版本。 |
| SPEC-005-OBS-001 | 输出来源与通道分项计数和缺口；错误库版本可按 038 停用回退，不删除已保存发现依据。 |
| SPEC-005-OPS-001 | 在隔离依赖验证后渐进启用本能力；保持历史资料可读。配置缺失或外部条件不满足时明确拒绝/延期。变更前评估数据兼容与回退，停止新增操作优先于破坏性迁移。 |

数据/接口/前端执行顺序：先冻结字段、状态与权限 → 如需则新增向后兼容迁移 → 领域服务和 Worker → FastAPI/Pydantic 运行契约 → 导出并核对 OpenAPI → 生成客户端 → 页面接入 → 配置/镜像与完整验收。无 API 或数据变更的质量项在 G2 记录不适用，不强建空接口/迁移。
