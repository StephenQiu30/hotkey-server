## 3. 测试优先步骤

### Task 1：冻结目录与 runner 契约

- RED：扩展 `TestGreenfieldLayout`，拒绝 `test/` 外的 `testdata`，当前五个目录必须导致失败。
- RED：增加 runner 单元测试，要求发现 `_test.go` 与整个 `testdata` 目录，忽略其他文件，并在物化冲突时清理已创建链接。
- RED：通过当前测试进程的 helper-process 模式作为伪 Go 命令，返回非零状态，断言 runner 返回同一状态且 `_test.go`/`testdata` 链接均已清理。SIGINT/SIGTERM 信号处理不在本计划承诺范围。
- RED 命令：`go test ./test/architecture -run TestGreenfieldLayout -count=1`、`go run ./test/runner test ./test/runner -run 'Test(SuiteEntries|Materialize|RunCleansLinksAfterChildFailure)' -count=1`。

### Task 2：最小实现 runner fixture 物化

- 将源扫描从仅 `_test.go` 扩展为 `_test.go` 文件与命名为 `testdata` 的目录；扫描到 `testdata` 后跳过子树，每个 fixture 树只建立一个链接。
- 保留相对于 `test/_suite` 的包路径，目标冲突时返回不含 fixture 内容的稳定错误。
- 物化中途失败和 Go 子进程非零退出均清理所有链接；GREEN 重跑 Task 1 的 runner 用例。

### Task 3：fixture 迁移与防回流

- 把 10 个 fixture 按原包相对路径移到 `test/_suite`，测试中的 `testdata/...` 读取路径保持不变。
- 完成 `TestGreenfieldLayout` GREEN；断言 `internal` 中无 `testdata`，runner 退出后无物化符号链接。
- 同步 AGENTS 和 README 的目录契约。

### Task 4：回归与验收

- `go run ./test/runner test ./test/runner -count=1`
- `go run ./test/runner test ./internal/modules/event/application ./internal/modules/event/domain ./internal/modules/ingestion/application ./internal/modules/intelligence/application ./internal/modules/source/infrastructure/rss ./internal/modules/source/infrastructure/hackernews -run 'Test(ClusteringEvaluation|RankingEvaluationV1Top20Baseline|Plan009BoundedMultilingualRelevance|SchemaRegistry|RelevanceReviewSchemaRegistryContract|EventIntelligenceSchemaRegistryContracts|ParseFeed|Connector)' -count=1`
- 六个包的不加 `-run` 全包命令若因 `HOTKEY_TEST_DSN` 缺失失败，只记录为集成环境 blocked，不代替上述 fixture 定向回归。
- `make lint`、`make build`、`make validate`、`git diff --check`
- `git diff --exit-code -- db/schema.sql docs/openapi`
- `git diff --exit-code -- internal/modules/intelligence/schemas`
- 如存在可丢弃 `HOTKEY_TEST_DSN` 和隔离 `HOTKEY_TEST_REDIS_URL`，执行 `make ci`；否则记录限制。
- 由非主要实施者复核全部差异与证据，无 P0/P1/P2 后结案。

## 4. 错误、安全与回滚

- runner 错误只输出仓库相对路径，不读取或输出 fixture 内容。
- 符号链接只指向同仓库 `test/_suite`，不跟随外部路径；不修改测试数据内容。
- 回滚时先恢复 fixture 原路径，再恢复 runner 扫描逻辑和架构门禁，避免测试暂时失去数据。
- 无数据库、API 或运行时回滚。
