# 搜狗授权来源适配计划

## 前置门禁

- Design 已 accepted，PRD 已 approved。
- 已核实官方公开资料只支持站方向搜狗提交资源，未核实到搜索结果读取契约；阻塞项不得用非官方接口绕过。
- 本版本不实现 Connector；先保存禁止 HTML 搜索页抓取、禁止注册来源类型和 UI 不可操作的失败回归。

## 预计变更范围

- frontend/src/app/dashboard/sources/page.tsx
- frontend/src/components/dashboard/
- frontend/test/unit/app/dashboard-sources-page.test.tsx
- backend/test/architecture/layout_test.go

## 执行步骤

1. 固化官方依据和“无可验证读取契约”的产品边界。
2. 添加架构门禁，禁止生产代码调用搜狗 HTML 搜索页或增加未授权 Connector 包。
3. 用 shadcn/ui Card、Badge 与 Button 组合不可调度的搜狗能力卡片和准入清单。
4. 添加管理员、viewer、无可执行操作和官方链接的单元回归。
5. 运行全量自动化与 agent-browser 桌面/移动端、权限和可访问性验收，新增同编号 Acceptance。

## 验证

- `cd backend && make ci`
- `cd frontend && npm run openapi:check && npm run typecheck && npm run test:unit && npm run build`
- 校验生产代码不存在搜狗 HTML 搜索页、Cookie/验证码绕过或未授权 Connector。
- 使用 agent-browser 验证管理员与 viewer 都能识别阻塞原因，且不存在搜狗创建、探测或启用操作。
- 根目录运行 Compose 配置检查与 `git diff --check`。

## 迁移与回滚

本条不增加来源记录、数据库枚举或调度路径。回滚只需移除静态能力卡片和架构门禁，不影响现有来源、检查点、采集运行或历史证据。
