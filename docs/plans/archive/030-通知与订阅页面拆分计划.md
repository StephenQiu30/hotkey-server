# 通知与订阅页面拆分计划

## 步骤

1. 先修改页面和导航单测，证明混合页面、缺失订阅路由和组合导航不满足新范围。
2. 从通知路由移除 `ReportSubscriptions`，新增订阅路由并复用原组件。
3. 拆分主导航标签，为独立订阅页复用页面级页头和一级标题。
4. 运行针对性与全量前端门禁，在桌面和移动端验证两个入口、内容隔离和新建订阅对话框。
5. 保存同尺寸视觉对照与 Acceptance；若回滚，删除订阅路由并把组件与组合标签恢复到通知页。

## 文件边界

- `frontend/src/app/dashboard/notifications/page.tsx`
- `frontend/src/app/dashboard/subscriptions/page.tsx`
- `frontend/src/app/dashboard/menuConfig.tsx`
- `frontend/src/components/notifications/ReportSubscriptions.tsx`
- `frontend/test/unit/app/` 与 `frontend/test/unit/lib/dashboard-menu.test.tsx`
- `frontend/design-qa.md`

不修改后端、OpenAPI、数据库或生成客户端。
