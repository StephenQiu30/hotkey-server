## 测试策略

- 单元测试覆盖 Payload 枚举、冷却键稳定性、手动分组、角色与 HTTP 安全投影。
- PostgreSQL 集成测试覆盖 active/paused、同桶去重、下一桶、新建 manual run、执行前目标变化和人工重试。
- 前端测试覆盖按钮可见性、提交/复用 Toast、错误态、Editor 无重试和 Viewer 无请求。
- 浏览器使用本地可控 RSS fixture 或既有本地服务，禁止调用真实第三方生产来源。

## 迁移与回滚

无 Schema 迁移。先发布兼容可选 `trigger_type` 的 Worker，再发布 API/UI；单体部署时保持同一版本。回滚先隐藏 UI/路由，再回退 Worker。已有手动 Job 的 JSON 字段为可选，旧 Worker 会忽略未知字段但只应作为短时回滚保护。
