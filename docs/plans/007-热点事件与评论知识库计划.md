## 2. 门禁与交付顺序

- **G0 范围/事实/目录**：007三文档追踪一致；每片先列文件位置、模块依赖、技术选择和待确认项。单owner；X等信息平台发现、四类国内评论来源、内容零付费、复用现有MinIO为用户已确定范围，不默认具备平台账号授权。
- **G1 数据/契约**：明确每片表约束、DTO、任务白名单、预算、权限及迁移影响；生产者与消费者兼容。
- **G2 来源**：目标来源逐操作真实小样本，保存成功、失败、分页/用途/成本证据。可以先开发通用代码，但没有G2不得声称完成真实采集链。
- **G3 测试先行**：本片关键行为先有失败测试，再实现与重构；模型/性能阈值先定义评估口径。
- **G4 功能**：真实数据库/消息、API生成契约和浏览器主链通过。
- **G5 可靠性/分析**：崩溃、权限/删除、预算、样本、引用与恢复实验通过。
- **G6 完整交付**：国内外真实覆盖、七日观察、备份恢复、人工使用验收；记录限制后建立007 Acceptance。

## 4. 实施规格：API

### SPEC-007-API-001 监控与来源

保持 `/api/v1` 和 owner会话。已有创建/编辑接口继续保存草稿；增加内容前明确DTO兼容。目标端点：

| 方法/路径 | 输入与输出 |
|---|---|
| GET /sources | 当前操作能力、用途、验证时间、连接状态；不返回凭据 |
| POST /sources/query-preview | query_spec + source_ids + 时间范围 → 每源实际查询、native/local/unsupported规则、请求估计；零网络调用 |
| POST /monitors/{id}/activate | expected_version + 已明确预算 → active配置快照；不支持关键操作返回冲突及稳定原因 |
| POST /monitors/{id}/pause | expected_version → paused；页边界停止，已采证据保留 |
| POST /monitors/{id}/runs | version + window + mode + Idempotency-Key → 202 + run_id/job_id；只入账，不在HTTP等待采集 |
| GET /collection-runs/{id} | 返回业务状态、collection_outcome、计数、检查点摘要、coverage/stop_reason、预算与时间 |

现有Bluesky查询预览端点的真实路径以生成契约为准；新通用预览若另设路由，实施时同步调用方并移除已无用的内部旧入口，不维护第二套长期契约。错误约定：401未登录、403 CSRF/用途拒绝、409版本冲突/来源不可启用/幂等键载荷冲突、422输入不合法、429本服务限额。上游429记录为异步运行结果，不伪装成HTTP提交失败。公开错误稳定code+request_id，敏感内部原因仅审计。

同一个owner/操作/幂等键及相同载荷返回同一运行；不同载荷复用键返回409。查询分页使用稳定排序 `(first_seen_at,id)` 或 `(published_at,id)` 的游标，不使用易漂移的offset。

### SPEC-007-API-002 内容、事件、分析与知识

目标端点分期增加：GET /contents、GET /contents/{id}、POST /contents/{id}/track-comments；POST/PATCH /events、POST /events/{id}/members、POST /events/{id}/merge、POST /events/{id}/split；POST /events/{id}/analyses、GET /analyses/{id}；GET /knowledge、POST /knowledge/query；GET /alerts、PATCH /alerts/{id}。

内容DTO必须有kind/identity/version/source_url/root/parent/关系状态、published_at/observed_at、coverage和rights摘要。合并/拆分提供expected_revision和显式成员映射；重试幂等。分析和问答异步返回ID，结果有sample_manifest、model_version、statistics_scope、citations、unknowns。引用内容超出权限不返回原文。

所有写操作延续CSRF与幂等/乐观锁；页面GET不触发隐式采集/模型费用。端点与字段在本切片Schema定稿后生成OpenAPI，不据本表提前修改发布契约。

## 5. 实施规格：DATA

### SPEC-007-DATA-001 身份、版本与迁移

使用Design第5节逻辑模型。身份唯一键包含真实namespace，外部ID和内部UUID分开；monitor_match唯一键 `(monitor_version_id,content_id)`。评论parent/root只引用同平台相容身份；未知关系允许暂存外部ID，已解析关联禁止自环/循环。

内容版本按正文hash去重；指标不变也可记录有价值的观察时间，但不得制造正文新版本。首次发现时间只赋值一次；发布/源更新时间为空不以当前时间伪造。未提供计数null，0为有效值。事件成员关联到内容，分析样本必须进一步固定到版本。

旧monitor.version快照回填只形成一个已知版本，不伪造此前修订；旧monitor默认为draft。jobs新增采集kind要变更数据库CheckConstraint和消息白名单。新的collection_run承载结构化产出，现有JobResult保持诊断语义，不能塞长JSON进String(80)。

### SPEC-007-DATA-002 样本、知识与删除

冻结样本清单包含成员版本/入选策略、时间桶、平台、根帖、排序、去重策略、采集截止点、内容hash；分析结果记录prompt/model/schema版本及预算。复算使用同一清单，不再次从实时表取“前100条”。

知识chunk绑定knowledge_version与证据版本；索引状态pending/ready/stale/deleted。词法和向量过滤使用相同权限/时间/事件条件。未被允许存储的页面不落原文，只保存可被允许的元数据；每数据类型配置有效保留期。删除先立屏障使在线查询立即排除，再异步清理原始页、版本、embedding、缓存及包含其引用的派生条目。报告可重算或撤回，不保留含已删原文的旧摘要旁路。

原始页可能含多个对象：单对象删除时对共享原始页进行可验证清理/重写；无法精确清理则撤回整个页证据，其他对象不得继续引用旧页。审计仅保留允许的最少非正文记录。备份按保留策略过期，恢复先重放删除/撤权清单再开放检索。

### SPEC-007-DATA-003 MinIO证据存储

连接现有MinIO。配置拟为HOTKEY_S3_ENDPOINT、HOTKEY_S3_ACCESS_KEY、HOTKEY_S3_SECRET_KEY、HOTKEY_S3_BUCKET、HOTKEY_S3_SECURE；密钥用SecretStr和私有运行配置，不写入任务载荷或API响应。由evidence适配器解释endpoint/TLS设置，业务只使用对象键和证据ID。

推荐环境独立私有bucket，例如hotkey-evidence-dev/test/prod，最终名称先检查现有命名；对象键为raw/{platform}/{yyyy}/{mm}/{dd}/{run_id}/{page_id}/{hash}.json.gz，不含Cookie/用户名等凭据信息。上传校验成功后才允许DB引用，重试幂等；ETag不一概等于正文hash，正文SHA256独立保存。

原文通过受认证后端读取并再次检查可见性；首片不默认发可绕过删除屏障的长期签名URL。不擅自变更现有bucket版本/锁定/生命周期设置。若已启用版本保留，删除需涵盖历史对象版本和未完成multipart上传，否则只创建删除标记不能算完成清除。服务端对象TTL作为后备，应用负责先撤销可见性、传播删除、清理孤儿对象与对账。

## 6. 实施规格：JOB

### SPEC-007-JOB-001 调度、提交与恢复

扩展kind建议为collect_page、normalize_page（只有确需分步时）、analyze_sample、index_knowledge、deliver_alert。消息仍只带内部job_id/epoch/contract_version，参数存业务表并做版本校验，不允许传任意可执行函数或外部认证数据。

定时运行唯一键：monitor_version/source_operation/schedule_slot；页唯一键：run_id/operation/query_variant/root/parent/sort/window/cursor_digest。持久页数据、checkpoint推进和后续Outbox同事务；发现重复页返回原提交结果。网络调用不持有长事务，提交时重新验证fencing和删除/授权屏障。

新任务默认页粒度；HTTP连接/读取时限、总页时限、软/硬任务时限、租约续期、重试上限由操作配置，实测后固定，不能套用诊断20秒总期限。暂时网络/5xx指数退避加抖动并设上限，429遵循Retry-After；403/永久解析契约错误停止该操作并暴露原因。cursor无变化或重复页面触发cursor_stalled并结束partial，不无限循环。

暂停/取消每页前后检查；deadline到达停止派发。恢复扫描只处理过期租约/未发送Outbox，旧epoch不回写。停机期间计划按有限回看窗口合并补采，不逐slot无界追赶；backfill单独标记，不触发实时突发提醒。保存页失败不推进水位，证据文件已写而事务失败产生的孤儿由清理任务按引用表核对。

### SPEC-007-JOB-002 预算、分析和通知

预算在数据库原子预留，维度至少监控/来源/日+每run。请求数、页数、节点、字节、模型输入/输出tokens分别限制。调用失败也记录实际或未知消耗；无法确认费用时不直接退还全部额度以触发重试风暴。刷新热度不重复分析未变化正文。

内容采购预算强制0；只有已验证免费或自建的来源provider可启用。云抓取/搜索服务免费额度独立记账，不能自动充值或转收费端点；自建的机器/带宽成本单独展示。X付费API和收费数据商不在本轮执行路径。

模型输出严格Schema校验，超时/格式错/引用无效记录失败并保留候选。模型只读数据，不执行来源内容里的指令。analysis幂等键包含sample_hash/model/prompt/schema版本。

站内提醒unique(rule_version,event_id,change_id)；业务变化、提醒记录与投递Outbox同事务。外部提醒P1增加provider receipt、retry与对账，不因内容已保存就跳过未送达通知。相同内容在重试或回填时不得重复提醒。

## 7. 实施规格：UI / SEC / OBS / OPS

### SPEC-007-UI-001 主流程

沿用React工作台并按阶段增加收件箱→内容评论→事件→知识页面。主题编辑显示真实查询与作用方式；收件箱区分pending/rejected/analysis_failed；来源可用性按操作呈现。任务轮询仅在页面可见且存在运行任务时进行，结束后停止，退避且取消过期请求；刷新页面从数据库恢复，不靠浏览器内存保存状态。

390px/1440px验证正常、初始空、合法空、加载、部分结果、权限不足、错误、预算耗尽和过期引用。确认关键动作可键盘操作；原链接安全打开。模拟fixture标识明确，最终验收必须运行真实来源路径。

### SPEC-007-UI-002 文件和依赖门禁

页面/业务状态在features/{domain}，装配在app，共享协议/UI在shared；任何新功能先选目录再写文件。S00增加frontend/scripts/check-boundaries.mjs并接入npm/CI，检查app→features→shared→generated方向、反向依赖及已迁移文件不再留副本。后端architecture测试从src递归枚举全部Python文件，对未登记顶层模块显式失败；固定PACKAGES不能成为排除新目录的扫描入口。分别构造未知目录、路由导入ORM、适配器导入数据库、shared导入feature等负向样例，先验证失败再实现检查。

### SPEC-007-SEC-001 用途与隔离

每次采集/分析/展示/导出按allowed/denied/unknown校验相应权限与保留期。凭据仅私有配置/引用；CSRF、owner检查继续存在。HTTP适配器限制主机、协议、重定向、私网和响应大小；需要浏览器时单独进程/资源/出站边界，取消回收进程树。对来源正文的提示注入建立负向测试，模型不获得写权限或凭据。

### SPEC-007-OBS-001 指标与证据

记录run/job/adapter/policy版本、实际查询指纹、窗口、每页计数/bytes/时延、停止原因、重试、预算、最后成功时间。分别计算作业成功率和来源采集结果，不用单一绿色状态掩盖partial。检测来源schema漂移、游标停滞、陈旧数据、积压与无效引用。日志不记录Cookie/token/认证头/完整评论；诊断面板只显示允许的信息。

### SPEC-007-OPS-001 发布、负载与恢复

开发与生产沿用根Compose及prod覆盖。修改顺序：失败测试 → additive迁移/后端Schema/Worker消费者 → OpenAPI导出 → 生成客户端/页面 → 配置/producer → 真实小样本 → 回滚实验。变更任务kind时先部署可识别新契约的消费者，再启新调度。

先单owner/单来源/单主题/一页放量，随后国内海外各一来源及多主题；每次放量以预算和积压证据决定。记录机器CPU/RAM、数据库版本/数据规模、内容/评论数、并发、页大小、缓存冷热、测试窗口、外部平台延迟/限制和成本。SLO在这些条件具备后制定，不预设无条件QPS或延迟。

回滚先暂停调度/分析并停止producer，排空或隔离新任务，旧应用只读旧能力；保留新表和证据卷。数据库恢复在隔离环境演练，核对内容/版本/页/checkpoint/Outbox/删除清单，恢复后新任务必须重新校验授权。不得执行删除用户持久卷的命令。
