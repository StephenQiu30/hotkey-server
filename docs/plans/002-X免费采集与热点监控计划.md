## 1. 目标、归属和边界

交付 X 的关键词 Latest/Top、指定账号作品、事件回复三条真实自动路径，以及持续快照、预算和失败证据。X 是首版必需，其他海外来源、用户导入或模拟样本均不能替代该验收。

本计划负责**来源可行性、X 适配器与真实能力验收**，不重写平台业务功能。003/004 管设置与连接，005/006/008 管三条产品路径，007 管作品，009/010/031 管执行，013 管评分。当前选择官方 X API；`twscrape` 不再是执行候选，当前没有实采结论。

责任角色：来源接入主责，后端/前端/质量验证协作。M0 关闭准入与样本问题；M1 交付隔离适配器与契约；M2/M3 接入真实业务；M5 结束专项验收。X 官方 API 是唯一已授权的按量内容来源例外；无用户确认的费用硬上限与开发者凭据时不发请求，不采购账号、代理或自动切换账号绕过限制。
