# X 免费采集与热点监控执行计划

日期：2026-09-17。依据 [002 专项设计](../design/002-X免费采集与热点监控设计.md)；状态 planned，全部任务和验证待执行。总进度见 [BACKLOG](../../BACKLOG.md)，逐项产品实现见 [计划索引](README.md)。

## 1. 目标、归属和边界

交付 X 的关键词 Latest/Top、指定账号作品、事件回复三条真实自动路径，以及持续快照、预算和失败证据。X 是首版必需，其他海外来源、用户导入或模拟样本均不能替代该验收。

本计划负责**来源可行性、X 适配器与真实能力验收**，不重写平台业务功能。003/004 管设置与连接，005/006/008 管三条产品路径，007 管作品，009/010/031 管执行，013 管评分。twscrape 是既有设计的初始候选，版本、访问条件和实际可用性必须在实施时复核，当前没有实采结论。

责任角色：来源接入主责，后端/前端/质量验证协作。M0 关闭准入与样本问题；M1 交付隔离适配器与契约；M2/M3 接入真实业务；M5 结束专项验收。免费与数据边界保持不变，不采购账号、付费 API/代理或自动切换账号绕过限制。

## 6. 验证入口、回退与完成定义

拟定验证入口：在 backend/ 的锁定环境执行 `python -m pytest tests/unit/test_x_adapter.py`、`python -m pytest tests/integration/test_x_pipeline.py`；在 frontend/ 运行后续由 042 建立的 test:e2e 脚本选择 x_monitoring.spec.ts。CLI 参数由 S01 固定，秘密不得放入命令历史或普通输出。当前未建立代码，以上命令未运行。

故障模拟只在受控来源执行，不向 X 压测或主动制造账号挑战。真实验证每次保留可核对时间、版本、访问条件和请求数；JSON 示例或录制样本不冒充当前实采。

回退先停用受影响能力，停止新请求并核对在途状态；只在数据兼容时回退适配器。既有资料继续可读，秘密撤销和删除标记不回退。所有原始 AC 和适用质量约束通过，且有真实证据和恢复说明，才完成本计划；即使其他平台可用，X 未通过仍阻塞首版“含 X 自动监控”的交付声明。
