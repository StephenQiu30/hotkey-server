# 模型服务接入与模型配置执行计划

日期：2026-09-17。来源：[043 PRD](../prd/043-模型服务接入与模型配置.md)、[调研](../research/043-模型服务接入与模型配置调研.md)、[设计](../design/043-模型服务接入与模型配置设计.md)。总体进度见 [BACKLOG](../../BACKLOG.md)。状态 planned，全部 checklist 待执行。


用户已确认两种信息获取入口都需要：044 采集平台自身公开信息，045 通过模型联网工具检索外部线索。本项仅提供模型连接/配置基础；044 不依赖模型推理，045 显式复用本项能力。详见 [044 PRD](../prd/044-模型平台信息采集与变更监控.md)、[045 PRD](../prd/045-模型联网检索与线索采集.md)。

## 1. 目标、角色和当前差距

交付受控的服务连接、模型信息、用途配置、零付费与数据策略，以及可追溯的运行记录。归属 M6，责任角色为后端＋前端＋分析验证；开工时登记实际人员。Research/Design 已建立，但 Design 仍 proposed；无适配器、模型部署、账户推理或验收结果。

043 的 S03 是 022/023/025 使用模型配置的先行输出。连接测试不依赖 022 的正式分析，正式分析激活须另经各用途质量门槛。P0、付费/BYOK 路线、模型训练和新 Node 后端不在本项实施范围。

## 4. 实施规格 SPEC

| ID | 执行规格 |
|---|---|
| SPEC-043-API-001 | 连接 CRUD、目录 GET/同步、用途版本、POST tests 受理 202、运行查询与取消；返回脱敏 DTO；写操作/测试幂等；分页有界；G2 冻结错误与 operation_id 后生成 OpenAPI/客户端。 |
| SPEC-043-DATA-001 | 连接＋完整模型 ID＋不可变目录/配置版本；能力声明与实测独立；费用币种/单位/维度和未知状态；模型尝试关联任务、输入证据及实际返回信息；版本不可绕过当前权限。 |
| SPEC-043-JOB-001 | 显式测试合成输入；派发前核对能力、外发、价格、当前权限；请求原子预留；有界超时/重试/取消；结果未知不自动重发；任务状态与 outbox 同事务。 |
| SPEC-043-UI-001 | 连接、模型卡、用途配置、运行记录四区；正常/空/加载/陈旧/额度不足/不兼容/无权限；显示单价和额度差异、选择不可用原因；不要求先充值。 |
| SPEC-043-SEC-001 | 密钥不可回读，不在浏览器请求供应商；批准端点白名单和本地例外；正文不执行指令；外发最小化及当前授权；免费和隐私条件交集为空时停止。 |
| SPEC-043-OBS-001 | 记录请求模型/返回模型/提供方、配置及目录版本、每次尝试、估算/实际/未知计量；失败/取消不抹消消耗；日志无正文、Key 或原始 URL；不用收费网关报表。 |
| SPEC-043-OPS-001 | local/zero_price 为当前执行类别；付费/赠送额度/未知只展示；外部默认关，正式启用前取真实证据；停止新增请求后兼容回退，保留历史与对账。 |

顺序：数据/状态与权限 → 领域服务/Worker → FastAPI/Pydantic → OpenAPI/生成客户端 → 交互 → 隔离依赖/浏览器/真实服务验证。无变更处写 N/A 理由，不创建空迁移或客户端旁路。
