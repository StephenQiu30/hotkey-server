# 微博开放平台关键词来源适配计划

## 前置门禁

- [x] Design 已 accepted，PRD 已 approved。
- [x] 已核实官方 CLI 0.9.0、生产 API 基址、Bearer、whoami、commands 与 invoke 契约。
- [x] 已确认公开示例中的关键词命令为 `search statuses/limited`，账号时间线不在本条猜测实现。

## 执行步骤

1. [x] 扩展 Source Domain、Schema、指标能力和健康启用门禁。
2. [x] 实现固定官方 CLI API 的关键词 Connector、能力发现、分页、映射、安全网络与错误分类。
3. [x] 更新 Source API、OpenAPI Client 与 shadcn/ui 来源表单和能力说明。
4. [x] 完成领域、连接器、数据库、权限、脱敏、分页和错误测试。
5. [x] 运行后端 CI、前端全量测试/构建、Compose、diff 与 React 质量检查。
6. [x] 使用 agent-browser 完成未登录、管理员、Viewer、桌面/移动和 axe 验收。
7. [x] 新建并通过同编号 Acceptance，以中文 Conventional Commit 独立提交。

## 测试清单

- 正常：whoami、available 命令、关键词 invoke、分页、转发关系、发布时间、指标和官方链接。
- 失败：缺少 Token、命令锁定、401/403/429/5xx、超时、畸形 JSON、超大响应、恶意重定向和非法 ID/URL。
- 幂等：同页重复、分页重试和跨 CollectionRun 重复微博 ID。
- 权限与脱敏：Viewer 无管理入口；API、日志、错误和浏览器均无 Token 或 env 名称。
- UI：1440×1000 与 390×844 无横向溢出，关键流程 axe 零违规。

## 迁移与回滚

不新增表。Schema 仅扩展受控来源枚举和固定配置约束；新来源默认 disabled。回滚时先停用微博调度，再回退应用，保留历史内容、指标、检查点和采集运行。
