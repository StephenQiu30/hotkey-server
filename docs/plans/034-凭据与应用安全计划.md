## 4. 实施规格 SPEC

这些是可评审的执行规格；路径/接口名称为候选，G2 冻结后才是实施契约。若调整需同步测试、客户端与本文件，不私自改变 PRD 的用户语义。

| SPEC ID | 规格 |
|---|---|
| SPEC-034-API-001 | 登录/注销与受保护会话入口；连接只接收秘密引用或安全写入材料，普通响应不可回读；修改操作防非预期跨站请求。 |
| SPEC-034-DATA-001 | 用户会话、秘密引用和撤销状态；密钥不入业务表普通视图、日志、源码或导出，适用传输和存储保护由设计冻结。 |
| SPEC-034-JOB-001 | 后台获得最小秘密与权限，撤销后停止新请求；采集目标与受控自建通知目标分开校验，每次重定向复核。 |
| SPEC-034-UI-001 | 改进本质量要求影响的实际业务页面、状态或运维记录，不默认新建一个独立质量功能页面；无界面变化时以书面理由说明该 UI 分支不适用，不能跳过实际受影响界面。 |
| SPEC-034-SEC-001 | 先检查当前身份及资源权限；配置版本不能绕过撤权、删除、停用和更严格预算。秘密不可回读，正文与外部输入只作数据。关键变更留操作者、对象、时间与版本。 |
| SPEC-034-OBS-001 | 测试脚本/公式、URL重定向及秘密全链脱敏；仅隔离样本，未验证不宣称通过安全认证。 |
| SPEC-034-OPS-001 | 在隔离依赖验证后渐进启用本能力；保持历史资料可读。配置缺失或外部条件不满足时明确拒绝/延期。变更前评估数据兼容与回退，停止新增操作优先于破坏性迁移。 |

数据/接口/前端执行顺序：先冻结字段、状态与权限 → 如需则新增向后兼容迁移 → 领域服务和 Worker → FastAPI/Pydantic 运行契约 → 导出并核对 OpenAPI → 生成客户端 → 页面接入 → 配置/镜像与完整验收。无 API 或数据变更的质量项在 G2 记录不适用，不强建空接口/迁移。
