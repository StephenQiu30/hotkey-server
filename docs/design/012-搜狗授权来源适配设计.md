# 搜狗授权来源适配设计

## 现状

参考项目通过搜狗网页搜索采集热点；搜狗公开的“开放平台”主要用于站方向搜狗提交结构化数据，不构成可读取搜索结果的官方 API。

## 目标

预留搜狗来源能力，但只有获得书面授权、稳定读取接口和明确条款后才启用关键词采集。

## 非目标

不使用未授权网页抓取、浏览器会话、验证码绕过或不稳定私有接口补齐能力；本条不实现其他编号的业务细节。

## 核心决策

- 不得解析搜狗搜索结果页、绕过验证码或复用浏览器 Cookie。
- SourceType 可在授权契约落地后加入；在此之前 UI 显示“需要授权”，且不写入可调度连接。
- 授权适配器必须实现固定端点、凭据引用、速率限制、分页、删除同步和原始字段证据。
- 若无读取授权，以站点官方 RSS/Atom 或其他已批准来源覆盖信息需求，不声称数据来自搜狗。

## 数据、接口与交互

- 授权准入清单
- 禁用态来源卡片与说明
- 未来 Connector 端口契约
- 条款、配额和删除同步记录

跨端契约先修改 Schema 与后端注解，再生成 OpenAPI 和前端 Client。来源能力必须在发布监控前可检测，禁用或阻塞状态不能进入调度。

## 安全、失败与降级

当前缺少可验证的公开读取接口，本条实现状态应保持 blocked，不能为了功能数量牺牲合规。

第三方失败按认证、限流、临时、解析和永久错误分类；关闭单个来源不影响历史证据和其他来源。

## 设计验收边界

- 未配置授权合同时系统无法发布搜狗来源
- 没有任何 HTML 搜索页抓取实现
- 授权版本能够通过契约测试后才解除 feature flag
