# 12 今日热点

对应 [12-今日热点](../requirement/12-今日热点.md)；实施拆分见 [12-今日热点](../plan/12-今日热点.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

从当天事件找到值得阅读和持续跟踪的变化。首页主内容是排序事件，不再混入旧资讯流和专题推荐。

## 结构与交互

- 主栏为事件信息流，默认6条、逐次加载到最多50条；辅栏保留全站指标、最快增长5条、X趋势6条和最新日报各自的数据边界。
- 四项全站统计不可从当前页推算；公开数据失效各区独立反馈，48小时来源参与度与24小时提及量按真实口径标注。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 四项概览 | 4项；同一公开范围和时间边界 |
| 分类与事件流 | 原稿首屏6行；当前热榜读取最多50个，每次展示增加6个 |
| 负面突增 | 1条重要提醒；无数据保持提醒容器空态 |
| 上升最快 | 原稿5条 |
| X趋势 | 原稿6条 |
| 今日日报 | 最新daily 1期 |

## 数据与复用边界

先核对现有入口：[frontend/src/app/components](../../frontend/src/app/components)、[backend/app/api/routers/publication.py](../../backend/app/api/routers/publication.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

首页增量上限、独立失败、权限撤回与窄屏单列；无情感样本不呈现零负面。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
