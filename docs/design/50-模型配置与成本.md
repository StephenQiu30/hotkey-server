# 50 模型配置与成本

对应 [50-模型配置与成本](../requirement/50-模型配置与成本.md)；实施拆分见 [50-模型配置与成本](../plan/50-模型配置与成本.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

作为独立运营人员，我需要按能力配置本机模型并核对真实成本。

## 结构与交互

- 按能力展示模型配置和版本，当前只启用本机Codex；OpenRouter等云端候选标条件，不能自动回退。
- 成本分组标货币、日期、输入/缓存/输出token，未知不显示0；变更有原因和确认，只影响后续任务。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 模型配置 | 一份配置；逐能力显式切换 |
| 成本与熔断 | 按天窗口汇总，确认成本异常需原因 |

## 数据与复用边界

先核对现有入口：[frontend/src/app/operations/models](../../frontend/src/app/operations/models)、[backend/app/api/routers/ai_models.py](../../backend/app/api/routers/ai_models.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

未配置、限流、未知账单、多货币、切换版本和禁止收费自动回退。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
