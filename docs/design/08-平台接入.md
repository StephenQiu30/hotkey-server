# 08 平台接入

对应 [08-平台接入](../requirement/08-平台接入.md)；实施拆分见 [08-平台接入](../plan/08-平台接入.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

区分关键词搜索、标签/账号、热榜与模型辅助研究的能力和接入条件。

## 结构与交互

- 来源能力矩阵分别显示原生搜索、详情、根评论、回复、增量、手动/定时与连接状态，不用一个“支持”覆盖全部能力。
- B站/HN是待真实核验候选；X、Instagram保留目标和不可用原因，OpenRouter列模型服务而非社交平台。
- 热榜、RSS、网页和模型研究标明发现方式；凭据只在本机配置，不通过页面存Cookie或复制到材料。

## 数据与复用边界

先核对现有入口：[backend/app/connections/catalog.py](../../backend/app/connections/catalog.py)、[backend/app/sources/editorial_factory.py](../../backend/app/sources/editorial_factory.py)、[backend/app/sources/adapters/x_api.py](../../backend/app/sources/adapters/x_api.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

候选或路由不算已接通，标签不冒充任意关键词，获批/授权不足只阻塞对应真实请求。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。

## 首个平台决策边界

| 对象 | 当前定位 | 对应设计决策 |
|---|---|---|
| B站/HN现有路径 | 免费首来源候选 | 分别核实关键词、详情、根评论、回复及自然执行能力，不用一个通过结论覆盖全能力 |
| X | 明确目标平台；当前官方付费路径未启用 | 保留目标缺口，离线MockTransport不能当网络已接通 |
| Instagram | 明确目标；接入本期冻结 | 先确认标签/账号是否满足目标与解冻范围，不能称任意正文关键词已支持 |
| OpenRouter | 模型与辅助搜索候选 | 归入09/50，不进入社交来源覆盖矩阵；当前不自动启用云端或收费 |
| RSS/网页/JSON/热榜 | 补充发现 | 明确发现方式与许可，不抵扣关键词搜索验收 |

凭据、账号与来源准入状态通过既有连接路径读取；手动/定时、搜索/评论/回复分别表达。没有授权仅阻塞该对象的真实请求，仍可进行合同核对与受控验证。
