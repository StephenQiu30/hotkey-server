# 47 任务详情与恢复

对应 [47-任务详情与恢复](../requirement/47-任务详情与恢复.md)；实施拆分见 [47-任务详情与恢复](../plan/47-任务详情与恢复.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

作为所属用户，我需要核对检查点、预算和可安全恢复的操作。

## 结构与交互

- 详情展示一份任务、冻结配置、有界窗口和最终回执；刷新只读。
- 重试/取消由服务端合法状态提供；提交未知先核对原回执，不盲目生成新任务。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 执行详情 | 单job，显式刷新；有界窗口响应 |
| 恢复与取消 | 仅服务器允许状态可操作 |

## 数据与复用边界

先核对现有入口：[frontend/src/app/jobs/[jobId]](../../frontend/src/app/jobs/[jobId])、[backend/app/api/routers/collection_jobs.py](../../backend/app/api/routers/collection_jobs.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

执行中取消、过期租约、未知写入、预算耗尽、重复恢复及凭据错误即停止。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
