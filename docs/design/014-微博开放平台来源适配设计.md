# 微博开放平台关键词来源适配设计

## 问题与目标

HotKey 尚不能通过微博官方、可审计的读取契约采集关键词结果。微博开放平台于 2026 年提供官方 `weibo-cli`：开发者完成认证、套餐或试用及 OAuth 登录后，CLI 通过固定 API 调用平台命令。MVP 只实现官方公开示例明确命名的 `search statuses/limited --q` 关键词能力，不猜测未公开的账号时间线命令或抓取网页。

## 官方能力边界

- 官方入口是 `https://open.weibo.com/cli`，生产 API 基址由官方 npm 包固定为 `https://open.weibo.com/cli/api`。
- 官方 CLI 0.9.0 公开 `GET /cli/whoami`、`GET /cli/commands`、`GET /cli/commands/{group}/{action}` 与 `POST /cli/invoke`；请求使用 `Authorization: Bearer <token>`。
- 关键词检索的公开命令是 `search statuses/limited --q keyword`。可用命令由当前开发者认证、OAuth 会话、订阅套餐、窗口额度和积分共同决定，不可由 HotKey 静态假设。
- 健康探测必须同时验证 whoami 和可用命令清单中存在 `search/statuses/limited`；未认证、未订阅、命令锁定、额度不足或 Token 撤销时来源不能启用。
- 任意网页搜索、热搜页、移动接口、Cookie、验证码和旧私有接口均禁止。账号时间线、发布、评论、关注和热搜趋势不属于本条 MVP。

## 核心设计

1. 新增固定来源类型 `weibo`，固定端点 `https://open.weibo.com/cli/api`，认证类型必须为 bearer，凭据只允许 `env:NAME`。
2. 来源创建后默认 disabled；健康探测通过后由管理员手动启用。探测和采集都动态确认命令仍为 available。
3. 采集调用 `POST /cli/invoke`，请求体固定 `group=search`、`action=statuses/limited`，只把监控查询、页码和有限 count 放入 args，不接受调用方提供路径或命令名。
4. 响应只映射微博 ID/idstr、正文、作者、发布时间、转发父 ID、官方链接及公开的转发/评论/点赞指标；原始 Token、错误体和命令目录不越过 Connector 边界。
5. 分页游标只保存版本、查询签名和页码；同一微博 ID 依靠既有来源内容唯一键幂等。空页终止，满页继续，最大页数仍由 SourceConfig 和调度层控制。
6. `deleted`、`is_deleted`、不可见状态或缺少稳定 ID 的结果不写正文，输出无原始载荷的稳定诊断。历史事实不因一次搜索缺失而被推断删除。
7. HTTP 客户端固定主机、TLS 1.2、全局公网 DNS 复验、同主机重定向限制、超时和 4 MiB 响应上限；401/403、429、5xx、网络和解析错误使用统一分类。

## 数据与交互

- SourceConnection 复用既有字段，不新增密钥或任意 JSON 字段；合规配置强制正文存储、归属标记和删除同步。
- 管理员表单只需名称与 `env:NAME`；官方端点、Bearer、开发者协议和合规开关固定只读，并明确列出认证、套餐、OAuth、命令可用和额度门禁。
- Viewer 只看到名称、类型、状态和条款链接，不看到端点、凭据引用、探测或启用操作。
- 公开指标可进入既有 MetricCapabilityProfile；未返回的指标保持 unknown，不补零。

## 安全、失败与降级

- Token 缺失、包含换行或上游 401/403均分类为 authentication；命令不在 available 清单中也视为授权能力不可用。
- 429 保持 rate_limited；5xx 和网络错误为 temporary；畸形 JSON、超大响应、非法微博 ID/URL 为 parse/permanent 安全诊断。
- 来源失败保持 disabled/degraded，不影响 RSS、HN、X、Bing、Bilibili 或历史证据。界面提供 RSS/Atom 作为不需要微博授权时的替代方式。

## 非目标

- 未公开或未验证的账号时间线 capability。
- 网页、热搜页、移动 API、Cookie、验证码、浏览器会话或私有接口。
- OAuth 登录页托管、套餐购买、Token 自动刷新、发布和互动写操作。
- 把一次关键词搜索未返回某条历史微博解释为删除。

## 验收标准

- AC-014-1：Token 无效、开发者/套餐未就绪或 `search/statuses/limited` 不可用时，来源不能启用或采集。
- AC-014-2：关键词、分页、稳定 ID、转发关系、作者、时间和公开指标映射正确；重试不重复 Content。
- AC-014-3：不可见/删除提示不写正文，失败分类、SSRF、大小和凭据脱敏门禁通过。
- AC-014-4：管理员与 Viewer 权限、OpenAPI、桌面/移动布局及可访问性验收通过。
