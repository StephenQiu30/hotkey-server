# 微博开放平台来源适配设计

## 现状

当前仓库没有微博连接器；参考项目提供微博关键词结果。

## 目标

在微博开放平台批准的权限范围内采集关键词或授权账号信号，并映射为可追溯内容和指标。

## 非目标

不使用未授权网页抓取、浏览器会话、验证码绕过或不稳定私有接口补齐能力；本条不实现其他编号的业务细节。

## 核心决策

- 使用 OAuth2 和官方批准接口，凭据只通过 env 引用；不得抓取搜索页、热搜页或移动接口。
- 将关键词搜索与账号时间线作为不同 capability，发布 Monitor 时只允许连接实际获批的能力。
- 以微博 ID、created_at 和分页游标去重，保留转发关系、作者、正文、链接和官方公开指标。
- 接口权限不足、审核未通过或配额过低时连接保持 degraded/disabled，并给出替代 RSS 来源。

## 数据、接口与交互

- 微博应用授权与健康检查
- 关键词/账号能力档案
- 内容、转发关系和指标映射
- 配额、权限与删除同步

跨端契约先修改 Schema 与后端注解，再生成 OpenAPI 和前端 Client。来源能力必须在发布监控前可检测，禁用或阻塞状态不能进入调度。

## 安全、失败与降级

微博接口开放范围与审核结果取决于应用资质；计划不得承诺未获批的字段或全站搜索。

第三方失败按认证、限流、临时、解析和永久错误分类；关闭单个来源不影响历史证据和其他来源。

## 设计验收边界

- 无批准 scope 无法启用对应能力
- 分页重试不重复内容
- 删除或不可见内容按授权条款执行同步
