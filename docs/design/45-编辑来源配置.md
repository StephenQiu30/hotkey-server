# 45 编辑来源配置

对应 [45-编辑来源配置](../requirement/45-编辑来源配置.md)；实施拆分见 [45-编辑来源配置](../plan/45-编辑来源配置.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

作为独立运营人员，我需要管理可公开阅读的合规取数来源。

## 结构与交互

- 来源配置和策略按版本编辑，展示候选许可、免费范围及不可用原因；资料20条、运行100条保持来源范围。
- 配置保存与手动外部预览/采集明确区分，网络动作提示真实作用；运营Token只在内存。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 编辑来源配置 | 现有运营列表和表单 |
| 预览/材料/运行 | 材料20条/页；运行最多100条；先选来源 |
| 准入与图标 | 显式维护动作；令牌仅内存 |

## 数据与复用边界

先核对现有入口：[frontend/src/app/sources/editorial](../../frontend/src/app/sources/editorial)、[backend/app/api/routers/editorial_sources.py](../../backend/app/api/routers/editorial_sources.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

未授权预览拒绝、版本冲突、来源过滤、Token不落盘及取消/停止。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
