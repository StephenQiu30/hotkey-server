# Web工作台全页面交互设计

## 现状

首页、完整认证、Overview、监控、来源、内容列表/详情、事件、告警、报告、订阅、用户、治理与资料页均已连接生成 OpenAPI Client。当前缺口不是再造页面，而是跨页面完整性：主导航只展示概览、监控、事件和简报，Viewer 无法从导航到达来源、内容与订阅，告警没有主入口；`topics`、`favorites` 仍占用只重定向的旧路由，报告通知还指向 `favorites`；Profile 与订阅加载失败会静默显示零值/空态，事件、内容和告警错误态没有就地重试；多张宽表缺少可命名的键盘滚动区域，内部原生 `<a>` 会触发整页刷新。

## 目标

在不新增后端事实或页面体系的前提下，补齐整个 Web 工作台的信息架构、恢复路径、客户端导航和响应式可访问性，使 Viewer、Editor、Admin 都能从导航完成监控→内容→事件→告警→报告/订阅主故事。

## 非目标

- 不改 Schema、后端 API、权限或业务状态机；缺失能力必须回到对应领域任务，而非前端 Mock。
- 不进行第二轮视觉重写，不引入 React Hook Form、Zod 或新的状态/组件库；现有表单尚不足以证明新增依赖必要。
- 不保留无业务意义的兼容路由，不新增全局命令面板、个性化仪表盘或自定义主题编辑器。

## 核心决策

- 主导航固定为概览、监控、来源、内容、事件、告警、报告、通知与订阅；账户菜单固定承载 Profile，Admin 才显示用户与权限、配额与审计。所有角色只隐藏无权功能，不隐藏有权读取的页面。
- 删除 `/dashboard/topics` 与 `/dashboard/favorites` 页面；仓库内链接只能指向真实终点。报告通知进入 `/dashboard/reports`，事件通知使用页面支持的 `event` 查询参数。
- Dashboard 段提供统一 `loading.tsx` 与 `error.tsx`；业务页仍对客户端请求分别呈现 loading、empty、error+retry，权限专属页呈现 forbidden。失败不得伪装为空数据或零值。
- 站内内部导航统一使用 Next.js `Link`；外站与同页锚点保留 `<a>`。列表/详情沿用现有 shadcn/ui 组合，不复制基础控件。
- 宽表的滚动容器具有 `role=region`、可读名称与键盘焦点；桌面主导航在 1280px 展开，768px 与 360px 使用可滚动 Radix Sheet，关闭后恢复触发器焦点。

## 数据、接口与交互

- 公共与认证：`/`、登录、注册、找回/重置密码、404 保留现有真实流程和错误反馈。
- 主故事：Overview、监控、来源、内容列表/详情、事件、告警、报告、通知与订阅必须从导航互达，查询参数与详情链接保持可刷新。
- 治理与账户：Profile 对统计失败给出重试；用户与治理页仅 Admin 可见且服务端继续强制鉴权。
- 全状态：适用页面覆盖 loading、empty、error+retry、forbidden；路由渲染异常由段级错误边界兜底。
- 可访问性：主/移动/账户导航具名，当前页使用 `aria-current`；宽表键盘可滚动，Dialog/Sheet 焦点循环与恢复由 Radix 保证。

所有状态变化保存明确版本、时间和操作者；跨端字段由 Schema、后端 DTO 和生成 OpenAPI 驱动，前端不得手写重复类型。

## 安全、失败与降级

前端只消费生成 Client；网络错误只显示安全业务消息。段级 `error.tsx` 不展示堆栈，重试调用 Next.js `reset()`；页面重试只重放幂等读取。站内导航不得把 Token、内部地址或错误详情写入 URL。

## 设计验收边界

- 导航列出的每个入口返回真实页面，无仓库内链接指向 `topics`/`favorites`，旧地址进入 404 而非伪装成功。
- 适用页面的 loading、empty、error+retry、forbidden 均有组件或浏览器证据；读取失败不显示误导性空态/零值。
- 站内导航不触发文档级重载；宽表、移动 Sheet、账户菜单和对话框均可完全键盘操作并恢复焦点。
- 360×800、768×1024、1280×800 完成 Viewer/Admin 主路径、错误恢复、无横向页面溢出和 WCAG 2 A/AA 验收。
