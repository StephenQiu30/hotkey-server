# X官方搜索连接器设计

## 现状

当前仓库没有 X/Twitter 连接器；参考项目通过 Twitter 搜索提供关键词监听。

## 目标

使用 X API v2 Recent Search 获取最近 7 天公开帖子，使关键词、账号和语言规则进入统一采集流水线。

## 非目标

不使用未授权网页抓取、浏览器会话、验证码绕过或不稳定私有接口补齐能力；本条不实现其他编号的业务细节。

## 核心决策

- 只调用官方 `/2/tweets/search/recent` 或经单独批准的全量归档接口，使用 env Bearer Token。
- QueryPlanner 编译关键词、短语、from、lang、排除转帖/回复等运算符，并受套餐长度和运算符能力约束。
- 以 since_id 和 next_token 维护检查点，映射作者、正文、时间、会话、引用、媒体和公开指标。
- 配额耗尽返回 rate_limited 并按 reset 时间延迟，不抓取 x.com 页面作为回退。

## 数据、接口与交互

- X 来源配置与健康检查
- 关键词和账号查询
- 分页检查点与指标快照
- 授权、配额和删除/隐藏同步

跨端契约先修改 Schema 与后端注解，再生成 OpenAPI 和前端 Client。来源能力必须在发布监控前可检测，禁用或阻塞状态不能进入调度。

## 安全、失败与降级

X 套餐、价格与运算符会变化；能力档案必须运行时可配置，不能在 Domain 写死商业套餐。

第三方失败按认证、限流、临时、解析和永久错误分类；关闭单个来源不影响历史证据和其他来源。

## 设计验收边界

- 最近搜索窗口内不漏不重
- 禁用连接或凭据撤销后不再发起请求
- 删除、withheld 和敏感内容按官方字段处理
