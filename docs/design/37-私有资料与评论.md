# 37 私有资料与评论

对应 [37-私有资料与评论](../requirement/37-私有资料与评论.md)；实施拆分见 [37-私有资料与评论](../plan/37-私有资料与评论.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

作为所属用户，我需要读取原帖与评论上下文并核对采集证据。

## 结构与交互

- 详情呈现内容身份、版本、观察和出处；根评论20条、回复20条分别分页，父上下文缺失明确说明。
- 分析绑定主题规则和提示/模型版本；评论刷新是显式任务，阅读详情不自动采集。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 资料正文与出处 | 单身份及当前可读版本历史 |
| 评论树 | 根评论20条/页，回复另按20条加载 |
| 分析及刷新 | 切主题/版本读取；刷新评论明确点击 |

## 数据与复用边界

先核对现有入口：[frontend/src/app/content/[contentId]](../../frontend/src/app/content/[contentId])、[backend/app/api/routers/content_records.py](../../backend/app/api/routers/content_records.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

父链缺失、评论分页、更新/删除、替换内容ID越权及刷新预算保护。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
