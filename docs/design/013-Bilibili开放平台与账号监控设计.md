# Bilibili开放平台与账号监控设计

## 现状

当前仓库没有 Bilibili 连接器；参考项目支持关键词搜索，并能识别 B 站账号后按账号追踪。

## 目标

通过哔哩哔哩开放平台和用户授权，实现已授权账号的稿件、专栏或直播信号监控，并保留账号识别体验。

## 非目标

不使用未授权网页抓取、浏览器会话、验证码绕过或不稳定私有接口补齐能力；本条不实现其他编号的业务细节。

## 核心决策

- 优先实现 OAuth/开放平台授权账号监控；公共关键词搜索仅在官方授予对应接口权限时启用。
- 规则解析 `@账号`、UID 或主页 URL 为 account target，并在发布前展示解析出的账号身份供用户确认。
- Webhook 可用时优先接收事件，轮询作为补偿；以稿件/专栏 ID 和更新时间维护检查点。
- 播放、点赞、评论等指标只有官方授权返回时才入库，并由指标能力档案声明语义。

## 数据、接口与交互

- B 站应用授权和账号绑定
- 账号目标解析与确认
- 稿件、专栏、直播事件采集
- Webhook 验签、轮询补偿和指标快照

跨端契约先修改 Schema 与后端注解，再生成 OpenAPI 和前端 Client。来源能力必须在发布监控前可检测，禁用或阻塞状态不能进入调度。

## 安全、失败与降级

开放平台能力可能偏向已授权创作者而非全站搜索；公共搜索不能以非官方接口补齐。

第三方失败按认证、限流、临时、解析和永久错误分类；关闭单个来源不影响历史证据和其他来源。

## 设计验收边界

- 未授权账号数据不会被读取
- 相同内容在 Webhook 与轮询并发时只生成一条 Content
- 授权撤销后停止采集并保留合规所需审计
