# 10 权限与数据生命周期

对应 [10-权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；实施拆分见 [10-权限与数据生命周期](../plan/10-权限与数据生命周期.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

公开阅读与个人监测权限清楚，撤回、删除和失败均可解释且不泄漏资料。

## 结构与交互

- 公开阅读与个人/运营资源按会话和许可分别读取；撤权清理视图，故障不伪装退出登录。
- 原帖、评论父链、正文版本和时间语义在关联视图保持一致；撤回后不回退旧修订绕过限制。
- 写入携带既有版本和幂等回执，冲突保留输入，超时未知先核对；客户端不保存凭据或复制受限正文。

## 数据与复用边界

先核对现有入口：[backend/app/api/routers/identity.py](../../backend/app/api/routers/identity.py)、[backend/app/api/routers/publication.py](../../backend/app/api/routers/publication.py)、[backend/sql/schema.sql](../../backend/sql/schema.sql)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

越权、凭据外泄、身份误去重、停止后请求均阻止验收；备份不等于可恢复。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可按本文件执行。

## 访问与安全

- 公开页面（首页、`/discover`、`/discover/stories`、`/items`、`/leaderboard`、公开日报/周报/月报）不需要登录；个人事件 `/events`、其他个人页面和管理页面需要会话，并设置 `noindex`。
- 每个请求生成独立的 CSP nonce（`src/proxy.ts`）；需要交互的 HTML 按请求渲染，不使用共享缓存。
- 生产环境 CSP 的 `style-src` 只放行 nonce 与哈希，服务端渲染出的 `style` 属性会被丢弃：组件不得依赖 `style` 设置布局或 CSS 变量，静态值写成类名（如 `site-sidebar-width`），动态值在客户端经 CSSOM 设置；图表等依赖内联样式的第三方组件只在客户端渲染。开发环境放行 `unsafe-inline`，这类问题只会在生产构建中暴露，由 `tests/layout/csp-inline-style.test.tsx` 把关。
- 交互元素可以用键盘访问；装饰图形加 `aria-hidden`；状态区域有语义名称。
- 每次改动 UI，都要在桌面和 390px 宽的窄屏下分别用浏览器检查。
