# 模型联网检索与线索采集设计

日期：2026-09-17。proposed；依据 [调研](../research/045-模型联网检索与线索采集调研.md)、[PRD](../prd/045-模型联网检索与线索采集.md)。官方资料确认存在模型联网工具；尚无真实联网调用和已验证长期零付费组合。

## 1. 接入方案与边界

定义 `model_web_retrieval` 来源类别，以 OpenRouter 或 Vercel 的受控搜索工具获得线索。直接采集仍走 005/006/008；044 为公开平台资料；045 用于补充发现与背景材料。搜索摘要不能变成伪造的完整作品、评论树或账号时间线。

采用明确模型/API/引擎的薄适配器，复用成熟官方协议。暂不引入无限 Agent 循环、第二后端、独立搜索平台或付费第三方兜底。043 的普通分析用途仍不允许工具；045 单独配置只读检索用途，授权不能被正文改变。

## 2. 责任与依赖方向

| 拟建/拟改模块 | 责任 |
|---|---|
| monitors | 主题检索设置、网关/引擎候选、外发范围、定时启停；不持有模型秘密本体 |
| analysis 的 043 配置服务 | 解析只读检索用途版本、连接/秘密引用和能力/费用策略，提供 DTO；不负责线索采集水位 |
| ai/contracts、ai/adapters | 标准化网关搜索协议、工具事件与使用量；纯适配，无业务授权或事务 |
| sources/adapters/model_search/ | 将受控检索结果转换为来源线索；只消费协议 DTO，不访问 ORM/Worker；与 ai 的允许依赖在架构门禁登记 |
| jobs | 持久运行、原子预算、搜索步骤限额、取消、租约和对账，禁止另建模型队列 |
| content / evidence / events | 检索线索及分层证据、已取原文、人工关联及版本；不复制成独立知识库 |
| api/routers/model_search.py；frontend/src/app/features/discovery/ | 独立检索入口、费用/范围预览、任务状态、结果/引用及事件关联 |

编排服务先获得当前权限及 043 的配置 DTO，再受理任务；Worker 派发前复核策略。跨领域原子写明确共享 Session，通过所属服务完成。S00 冻结现有领域职责，不因本设计先铺空模块。

## 3. 数据与能力矩阵

SearchProfileVersion：query/range、网关/模型/API/tool/engine、允许域名/日期/账号、最大步数/结果/耗时、费用有效期、外发规则、配置版本。模型推理配置与搜索配置分别版本化并关联。

SearchRun/Attempt：持久任务、实际查询摘要及受控证据引用、模型和引擎、provider request ID、真实工具调用、请求/返回时间、usage/cost、结果状态。每一步计量，未返回的实际引擎/使用量保持 unknown。

SearchHit：URL/原生 ID（仅返回可验证时）、标题、snippet、rank、provider_published_at、retrieved_at、retrieval_evidence_ref、正文获取状态；GeneratedSynthesis 单独保存，引用指向 hit 或已有证据，不能覆盖原文。

按模型＋API＋引擎记录域名/日期/账号过滤、引用格式、强制搜索/搜索证据、调用硬上限与费用回传的声明/实测/不支持状态。不兼容参数不能悄悄删掉，必须拒绝或让用户明确选择范围更小的受支持配置。

## 4. 执行与费用准入

1. 用户选择检索主题和范围，查看最小必要外发信息；保存或预览不调用模型。
2. 核对推理、搜索、额外结果、媒体和附加项的全部费用与数据政策；沿用 043 当前仅 local/已核查 zero_price 可执行的规则，不能因工具免费忽略模型费用。
3. 固定引擎和上游，不使用未验证 auto 或收费 fallback；活动零价保存截止及来源。截止时间未知采用提前停止，不把“9 月 30 日结束”自行解释为最晚时区。
4. 原子预留本地请求/步骤/资源上限；用供应商确实支持的硬上限限制网关内部步骤。只有参数实际生效才可启用；仅输出后检查次数不足以证明无超限。
5. 执行白名单只读搜索。模型返回 0 次搜索时标 `no_search_evidence`，不能以流畅回答当采集成功；原生工具内部计量不可观测或不可约束则该组合不准入。
6. 落库命中和搜索证据，再按权限、安全、预算补原文与关联事件。模型生成文本只是辅助归纳，缺引用不能作为事实入库。

如均为收费组合，只开放配置与不可用原因，不发起真实调用。限时活动不能承担长期免费 SLA；活动结束关闭该路线，044/直接爬虫/人工路径继续可用。

## 5. API、界面与来源补采

候选接口 GET `/api/model-search-capabilities`，POST `/api/model-search-runs`（202、幂等），GET `/api/model-search-runs/{id}`，POST cancel；结果分页及加入事件复用内容/事件服务。FastAPI/Pydantic 唯一契约并生成客户端，不在 Next 服务端直接持有模型 Key 调用另一套业务逻辑。

入口名“联网检索补充”，显示查询范围、组合、费用资格、最大搜索次数和有效期。结果卡分“搜索摘录”“原文已获取/尚未获取”“模型归纳”；时间未知明确显示，排名是搜索结果顺序，不是平台热度。

用户从 X 引用请求评论时，按 004 的来源能力检查后交给 008 的独立任务，未取得能力显示不支持/未连接。只有检索到账号某些帖子不能把 006 的持续完整作品追踪标成功。

## 6. 安全、失败与可观测性

关键词、账号过滤和时间范围本身也是外发资料；不得仅因没有正文而跳过授权。服务和当前主题范围显式启用后，后续按同一规则运行，无需每次重复询问。模型和网页指令不能追加工具、读密钥、登录或发帖。

工具返回引用也视为不可信 URL，补抓前检查协议、域名/IP、DNS、跳转、体积和 Content-Type；防止内网与元数据探测。HTML 不执行脚本。日志保留关联 ID 和状态，不记录正文、原始查询或秘密。

流中错误、部分引用、结构错误、预算停止、活动到期、取消和结果未知分别记录。未知是否执行的请求不自动重发；本地幂等只保证业务结果唯一，不保证远端无重复计费。取消停止新步骤，在途请求尽力停止并留账。

指标：有搜索证据的运行比例、引用可达/相关率、去重率、实际工具次数、费用未知比例和部分原因。来源引用可核查率由独立人工样本评估；不采用模型自评分作为唯一依据。

## 7. 迁移、回退与验证

只添加兼容的检索配置/运行及线索类型，复用原有来源证据。先以受控工具完成边界，再对满足零付费条件的组合做小样本真验证；账户条件不符保留未验证，不宣称全部网关接入。

回退先暂停新步骤和定时任务、对账在途，再退回兼容配置/程序；保留已确认资料及人工关联，不删除使用量记录。OPEN-045-001/RSK-045-001 以 PRD 为准。

验收 AC-045-001—006，覆盖组合不支持、零价模型＋收费工具、促销到期、参数被忽略、提示注入、危险引用、无搜索证据、X 评论边界、取消与未知消耗。真实联网证据与公开资料调研、mock 回归分别记录。
