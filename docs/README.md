## 4. 编号与格式

- 格式仍按 [TEMPLATE.md](TEMPLATE.md)。v2.0 新增的需求、决策、未决项在 001 下使用 `-101` 起的编号（如 `FR-001-101`、`DEC-001-201`），与 v1.x 的旧编号区分，旧编号不再复用。
- 新文档只在确有必要时新建（例如独立的平台接入调研），从 **048** 起编号。
- 阶段验收记录放 `acceptance/`，文件名 `001-P1-主链路验收.md` 这类格式。
