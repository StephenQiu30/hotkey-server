# Plan 030：报告与原始数据导出

## 范围与需求

导出尚未实现。本卡按 [PRD 007](../prd/007-扩展能力需求.md) `FR-007-001`、`NFR-001-101/107` 和 `AC-007-004`，分别导出已存档报告 Markdown/PDF 与有权限的原始数据 CSV/JSON。依赖 M4 真实报告与可访问数据；导出不作为报告生成或信息获取完成证据。预计涉及导出服务、权限 API/页面、格式转换、测试与必要任务状态；开工分清报告和数据事务/读取边界。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-030-API-001` | owner 按报告版本或获准数据范围请求导出；权限不足、无数据、格式失败、取消有稳定状态和错误响应。 |
| `SPEC-030-DATA-001` | Markdown/PDF 保留报告版本、时间窗、引用和覆盖说明；CSV/JSON 有稳定字段、时间与分页口径，按权限脱敏。 |
| `SPEC-030-SEC-001` | 不把凭据、浏览器资料或无权限正文写入导出物、日志和临时目录；下载范围按 owner 隔离。 |
| `SPEC-030-OPS-001` | 导出失败或取消不修改已存档报告和原始采集事实；临时文件有受控清理与可定位错误。 |

## 验收与 Checklist

Given：真实已存档报告和有权限的原始数据。When：分别导出四种格式，并制造越权、失败和取消。Then：版本、引用、字段脱敏与错误状态可核对；失败不回滚来源或报告。

- [ ] `CHK-030-G0-001`：核对 046 S03、PRD/Design、M4 报告版本和数据权限。
- [ ] `CHK-030-G1-001`：冻结四项 SPEC 的格式、字段、权限、临时文件与错误契约。
- [ ] `CHK-030-G2-001`：受控验证越权、超大结果、失败、取消、空数据和脱敏。
- [ ] `CHK-030-G3-001`：实现导出与页面/任务，API 变化同批更新生成客户端。
- [ ] `CHK-030-G4-001`：运行后端、前端、OpenAPI、真实 PostgreSQL 与浏览器门禁。
- [ ] `CHK-030-G5-001`：分别保存真实报告 Markdown/PDF、原始数据 CSV/JSON 及版本/字段证据。
- [ ] `CHK-030-G6-001`：按 `AC-007-004` 分格式、权限和失败状态给产品结论。

失败时停止本次导出并清理本次临时文件，保留报告与采集数据；不以空文件或格式扩展名证明导出成功。
