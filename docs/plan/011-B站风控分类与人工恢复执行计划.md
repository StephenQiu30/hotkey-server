# Plan 011：B 站风控分类与人工恢复

## 范围与需求

当前离线回放存在未知非零退出误归 `authentication_required` 的风险。本卡依据 [PRD 003](../prd/003-本人账号B站试点需求.md) `FR-003-002`、`NFR-003-001` 和 `AC-003-002/003`，区分验证码/滑块、登录失效、访问频繁与普通进程错误；显式停用并由本人检查后人工恢复。依赖 Plan 002 的节奏/预算与 Plan 010 的版本校验。预计复核 `connections/`、MediaCrawler 适配器、Worker 子进程监督、API/CLI、前端状态及 tests；精确路径开工登记。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-011-JOB-001` | 验证、登录失效或访问频繁即终止对应进程组、停用来源和后续调度；排队 Job 不自动受理，未确认窗口保留缺口。 |
| `SPEC-011-DATA-001` | 风控、限流、普通非零退出、协议/文件错误使用独立稳定状态与原因，unknown 不默认当认证失败。 |
| `SPEC-011-SEC-001` | 不破解、不换号、不绕过、不自动恢复；只有 owner 本人核查后才可通过显式入口恢复，操作有版本、时间和审计。 |
| `SPEC-011-UI-001` | Web/CLI 显示停用原因、待本人处理和恢复结果；无权限与重复恢复有明确响应。 |

## 验收与 Checklist

Given：固定补丁、独立 CDP 资料、来源开关和预算可核对。When：分别模拟验证码、滑块、登录失效、访问频繁及普通进程错误，再由本人显式恢复。Then：前四类立即停止且不自动重启；普通错误不误分类；恢复后仍需低频真实复验。

- [ ] `CHK-011-G0-001`：核对 046 S03、PRD/Design、Plan 002/010 及当前错误分类证据。
- [ ] `CHK-011-G1-001`：冻结四项 SPEC 的停用状态、进程截止、权限和审计契约。
- [ ] `CHK-011-G2-001`：保存五类错误、取消超时、重复恢复和无权限恢复的失败先行测试。
- [ ] `CHK-011-G3-001`：逐规格修复状态、进程回收和显式恢复入口。
- [ ] `CHK-011-G4-001`：运行 Ruff/mypy/pytest、真实 PostgreSQL/Kafka、API 契约和适用浏览器验证。
- [ ] `CHK-011-G5-001`：本人检查后低频恢复并记录来源状态、Job 和预算，真实风控信号不得为测试制造。
- [ ] `CHK-011-G6-001`：核对 `AC-003-002/003`，保留未完成的连续三天与 Plan 013 条件。

触发真实风控时立即停用并停止本轮取证，由本人核查；保留状态和缺口，不自动继续。凭据、Cookie 和 CDP 资料不得写入证据附件。
