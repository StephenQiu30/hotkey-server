# Plan 057：通用网页与浏览器采集底座回归

## 状态、边界与验收

承接 NFR-001-107/110 的共享技术回归 `TECH-001-057`；当前公开网页 `webpage.collect`、Firecrawl适配、Browser运行时与两个probe命令已有代码及历史受控验证，但通用Browser业务处理器未接Worker，G4-002凭据隔离/换版旧写端到端验证待做。当前M1只推进四关键词来源和六个公开热榜，本卡冻结在blocked，不作M1前置或平台接入声明。恢复实施需用户决定通用Browser的目标来源与授权、出口白名单/计量、是否启用业务处理器及运行预算；若仍不推进，保留代码维护与禁用状态。probe仅诊断运行基础，不算采集成功。
