| SPEC-014-DATA-004 | 模型调用在数据库事务外；确认写入时锁候选和相关事件、再次检查内容归属及人工revision；冲突保留待重算，不能覆盖人工决定。重复消息返回已保存结果，不生成第二事件。首次出现取成员实际发布时间，否则首次发现并标时间依据；平台分布按真实source去重，代表评论保留原ID。 |

## 范围与需求

`events`尚未落地；本卡承接 [PRD 004](../prd/004-事件与热度需求.md) FR-004-001的候选、模型确认、身份和幂等，贡献AC-004-001。设计和技术实施按本文具体合同；真实三平台样本须M1验收，B站仅M2通过后纳入。015/016/042分别负责人工修订、热度与页面。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-014-DATA-001` | 候选内容身份、来源与时间窗可回溯；相似度或 `pg_trgm` 命中只是候选，不能自动等同事件成立。 |
| `SPEC-014-DATA-002` | 事件有稳定 ID、成员版本、标题、摘要、首次出现时间、平台分布和代表帖/评论引用；同内容重复归并不重复成员。 |
| `SPEC-014-JOB-001` | Codex模型确认的输入、版本及结果可审计；确定性规则只产生候选，消息重放与并发写入按本卡事务边界幂等。 |
