# Plan 028：指定账号追踪

## 范围与需求

本卡按 [PRD 007](../prd/007-扩展能力需求.md) `FR-007-003`、`NFR-001-107/111` 和 `AC-007-002`，跟踪本人已授权作者的新帖，且不受主题关键词过滤。每个来源能力须经 Plan 029 的准入；B 站试点不自动开放其他平台。授权账号和真实来源未确定前只做契约与受控准备。预计涉及账号身份/授权、来源适配、任务/内容、覆盖查询、API/Web 和 tests；开工定精确文件。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-028-SEC-001` | 每账号保存本人授权范围、来源能力、有效期、操作人与预算；未授权或未准入来源不得受理追踪。 |
| `SPEC-028-DATA-001` | 作者新帖按来源原生 ID 逐条收录，独立于主题关键词；发布时间/发现时间分离，去重与分页尾段可核。 |
| `SPEC-028-OBS-001` | 逐账号/来源显示请求页、限流、权限、失败、入库/去重和未确认缺口，不把实际空结果当完整历史覆盖。 |

## 验收与 Checklist

Given：本人授权账号且目标来源能力已准入。When：运行新帖追踪和分页/权限故障。Then：新帖不受关键词过滤并逐条持久，缺口按来源可见；其他来源结果不代替本来源。

- [ ] `CHK-028-G0-001`：核对 046 S03、PRD/Design、本人授权和 Plan 029 准入。
- [ ] `CHK-028-G1-001`：冻结三项 SPEC 的身份、授权、分页与预算契约。
- [ ] `CHK-028-G2-001`：受控验证授权不足、关键词绕过、重复帖、分页和限流。
- [ ] `CHK-028-G3-001`：实现逐账号追踪和覆盖查询，API 变化同步客户端。
- [ ] `CHK-028-G4-001`：运行后端、前端、OpenAPI、真实数据库与浏览器门禁。
- [ ] `CHK-028-G5-001`：每个获准来源记录真实作者新帖、分页与缺口。
- [ ] `CHK-028-G6-001`：按来源能力分别判断 `AC-007-002`，不并算未准入来源。

授权撤销或风控时停用该账号任务，保留已采内容与缺口，不自动切换其他账号。
