# Plan 018：日报生成、降级与存档

报告时间唯一读取现有 `monitor_topics.report_time` 与 `report_timezone`；043只负责在这些字段上调度和冻结。本卡消费其固定manifest并生成日报，不创建或写入第二份报告设置。

## 数据、接口与完整阅读交付

修改 `backend/app/reports/services.py`、`schemas.py`、`render.py`、`prompts.py`、`models.py`；消费043冻结manifest，复用现有reports表，程序产概览/前日对比、Top10、风险/代表观点、各来源覆盖与缺口、按发现时间计数及“样本观察，不代表全网”。对比日缺少存档或窗口不完整时显示不可比较及原因。模型只返回带[cN]引用的句子，数字从结构化结果插入；无效引用句删除，正文不足或调用失败用模板并保留降级原因。

当前 `backend/app/api/routers/reports.py` 是 `/v1/reports`，本卡将其规范为 `/reports`（统一挂载后 `/api/reports`），同步全部生成客户端与前端，现阶段不保留第二套兼容路由。GET列表按topic/kind/window/游标，详情按report_id固定不可变版本；`generator`、coverage、input_manifest摘要与原帖引用可查。修改 `frontend/src/app/reports/components/report-list.tsx`、`[reportId]/components/report-detail.tsx`、`report-markdown.tsx` 展示版本、生成方式、缺口和引用，不加载外部HTML脚本。

日报完成后只是final存档；Obsidian和推送由各自调度扫描，不在日报事务内写vault或发消息。同窗重生成沿用043最终清单，version原子递增；失败不删除旧final。保留库DDL先051。

- [ ] CHK-018-101 → DATA/JOB：扩展 `backend/tests/unit/test_daily_reports.py`、`test_report_queries.py`，新增 `backend/tests/integration/test_reports.py`：冻结后迟到数据、发现时间、同文多主题、空样本、前日缺报、并发重生成、模型乱填引用/数字、09:10水位到限与15分钟目标。
- [ ] CHK-018-102 → API/UI：`backend/tests/integration/test_http_contract.py`及报告前端新增测试，确认旧/v1路径移除、新路径/生成物一致、owner权限与模板/缺口渲染。
- [ ] CHK-018-103 → AC-005-002/005/007：连续3自然日存档，至少10条原帖引用与程序数字核对，分别模拟来源不可用和Codex不可用仍生成明确降级报告；记录实际final_at−scheduled_at≤15分钟。Obsidian/推送不参与此结论。

运行B/C/F门禁；证据写M4 Acceptance Plan018。不能只验渲染函数或任务创建；用户须能在Web打开对应真实存档版本。

## 范围与需求

日报已有代码，连续真实存档与Web读取未验。本卡承接 [PRD 005](../prd/005-报告与知识库需求.md) FR-005-003/004、NFR-005-001和AC-005-002/005/007；配置FR-005-001由043交付。按本文确定路径实施，使用017分析状态和004覆盖DTO；真实取证仅用已验收来源，事件待M3，vault/渠道分别后验。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-018-DATA-001` | 按主题和自然日冻结输入；数字、排序、引用由程序计算，模型只润色；存档版本、覆盖说明和十条原帖引用可追溯。 |
| `SPEC-018-JOB-001` | 默认 09:00 Asia/Shanghai 生成，目标设定时间后 15 分钟内完成存档；重复调度不重复报告。 |
| `SPEC-018-JOB-002` | 来源或 Codex 停用时仍用已知输入存档，明确缺口或模板版；vault/渠道故障不回滚报告。 |
| `SPEC-018-UI-001` | Web 可读取指定报告版本并区分正常、模板、缺口、加载、空、失败和权限不足。 |

## 验收与 Checklist

Given：M1/M2 真实资料可核对。When：连续三个自然日按配置生成、存档并在 Web 读取，另停用一个来源或 Codex。Then：三份报告可复算数字并打开十条原帖，降级版明确缺口，生成与 vault/推送相互独立。
