# Plan 048：小红书来源准入

FR-007-004、NFR-001-107/110、AC-007-003。当前仅B站本人账号试点有已定路径，小红书未授权启用、未确认固定实现/许可/分页。本卡是独立研究交付，不能提前声明适配器可实施。

| SPEC | 交付 |
|---|---|
| SPEC-048-SEC-001 | Design007登记官方/候选组件能力与固定源码提交、许可用途、本人授权和独立资料边界；记录频次、请求/条数/并发、停止/恢复责任，不能直接复制B站参数。验证码、失效、频繁访问立即停用，不自动恢复。 |
| SPEC-048-DATA-001 | 分别核对搜索帖子、一级评论、回复的原生ID、父链、游标和可见范围；用源码及获准样本识别无尾段、登录限制、删除和部分结果。每种能力明确支持或不支持，不用“全量”描述替代证据。 |
| SPEC-048-OPS-001 | 定义 HotKey 适配边界、独立资料/子进程或官方API入口及资源成本，方案影响部署时由用户决定；获准后新增对应能力Plan，目录落在 `sources/adapters/`，持久化复用content/jobs。准入阶段不新增运行模块。 |

- [ ] CHK-048-001 → SEC-001：固定资料来源日期/版本和本人授权，缺失继续blocked。
- [ ] CHK-048-002 → DATA-001：形成搜索/评论/回复能力矩阵及分页、错误、预算样例，不复用B站离线回放。
- [ ] CHK-048-003 → OPS-001：获准方案和独立实施Plan具备SPEC、状态机、文件/测试与低频真实验收标准；产品AC留给实现验收。

用户负责账号/启用和影响部署的决定，实施者负责调研。产物归M6研究证据；未满足条件不触发平台请求或自动登录。
