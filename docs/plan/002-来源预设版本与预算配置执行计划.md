## 文件与SPEC

| ID | 具体实现 |
|---|---|
| SPEC-002-DATA-001 | 修改 `backend/app/connections/presets.py`、`schemas.py`、`services.py`，定义SourceExecutionPolicy：min_interval_seconds、quiet_windows(timezone/start/end)、max_queries、max_items_per_query、max_requests、max_seconds、hard_timeout_seconds、max_concurrency、enabled。拒绝负/零上限、未知字段和max_seconds>hard_timeout；config只存非秘密。 |
| SPEC-002-DATA-002 | `SourcePresetService.apply_in_transaction` 同事务写连接版本、准入、保留、组件和预算策略；相同配置幂等、变化升版本。按指定connection_version读取策略DTO；Job在受理时固定版本，领取时再检查当前安全停用。换版不改变已受理Job输入，也不解除安全停用。 |
| SPEC-002-JOB-001 | B站策略迁入预设：6小时、Asia/Shanghai 00:00—08:00、3词、5条/词、26请求/词、日60请求、任务220秒/进程240秒、并发1。四关键词来源保持当前声明预算值并固定测试快照；六榜独立间隔默认1800秒且可配置，M1窗口按008/009冻结。调度消费在031实现，不在这里复制算法。 |
| SPEC-002-SEC-001 | `jobs/services.py` 的预算窗口键按owner/source/metric/time_window，不含可换版连接ID；升版不返还已用日/月额度。预设失败整体回滚，不能出现连接已启用但无预算策略。秘密引用走既有服务端配置白名单。 |

现有 `PUT /api/source-connections/{source_key}` 与CLI preset apply沿用版本/权限合同；如果返回策略DTO变化，同改 `api/routers/source_connections.py` 并由运行OpenAPI生成 `frontend/src/api/`。不为本卡建新的配置服务。若需要schema字段，同步 `connections/models.py`、`backend/database/schema.sql`，保留库先051。
