# Plan 027：突发告警

## 规则、计算与投递契约

新增 `backend/app/notifications/alerts.py`、`api/routers/alerts.py`，扩展notifications models/schemas、schema、Worker/调度和API注册。规则归notifications领域，通过analysis/events只读DTO取数；不得直接读写其他领域ORM。新增 `notification_alert_rules`（owner/topic、type=negative_count或event_heat_delta、threshold、cooldown_seconds、target_id、enabled、revision）与 `notification_alert_occurrences`（rule_revision、subject_id、window_end、input_manifest、value、state、delivery_id）。启用必须给正阈值和冷却时长，默认关闭，不虚构产品阈值。

每5分钟评估最近完整一小时 `[now-1h,now)`，负面数只计有效相关且情感negative的内容版本，事件热度增量仅用同formula/revision可比快照；达到配置阈值且过冷却才创建occurrence。按rule+subject锁最新触发记录，重复扫同窗幂等，重启不丢冷却；跨连续窗口不在冷却内重复发。未知投递仍占用冷却，不因未确认重发。数据不足/未成熟/无可比热度标insufficient，不产生告警。

扩展024投递负载为 `subject_type/subject_id/subject_version`，报告与告警各自唯一；不能伪造report_id容纳告警，DDL须保留既有报告唯一约束与外键语义。GET/POST `/api/alert-rules`、PATCH `/{id}`、GET `/api/alert-occurrences` 分别list/create/update规则与查历史，owner/CSRF/revision。新增 `frontend/src/app/alerts/page.tsx`、`components/alert-rules.tsx`、`alert-history.tsx`，显示值/窗口/抑制原因/投递结果。

- [ ] CHK-027-101 → DATA/JOB：新增 `backend/tests/unit/test_alerts.py` 与 `backend/tests/integration/test_alerts.py`，覆盖threshold−1/=threshold、跨小时边界、相同主体连续窗、冷却到期、公式变更、负面标注invalid、并发受理/重放。
- [ ] CHK-027-102 → API/UI：新增规则/历史前端测试，验证禁用默认、无阈值不启用、无渠道409、owner、版本冲突和持久unknown。
- [ ] CHK-027-103 → AC-007-001：至少一个获准且已验收的025/026渠道，使用真实输入和用户配置阈值核对触发、冷却、接收方实际收到及未重复；不得向未批准目标试发。

运行B/C/F，证据归M6 Acceptance Plan027。负面内容规则可独立于事件启用，但事件规则必须等M3；依赖表表示全部本卡功能的技术前置，真实渠道是单独启用门槛。

## 范围与需求

按 [PRD 007](../prd/007-扩展能力需求.md) FR-007-002、NFR-001-104/106和AC-007-001，交付一小时阈值/冷却规则、评估与投递。技术路径、接口和并发锁按本文固定；真实验证需已验负面内容或M3事件输入，以及至少一个已验M5渠道。

## 验收与 Checklist

Given：真实已验收事件/内容与渠道可用。When：跨阈值、重复触发和冷却后再触发。Then：每个事件窗口仅按规则发送，冷却和结果可复查。

- [ ] `CHK-027-G0-001`：核对 046 S03、PRD/Design、M3/M5 产品证据与文件边界。
- [ ] `CHK-027-G1-001`：冻结三项 SPEC 的阈值、窗口、冷却与状态。
- [ ] `CHK-027-G2-001`：受控验证阈值边界、重复、冷却、消息重放和渠道失败。
- [ ] `CHK-027-G3-001`：实现规则、持久冷却、任务与显示。
- [ ] `CHK-027-G4-001`：运行后端、前端、OpenAPI、真实 PostgreSQL/Kafka 与浏览器门禁。
- [ ] `CHK-027-G5-001`：用真实事件和已启用渠道保存告警发送与接收证据。
- [ ] `CHK-027-G6-001`：按 `AC-007-001` 独立判定告警，不借报告送达结果。

失败时停用告警规则、保留阈值窗口和投递身份；不得返还已用预算或删除冷却历史。
