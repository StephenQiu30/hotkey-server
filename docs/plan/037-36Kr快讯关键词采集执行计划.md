# Plan 037：36Kr 快讯关键词采集

交付 `rss_36kr` 经本机 RSSHub `/36kr/newsflashes` 按主题过滤的真实链路。它与 `hotlist_36kr` 的 `/36kr/hot-list` 分别计量。FR-002-003、AC-002-002/004；NFR-001-101/102/105/111。

| SPEC | 实施契约 |
|---|---|
| SPEC-037-DATA-001 | 修改 `backend/app/sources/adapters/rss.py`、`connections/presets.py`：入口仅本机 `127.0.0.1:1200/36kr/newsflashes`；guid/原文 URL 为稳定身份，保留真实发布时间、首次发现、标题/摘要/作者的缺失状态。source_key 不与热榜混用。 |
| SPEC-037-JOB-001 | `content/discovery.py` 复用 `evaluate_monitor_rules` 对 Feed 标题/摘要作任一、全部、排除规则；英文整词、中文子串口径与预览相同。不匹配不建主题发现，重复命中只补观察。Feed 头部不证明 24 小时全量覆盖，缓存更新时间与本次请求时间分开。 |
| SPEC-037-OBS-001 | `content/discovery_execution.py` 保留 RSSHub 网络/解析/缓存结果与窗口缺口；合法空 Feed、无主题命中、来源失败三种状态可区分；请求与计数进入 033 DTO。 |

- [ ] CHK-037-001 → DATA-001/JOB-001：扩展 `backend/tests/unit/test_feed_adapters.py`，证明 AI 不命中 daily、排除词优先、同文多词不重复、无时间不丢弃。
- [ ] CHK-037-002 → OBS-001：扩展 `backend/tests/integration/test_keyword_discovery.py`，证明重复 RSS、失败恢复、无匹配和合法空分别对账，快讯和热榜身份/预算互不覆盖。
- [ ] CHK-037-003 → AC-002-002/004：真实快讯原帖、规则命中、请求入口、时间依据和两次扫描去重逐项核对；没有合格命中保留待验收。
