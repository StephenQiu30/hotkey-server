# 热点舆情监控平台总计划

本计划管理跨里程碑顺序、依赖与历史追溯。现行任务和验收映射在 002—007 里程碑 Plan。状态：**文档修订完成，实现暂停，待用户确认恢复**。现行依据为 [PRD 001 v5.0](../prd/001-热点舆情监控平台需求.md)、[Design 001 v4.0](../design/001-热点舆情监控平台总体设计.md) 及各里程碑 PRD；本版只整理文档，不宣称新增实现或产品验收。

## 1. 分工与证据

- Codex：按对应里程碑 TASK 实现，先验证失败，做单元/架构自检并写明文件、验证结果与限制。
- Claude：规划审查、代码审查、真实库全量测试、真实运行验证与独立证据；仅在用户明确授权后提交和推送。
- 用户：本人账号登录与风控核查、授权、费用/来源/渠道及产品排期决策。

证据等级依次为代码、受控测试、真实运行、产品验收。局部开发库运行、离线回放、接口 200、健康检查和推送代码均不能推出对应产品 AC 已通过。阶段验收按里程碑计划写 `docs/acceptance/`，记录版本、环境、库、时间窗、查询、缺口和人工核对结果。046 S03 公共门禁已由 旧 Acceptance 046 全局异常与响应契约验收（已删除，见 Git 历史） 证明通过（含 AC-046-006 真实本地上游验证）；后续实现沿用该契约。
