# Plan 024：投递身份与未知状态

## 范围与需求

飞书已有局部代码/受控证据，结果 unknown 的完整人工流程未证。按 [PRD 006](../prd/006-推送需求.md) `FR-006-002`、`NFR-001-101/104` 和 `AC-006-001`，本卡先定义跨渠道投递身份、Outbox、unknown 和人工确认；SMTP 与飞书真实送达分别在 Plan 025/026。M4 报告须已定稿，渠道仍须各自获准启用。预计修改 `notifications/`、Outbox/Worker、权限 API/页面及 tests，开工列确切路径。

## SPEC

| ID | 规格 |
|---|---|
| `SPEC-024-DATA-001` | 同报告版本、渠道和接收方唯一投递身份；业务状态与 Outbox 同事务提交，消息重放不重复创建投递。 |
| `SPEC-024-JOB-001` | 发送结果不确定记 unknown 并停止自动重发；确认前不把超时当失败或成功，人工确认后按明确结果推进。 |
| `SPEC-024-SEC-001` | 只有 owner 可查看/确认 unknown；接收方和操作人审计可查，不在日志或客户端暴露凭据。 |
