# 08 平台接入

需求编号：`REQ-08`。本文定义需求，不表示已实现或验收通过；进度只在BACKLOG。

## 用户任务

区分关键词搜索、标签/账号、热榜与模型辅助研究的能力和接入条件。

## 功能与约束

| 平台/服务 | 当前决策 | 进入实施的条件 |
|---|---|---|
| B 站、Hacker News | 首个闭环的现有路径候选，不代表已验证可用 | 确认主题、语言、账号/授权、样本窗口与来源能力后真实验收 |
| X | 海外关键词目标；当前不启用官方收费 API，公开趋势不等于站内关键词检索 | 官方路径需要用户另行调整费用边界并给出预算；本人账号有限试点按现有规则单独确认，不承诺全量或长期稳定 |
| Instagram | 海外目标，本期仍不实施接入；区分标签/账号监测与任意正文关键词 | 确认标签/账号是否满足需求、账号与权限准入，并明确解冻范围；不能承诺官方未提供的全文搜索 |
| OpenRouter | 模型与辅助搜索候选，本期运行模型仍用本机 Codex | 云端模型、收费搜索及数据处理范围须另行确认；模型搜索不能替代可核查的采集覆盖 |
| Reddit、YouTube、Bluesky | 补充候选，不自动列入必做平台 | 各自通过范围、准入、费用和能力审查；Reddit 获官方批准前不请求 |
| RSS、热榜、新闻搜索与公开网页 | 背景材料和交叉证据补充，标明发现方式 | 逐来源核对准入；热榜过滤和搜索引擎索引不作为社媒站内关键词覆盖证明 |

平台依据与开源候选见 [调研](../prd/02-关键词热点监测调研.md)。现行范围以本文为准；调研中的价格和权限是核查时证据，实际接入前需重新核对。未决的平台或预算不阻止已准入来源的核心建设，但不能据此启用受限请求。

### 可复用能力与缺口

| 目标 | 可复用入口 | 缺口 |
|---|---|---|
| X 目标 | [离线适配器](../../backend/app/sources/adapters/x_api.py)、[编辑来源工厂](../../backend/app/sources/editorial_factory.py) | 前者强制 MockTransport，后者在业务零费用入口拒绝收费来源；平台准入和费用决策未完成前不算可用 |

## 验收标准

X/Instagram是目标，B站/HN不能替代其验收；OpenRouter是模型服务；搜索、评论、回复、增量、费用和准入分别核对，目录/离线适配器不是可用证明。
