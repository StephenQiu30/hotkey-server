# 32 监控主题工作区

需求编号：`REQ-32`。路由：`/topics`。本文件定义需求，不表示实现或验收通过；进度只在BACKLOG。

## 用户任务

在同一屏理解主题关键词、采集平台、命中变化和告警，并进入必要设置。

## 功能与约束

| 区域/操作 | 必需字段 | 数量与范围 | 业务约束与待补项 |
|---|---|---|---|
| 主题列表 | id/name/status、频率、搜索/新建 | 20条/页，全宽列表位于当前主题详情上方 | 复用monitor_topics；已归档通过次级筛选查看 |
| 标题/关键词 | name、status、interval、match_any/match_all/exclude | 选中1主题 | 标题与关键词直接展示；不是四页签默认结果页 |
| 每小时命中 | hour、new_items、coverage、snapshot_at | 24小时桶 | 当前接口缺失；最近5条结果不是小时总量 |
| 采集平台 | key/name、支持能力、准入、选中、最近成功/条数 | 原稿8行；实际以来源目录为准 | 开关进入草稿设置并明确保存；不可用来源不能伪装启用 |
| 告警规则 | rule_id/阈值/window/channel、enabled | 当前主题规则 | 复用规则与版本；其他主题不得混入 |
| 最近告警 | evaluation_id、事件/时间/状态、read_at | 最近可读历史，按规则最多50 | 评估历史按需读取；已读操作无合同，禁用而不假写 |
| 次级操作 | 结果、采集运行、编辑设置 | 展开区保持草稿和运行回执 | 已有预览/版本冲突/幂等运行/恢复链保留 |

### 页面行为

移除默认“结果/采集/告警/设置”四页签；主视图连续展示原稿区域，结果与编辑作为次级展开区，兼容旧tab深链接。命中统计、已读与平台成功摘要是服务待补项。

### 已确认的数量与操作约束

全宽主题列表位于详情上方，连续关键词/小时命中/采集平台/规则/最近告警；结果、运行和设置次级展开，保留草稿和幂等

## 验收标准

- 字段、数量与操作按上述要求核对；未知、未分析、失败与真实零值分开，统计注明来源、窗口与版本。
- 读取不启动采集、模型或通知，写操作显式触发；失败保留输入，冲突先重读，未知结果先核对。
- 公开读取执行当前许可，个人数据按会话owner隔离。
- 1440px/390px覆盖正常、空、加载、错误、无权限和键盘；静态说明无远程数据的状态明确不适用，不编造样本。
- 全宽主题列表位于详情上方，桌面和手机默认展开并可收起；只改变主题工作区，其他页面保持各自布局。active表示定时启用，不表示执行中。
