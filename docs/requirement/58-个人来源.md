# 58 个人来源

需求编号：`REQ-58`。本文定义需求，不表示已实现或验收通过；进度只在BACKLOG。

## 用户任务

维护本人RSS、网页或JSON来源，独立控制采集与公开许可。

## 功能与约束

路由：`/sources/personal`。保存、编辑、启停为显式操作，新建默认关闭，owner来自会话。站点与个人来源分开，不因本人也是发布账号而自动公开。逐来源说明搜索、详情与发现方式，不因URL存在认定可采。

## 验收标准

保存不采集；他人不能读写连接/材料；启用受准入和预算约束，版本冲突保留草稿；原文、覆盖与job可追溯。
