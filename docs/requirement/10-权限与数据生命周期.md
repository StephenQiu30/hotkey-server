# 10 权限与数据生命周期

需求编号：`REQ-10`。本文定义需求，不表示实现或验收通过；进度只在 BACKLOG。

## 用户任务

公开阅读与个人监测权限清楚，撤回、删除和失败均可解释且不泄漏资料。

## 功能与约束

- 公共阅读免登录，个人设置和结果按会话 owner 隔离；站点与个人来源分开，公开读取执行当前许可。
- 另一账户替换 ID、cursor、导出或附件 URL，不能读到标题、正文、计数或附件；撤权清理个人视图，不回退旧修订绕过撤回。源删除同步处理本地关联。
- 凭据只留本机配置或独立浏览器目录，不进代码、日志、URL、导出、快照或数据库明文；模型输入、正文和证据不带凭据。Markdown、HTML 和 URL 安全渲染。
- 原帖、根、父和回复对象分别保留，缺父为未知；来源发布时间、观察和接收时间分开。UTC 存储，接口带时区，窗口左闭右开。按平台原生对象去重，不按相似文字合并不同原帖。
- 保存、受理、执行、部分完成、取消、发送和送达分别说明。写操作显式触发，沿用版本、幂等与回执，超时未知先核对；失败保留草稿。
- 读取有界，取消或忽略过期响应，失败不当零。URL 保存筛选、页签和分页，草稿留组件，本机收藏和阅读位置沿用既有合同；位置绑定 ID 与修订，版本变更不跳旧段落。
- 复用 jobs、租约、outbox、许可与内容身份，不新增通用账本、第二套采集批次、正文副本或默认云同步。
- 数据库唯一来源仍为 `backend/sql/schema.sql`；物理删除前核对消费者、外键、迁移、备份与独立库恢复。

## 验收标准

匿名、本人、他人、运营角色，资源替换和撤回许可分别核对。数据泄漏、越权、身份误去重、停止后新请求阻止验收；备份成功不等于恢复成功。损坏存储、过期结果和网络故障不得误报成功。
