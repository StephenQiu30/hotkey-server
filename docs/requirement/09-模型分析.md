# 09 模型分析

需求编号：`REQ-09`。本文定义需求，不表示实现或验收通过；进度只在 BACKLOG。

## 用户任务

分别判断相关性、情感与观点，不让热度替代相关性。

## 功能与约束

- 本期使用本机 Codex app-server；相关性读取实际 bool、理由、错误或未知，不编造四档或连续分数。
- 情感分正面、中性、负面，观点有原文引用，数量和占比由程序按明确分母计算；未分析不当中性。
- 短回复结合原帖和可得父评论，信息不足标不足；评论不必复述主题关键词。
- 模型限流延后处理，不丢材料；模型切换只影响之后受理的任务。
- OpenRouter 为模型与辅助搜索候选，按[平台接入](08-平台接入.md)核对数据范围与费用，不替代采集覆盖。
- 情感、观点和复杂分析保留为后续要求，不阻塞相关性与事件核心闭环。

## 验收标准

相关性与事件用真实样本独立评测。情感、观点单独标注，200 条情感样本评测仍待执行，阈值按有效基线冻结。摘要、观点和计数可回到证据，模型异常不伪装结果。见[质量验收](11-质量评测与验收.md)。
