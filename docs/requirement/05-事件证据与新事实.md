# 05 事件证据与新事实

需求编号：`REQ-05`。本文定义需求，不表示已实现或验收通过；进度只在BACKLOG。

## 用户任务

了解事件变化、新进展及原始证据，能够纠正误归并。

## 功能与约束

### EV-03

形成可追踪、可纠正的事件详情和热点条件。

验收：展示事件摘要、最早/最新证据时间、本轮新增事实、成员与作者数、来源分布、证据及覆盖缺口；误归并/拆分沿用修订和预期版本。热点按固定窗口、最低样本与明确规则判断，规则值经基线校准后冻结，不仅依据摘要或平台热榜。

事件关联不改变原帖身份。用户必须能从一个事件回到原帖、可访问评论和当前可读证据；许可撤回或删除后，关联视图和引用按现有生命周期规则处理，不继续显示已不可读材料。

## 验收标准

摘要、证据时间、新事实、材料/作者数与覆盖缺口可复核；统计由程序计算，合并/拆分有预期修订，撤回不回退旧证据。
