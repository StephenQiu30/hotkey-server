# 01 范围与优先级

| 层次 | 本期要求 | 后续扩展条件 |
|---|---|---|
| 关键词采集 | 一个已准入来源的任一词、必含词、排除词；有界窗口、原生身份、增量与覆盖回执 | 首个平台真实闭环通过后，再逐个平台核对搜索、评论、回复和回补能力 |
| 事件识别 | 相关性、事件候选、同事件归并、证据、新事实和可纠正的修订；单条材料保留线索 | 真实样本评测证明需要后，再比较额外聚类算法、多语言模型或大型索引 |
| 持续监测 | 定时运行、预算、到期/暂停/停止、恢复、正确窗口趋势、异常解释和最小告警 | 自然运行与最小告警通过后，再扩渠道、频率及报告 |
| 既有阅读与辅助功能 | 保留页面、会话、许可、收藏和报告合同；修复阻断核心流程的问题 | 全站统计、情感、关注、模型榜和非核心视觉完善按后续优先级交付 |

## 用户路径

| 用户路径 | 必须得到的结果 |
|---|---|
| 登录 → 来源 → 主题与关键词 → 运行 → 帖子与评论 | 命中词、发现方式、配置版本和窗口可追溯；保存、受理、采集、分析分别可辨 |
| 相关材料 → 线索/事件 → 证据与新事实 | 同主题与同事件不同；误归并可纠正，原帖身份保留，重要变化有出处 |
| 再次运行/调度 → 趋势与告警 → 暂停/恢复 | 新增、重复、旧帖更新和失败分别可读；覆盖变化不误报成降温，停止后不发新请求 |
| 首页、探索 → 事件或文章 → 原文 | 标题、摘要、来源、时间和许可一致；正文与证据版本可追溯 |
| 收藏 → 搜索、备注 → 所选导出 | 本机状态刷新后可恢复，只导出选中且仍可公开的信息 |
| 日报或榜单 → 固定刊期、模型与来源 | 同一修订或计算轮次可复核，不拼接历史版本冒充当前结果 |
| 必要的来源、任务和运营维护 | 仅授权角色可操作，版本冲突不覆盖输入，不在浏览时触发采集或外发 |

平台条件见[REQ-08](../requirement/08-平台接入.md)，验收见[REQ-11](../requirement/11-质量评测与验收.md)。这里只表达范围取舍，不维护进度。
