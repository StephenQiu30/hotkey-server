# 基础报告与数据导出 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-016，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/018-基础报告与数据导出计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

研究需要留存、复查和二次分析。缺少样本范围与引用的报告无法判断可靠性，导出过程中权限变化也可能泄漏已删除资料。

总纲原始要求：按主题/事件和时间窗生成可复查的简报；导出基础 CSV/JSON 数据与 Markdown 报告，包含来源、采样范围、指标口径、生成时间和引用。

用户导出一个召回事件过去七天的简报和评论表，稍后仍能核对数据范围及生成依据。

## 2. 目标与成功指标

**BR-018-001：**生成可读、可核查、可安全复用的基础报告与结构化数据，结果与用户选择的范围一致。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 导出一致率|冻结范围的条数、筛选与页面对账|100% |
| 报告引用覆盖|关键结论附有效证据比例|100% |
| 越权/删除泄漏|导出含无权或已要求删除数据次数|0 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**事件/主题时间窗简报、CSV/JSON 数据、Markdown 报告、异步生成、下载状态和版本说明。
- **明确不包括：**首版复杂版式编辑、无权限全库下载、付费报告生成服务、对外自动发布。
- **与相邻能力的边界：**报告整理已有资料和分析；不能因点导出自动扩大外部采集或生成未经证实的新结论。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 选择事件/主题、数据类型、时间口径、字段与格式。
2. 预览数量、样本边界及将包含的敏感/受限字段说明。
3. 提交导出，冻结查询与可用分析版本并显示进度。
4. 完成后复核权限和删除状态，提供有时效的下载入口。
5. 打开报告可回到证据，过期或资料变化时提示重新生成。

完成后用户获得：含范围、时间、字段口径和引用的可下载报告或数据文件。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 导出范围|主题/事件、平台、时间、资料类型必选|默认当前筛选 |
| 格式|CSV/JSON 对应数据，Markdown 对应简报|明确字段字典和 UTF-8 |
| 规模|建议单任务 50,000 行，上限可配置|超出需分批，不静默截断 |
| 有效期|下载建议 24 小时，可提前撤销|过期文件按生命周期清理 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-018-001 | 范围固定 | 导出绑定筛选快照和数据版本，记录总行数/实际行数；新入库资料不悄悄混入同一份结果。 | AC-018-002 |
| FR-018-002 | 内容结构 | 简报含概况、进展、讨论焦点、样本说明、来源缺口与证据；未知不补造结论。 | AC-018-003 |
| FR-018-003 | 字段字典 | 平台 ID 为字符串，时间含时区，缺失与零不同；正文换行和 CSV 分隔符正确处理。 | AC-018-004 |
| FR-018-004 | 权限复核 | 生成与下载时都校验权限/删除状态，撤权时使产物失效或重生成，不只检查提交时。 | AC-018-005 |
| FR-018-005 | 有界执行 | 长导出异步运行，可取消与重试；部分失败明确说明，禁止用不完整文件冒充完成。 | AC-018-006 |
| FR-018-006 | 版本与安全 | 报告保留生成时间、规则与分析版本；脚本/表格公式内容作为数据输出，不执行；下载不代表外部发布。 | AC-018-004 |

**DEC-018-001：**将报告视为固定范围的研究产物，导出前后都遵守证据和访问边界。

以上规则解释 FR-001-016，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 准备/生成中|显示范围和阶段，用户可继续浏览。 |
| 完成/部分失败|完整结果可下载；部分文件明确缺口并不混称完成。 |
| 过期/已撤销|不再提供内容，说明可重新生成的条件。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

所有者导出自己有权的数据；未来只读协作者默认无导出权；维护操作不自动授予内容下载权限。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-016 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-018-001 | 总纲场景继承 | 用户导出某事件某时间范围 | 生成文件并回读 | 行数/筛选与页面一致，证据可回溯；未授权或删除的数据不被导出。 |
| AC-018-002 | 固定范围 | 生成期间新评论入库 | 下载同一导出 | 只含冻结范围，元数据可核对 |
| AC-018-003 | 报告缺口 | 一个平台采集失败 | 生成简报 | 说明缺失来源，不推断为没有讨论 |
| AC-018-004 | 格式回读 | 正文含引号/逗号/换行和超长 ID | 导出 CSV/JSON 并解析 | 字段和 ID 无损，公式不执行 |
| AC-018-005 | 中途撤权 | 导出已生成后资料权限撤销 | 打开下载链接 | 拒绝或使产物失效，不泄漏内容 |
| AC-018-006 | 上限与失败 | 条数超过单任务上限或中途失败 | 请求导出 | 提示分批或明确失败，不静默给截断完成文件 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
