# 基于资料的问答与高级比较 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-023，保持 P2 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/025-基于资料的问答与高级比较计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

当资料量增加时，用户可能想直接提问或比较事件。但问答很容易超出已有证据、引用错误或混入无权数据。

总纲原始要求：在可追溯的采集资料上问答，或比较多个事件/品牌；回答标明资料范围、时间和证据，不执行越权采集。

用户问“这次召回与上次相比，退款诉求有哪些不同”，希望看到明确时间范围、样本差异和原始依据。

## 2. 目标与成功指标

**BR-025-001：**在有权、可追溯资料内提供辅助问答和比较，并对资料不足与不可比样本明确弃答。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 引用支持率|回答中的可核查断言能由对应证据支持|目标 100%，不支持断言不得发布为确定事实 |
| 越权检索|使用无权资料或已删除资料的次数|0 |
| 资料不足识别|冻结越界问题集明确拒绝推断比例|按 Q0 扩展集验收 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P2）：**选择资料范围、提问、证据检索、带引用回答、事件/品牌对比、反馈与历史版本。
- **明确不包括：**开放域万能问答、自动外网搜索或采集、自动发布、基于私密身份画像回答。
- **与相邻能力的边界：**问答消费 015/016 等已有资料；资料不足时可以提出补充采集建议，但不能自动执行。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；本文件展开后仍属后续阶段，不因文档已写完自动提升首版优先级。

## 4. 用户流程与关键结果

1. 用户选择有权资料集、主题/事件和时间窗口。
2. 输入问题，系统展示识别到的对象与范围。
3. 检索可用证据并判断是否足够、比较口径是否相容。
4. 生成带引用的回答或明确资料不足，展示缺失内容。
5. 用户反馈或保存回答为研究备注，后续资料变化标记历史版本。

完成后用户获得：范围明确、可核查且允许不回答的研究辅助结果。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 资料范围|至少明确事件/主题或允许查询的资料集合|默认当前事件 |
| 比较对象|时间窗、平台、采样口径需展示|不默认不同规模样本可比 |
| 问题|建议最多 1,000 字；不作为工具执行指令|长问题要求收敛对象 |
| 输出|回答、引用、假设、缺口、生成版本|事实与推断分段表达 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-025-001 | 权限先行 | 检索、摘要、引用和缓存均按当前权限及删除状态，不只在最终页面过滤。 | AC-025-005 |
| FR-025-002 | 封闭范围 | 默认仅使用已选资料，不因问题宽泛自动检索外网、扩大关键词或消耗采集预算。 | AC-025-002 |
| FR-025-003 | 证据绑定 | 可核查断言附具体证据和范围；证据冲突则并列说明，不能由语言流畅度掩盖。 | AC-025-003 |
| FR-025-004 | 比较公平 | 比较前展示样本规模、窗口与来源差异；不将采样差异解释成品牌好坏或总体趋势。 | AC-025-004 |
| FR-025-005 | 不足与不确定 | 无证据、上下文缺失或资料过期时可只给相关材料和缺口，不强行回答。 | AC-025-002 |
| FR-025-006 | 版本与反馈 | 保存问题、范围、方法和回答版本；人工反馈不直接改原文，重答不覆盖旧结果。 | AC-025-006 |

**DEC-025-001：**问答只作为有边界的研究入口，不能让模型扩大权限或替代证据核查。

以上规则解释 FR-001-023，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 资料选择/检索中|可见当前范围及进度，不暗中扩大。 |
| 有证据回答/存在冲突|区分事实、推断与不同来源说法。 |
| 不足/无权/过期|说明可回答边界和需要补足的资料，不编造。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

仅回答有权数据范围的问题；共享撤回后历史答案中的相关正文也应失效，不能通过对话缓存绕过。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-023 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-025-001 | 总纲场景继承 | 提问超出资料范围 | 生成回答 | 明确资料不足，不杜撰答案或扩大采集预算。 |
| AC-025-002 | 越界请求 | 问题要求搜索未接入平台全部历史 | 发送问题 | 明确资料不足，不自动外采或扩预算 |
| AC-025-003 | 回答引用 | 有若干支持与反对证据 | 生成回答 | 逐项引用并呈现冲突，不选性隐瞒 |
| AC-025-004 | 比较不同样本 | 两事件时间窗与来源不同 | 比较讨论比例 | 先说明不可比因素，不输出无依据优劣结论 |
| AC-025-005 | 权限缓存 | 答案曾引用后被撤权资料 | 打开历史对话 | 相关内容失效，缓存不越权 |
| AC-025-006 | 重答与纠正 | 用户指出结论错误并补充材料 | 再次回答 | 保存新版本及反馈，不覆盖原文或旧回答 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
