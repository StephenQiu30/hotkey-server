# 历史内容检索与筛选 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-012，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/014-历史内容检索与筛选计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

研究成果需要能够找回。没有清楚的筛选口径，用户可能把本地历史检索误当成重新搜索全平台，或无法复现之前看到的结果。

总纲原始要求：按主题、事件、平台、作者、时间、作品类型、关键词、已读/关注状态检索；明确检索的是已采集资料；分页可回到关联事件和原帖。

用户查找过去两天 X 上某账号涉及召回的作品，并进一步检索这些作品下已采到的评论。

## 2. 目标与成功指标

**BR-014-001：**让用户在有权访问的已采集资料中准确筛选、定位和回到事件上下文，保持查询结果可解释。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 筛选正确率|冻结数据中结果满足所有条件|100% |
| 分页稳定性|固定查询快照遍历后重复/遗漏记录|0 |
| 检索响应|B0 下本地检索 P95|≤3 秒目标，失败纳入报告 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**作品/评论/事件检索、组合筛选、时间类型、排序分页、结果上下文和条件留存。
- **明确不包括：**借本地检索发起未授权外部采集、承诺平台全量召回、高级正则查询语言。
- **与相邻能力的边界：**已采集资料检索归本模块；主动发现新资料需用户进入 005/009，不能混淆两个结果池。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 选择作品、评论或事件资料范围。
2. 输入文本及主题、平台、作者、类型和时间条件。
3. 确认使用发布时间或采集时间，查看本地覆盖说明。
4. 分页浏览并打开原帖、父评论或事件详情。
5. 保存筛选或导出当前范围，结果集版本可复查。

完成后用户获得：可复现筛选条件、明确范围的本地结果和原始证据跳转。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 文本条件|建议 1–200 字；空文本可用结构筛选|不自动翻译或扩词 |
| 时间|起止有时区且起≤止|默认发布时间；未知时间单列 |
| 结构筛选|同字段多选 OR，不同字段 AND|选项仅来自有权资料 |
| 分页|建议每页 20，可选 50/100|稳定排序，查询变更重置分页 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-014-001 | 范围明确 | 每页标已采集资料、采集覆盖和更新时间；结果数量不是全平台命中量。 | AC-014-006 |
| FR-014-002 | 组合语义 | 文本与主题/平台/作者/类型等条件组合可预测；移除条件后结果集重新计算。 | AC-014-002 |
| FR-014-003 | 时间口径 | 发布与采集时间可选择但不混用；未知发布时间按明确规则分区，不默认为今天。 | AC-014-003 |
| FR-014-004 | 稳定分页 | 同查询与结果快照下去重稳定遍历；新数据到来提示刷新而非悄悄改页内容。 | AC-014-004 |
| FR-014-005 | 关联上下文 | 评论结果可打开父链和所属作品；原文/父节点不可见时显示原因，不制造正文。 | AC-014-005 |
| FR-014-006 | 权限与删除 | 计数、建议词、结果和导出均受同一权限及删除规则，不能从统计泄露未授权对象。 | AC-014-006 |

**DEC-014-001：**将本地检索与外部发现明确分开，优先保证筛选、时间和分页语义一致。

以上规则解释 FR-001-012，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 有结果|显示条件、时间口径、数量和排序。 |
| 零结果|明确本地范围，提供清除条件或显式转主动搜索的入口。 |
| 索引更新中/结果变更|提示资料更新，保留原查询并可刷新，不暗中替换范围。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只检索有权资料；共享撤销后结果、计数、建议和导出立即遵守新权限，缓存不得继续暴露。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-012 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-014-001 | 总纲场景继承 | 用户选定两天与一个平台 | 检索作品和评论 | 结果符合筛选与访问范围，并显示本地样本边界，不宣称全平台检索。 |
| AC-014-002 | 筛选组合 | 两个平台三作者且跨时间窗 | 选平台+作者+时间 | 结果满足字段间 AND，字段内多选 OR |
| AC-014-003 | 未知日期 | 作品无发布时间但今天采集 | 按发布时间筛近一天 | 按未知时间策略单列，不自动当今天发布 |
| AC-014-004 | 分页刷新 | 翻到第二页时新资料入库 | 继续当前分页再刷新 | 旧快照不重复遗漏，刷新后明确新范围 |
| AC-014-005 | 评论定位 | 检索命中嵌套回复 | 打开上下文 | 可到所属作品和可见父链，缺失节点明确 |
| AC-014-006 | 权限收回 | 结果曾有访问权但已撤销 | 重试缓存查询与导出 | 计数、结果和导出均不泄漏 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
