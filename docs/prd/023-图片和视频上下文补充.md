# 图片和视频上下文补充 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-021，保持 P1 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/023-图片和视频上下文补充计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

视频或图片中的核心信息可能不在标题和描述里。把没有读取媒体正文的作品当作已理解，会让事件判断和评论分析失去上下文。

总纲原始要求：按需 OCR、字幕或转写并附时间位置，标注机器提取与不确定片段；不默认下载所有媒体。

一条视频标题很简短，研究者需要按需提取字幕或截图文字，并能定位到对应时间或画面核对。

## 2. 目标与成功指标

**BR-023-001：**在有权处理媒体且资源可控时补足必要上下文，并清楚区分原始文字、机器提取和人工修订。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 定位覆盖率|提取片段可关联时间段/帧/页或区域|100% 对可定位材料 |
| 提取质量|冻结样本与人工文字逐项比对|记录错误率，发布阈值待样本冻结 |
| 资源遵守|处理越过配置时长/大小/预算的次数|0 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P1）：**显式选择作品、字幕/转写/OCR、片段定位、低置信标记、人工修订和衍生文本版本。
- **明确不包括：**默认下载全账号媒体、生成未听清内容、身份识别、付费云转写成为默认依赖。
- **与相邻能力的边界：**原作品仍由 007 管理；媒体衍生文本只补充证据，不自动升级为已核验事件事实。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；本文件展开后仍属后续阶段，不因文档已写完自动提升首版优先级。

## 4. 用户流程与关键结果

1. 在上下文不足的作品中选择补充解析。
2. 确认可访问媒体、处理类型、大小/时长范围与资源预算。
3. 执行有界提取，保留字幕来源和片段定位。
4. 用户对低置信片段回看核对并修订。
5. 分析引用明确指向机器/人工版本，资料删除同步处理衍生文本。

完成后用户获得：可定位、可纠正的媒体文本与明确的未识别片段。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 处理对象|有权访问的作品或授权提供媒体|不自动遍历其他媒体 |
| 范围|建议单任务最多 10 分钟或 50 MB，取更严格资源条件|长媒体选择片段或分段 |
| 提取方式|平台字幕、语音转写、图像 OCR 分别标记|优先已有可用字幕 |
| 输出定位|视频时间段、图像区域/页、语言、置信与版本|无法定位需说明原因 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-023-001 | 显式触发 | 只有用户请求或明确启用的监控规则才处理媒体，不能在浏览作品时默认下载。 | AC-023-002 |
| FR-023-002 | 来源区分 | 平台原字幕、自动转写、OCR 和人工修订独立标记，不用提取文本冒充发布者原文。 | AC-023-003 |
| FR-023-003 | 定位与未知 | 每段文本保留可核对定位，噪音/遮挡/听不清标未知，不自动补成连贯事实。 | AC-023-004 |
| FR-023-004 | 处理限额 | 下载、解码和推理均有资源边界；超过大小/时长可选择片段或延期，不静默截断当完整。 | AC-023-005 |
| FR-023-005 | 版本传播 | 人工修订与重新解析生成新版本，引用旧文本的分析标需复核；不覆盖原媒体观察。 | AC-023-006 |
| FR-023-006 | 生命周期 | 临时媒体和衍生文本按授权与保留规则处理；删除源资料时定位关联产物并清理。 | AC-023-006 |

**DEC-023-001：**以按需、分段、可定位的媒体补充代替全量下载与黑盒理解。

以上规则解释 FR-001-021，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 待确认/资源评估|说明将处理的范围和限制。 |
| 部分识别/低置信|明确未识别区域或时间段，可回看修正。 |
| 不可访问/格式失败|保留原帖链接与上下文不足状态，不编造文本。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

仅处理当前有权访问的媒体；导出提取文本不扩大原资料授权，维护者不能任意下载用户内容。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-021 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-023-001 | 总纲场景继承 | 标题无法说明内容而用户有权处理媒体 | 请求补充解析 | 解析文本与原媒体位置对应；失败时明确上下文不足，不编造内容。 |
| AC-023-002 | 未触发 | 用户仅打开一个视频详情 | 加载页面 | 不自动下载或提交转写任务 |
| AC-023-003 | 多种来源 | 平台字幕与机器转写不一致 | 查看文本 | 分别标来源和版本，可回看核对 |
| AC-023-004 | 噪音片段 | 一段语音听不清 | 转写 | 标未知与时间位置，不补写推测内容 |
| AC-023-005 | 超限媒体 | 媒体超出时长或大小预算 | 提交处理 | 提示选段/分批或拒绝，不截断冒充完整 |
| AC-023-006 | 修订与删除 | 人工纠正后原作品被删除 | 刷新分析和引用 | 旧版需复核，衍生文本按生命周期清理 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
