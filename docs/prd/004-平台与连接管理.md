# 平台与连接管理 PRD

日期：2026-09-22。状态：已评审；承接既定范围 FR-001-002，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已验收。对应 [Design](../design/004-平台与连接管理设计.md) 已接受 S00—S03 内部技术范围，[执行计划](../plans/004-平台与连接管理计划.md) 保持 `in_progress`；S04 真实来源执行联验与 Acceptance 尚未完成，产品 AC 仍为 0/6。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

一个平台往往只有部分接口可用。仅显示“已连接”会让用户误以为关键词、作者、评论都能采集，也无法判断何时需要重新登录。

总纲原始要求：X 必须纳入；按关键词、作者作品、评论、回复分别显示已验证/待验证/受限/不可用，以及最近验证和成功时间；管理连接与失效提示。

研究者为 X 配置连接后，发现作品读取正常而评论受限，需要继续查看作品并明确评论未就绪。

## 2. 目标与成功指标

**BR-004-001：**按能力提供准确的连接与访问状态，使用户知道哪些需求已验证、哪些仍不可执行。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 能力状态准确性|能力探测结果与展示逐项比对|冻结样本 100% 一致 |
| 过期可见性|失效连接在下一次已授权操作后是否更新状态|不继续显示无条件可用 |
| 秘密泄漏|界面、响应、日志与导出出现连接秘密次数|0 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**平台目录、逐项能力、连接配置/更新/停用、验证时间、能力失败及重新就绪过程。
- **明确不包括：**购买账号、获取他人会话、自动绕过验证、以公共镜像替代 X 验收。
- **与相邻能力的边界：**本模块说明连接是否能工作；每次采集范围和成败归 009；秘密处理遵循 034。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 选择平台，查看支持范围、访问条件与已知限制。
2. 按受支持流程配置自有或获授权连接，界面只保存秘密引用。
3. 通过独立显式探测确认单项能力，记录组件版本和验证时间。
4. 完成持久化采集验收后，开放对应能力的任务执行。
5. 失效时暂停受影响能力，用户处理后重新验证。

完成后用户获得：平台能力矩阵、连接状态、最后成功时间和可执行的下一步动作。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 平台|使用稳定来源标识|X 必需，其他目标逐项标注 |
| 能力|关键词/作品/作者/评论/回复/指标独立登记|未知默认待验证 |
| 连接材料|只接收受支持的本地配置或秘密引用|不在页面或聊天回显会话 |
| 验证证据|版本、时间、范围、结果、错误类别|过期证据保留历史但标需复验 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-004-001 | 能力粒度 | 同平台搜索、作者、评论和回复状态独立；不能从一个接口成功推导全部能力可用。 | AC-004-002 |
| FR-004-002 | 状态来源 | 未配置、待验证、可用、部分可用、需登录、受限、停用分开；每次变化保留依据与时间。 | AC-004-002、AC-004-005 |
| FR-004-003 | 启用条件 | 诊断成功仅说明探测；须有数据持久化并可读取的验证才标可用，X 路径未通过不得宣称首版完成。 | AC-004-003 |
| FR-004-004 | 入口一致性 | 手动、定时及未来技能入口共享能力定义；能力范围不同必须明确显示，不只依据函数存在。 | AC-004-004 |
| FR-004-005 | 停用与更换 | 停用后不接受新任务；换凭据重新验证，旧结果保留原连接版本，不复用旧成功状态。 | AC-004-005、AC-004-006 |
| FR-004-006 | 失败隔离 | 单能力受限只暂停该能力；秘密过期影响整个连接时应联动暂停，不能自动转收费来源。 | AC-004-002、AC-004-006 |

**DEC-004-001：**用可验证的能力状态代替单一平台开关，保留 X 为必需而不伪报已支持。

以上规则解释 FR-001-002，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 未连接/待验证|展示缺少的条件，不能运行尚未就绪能力。 |
| 部分可用|列明可执行和受限能力，已有资料继续可读。 |
| 需登录/被拒绝|显示稳定错误类别和处理入口，不回显会话或上游完整响应。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

所有者管理自己的连接，获授权维护者可执行探测和更换秘密引用；任何普通读取都不得取回凭据。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-002 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-004-001 | 总纲场景继承 | 某来源能读作品但不能读评论 | 选择该来源并查看能力 | 页面清楚显示能力差异，不把不支持评论当作零评论；X 未通过时整体首版不能宣称完成。 |
| AC-004-002 | 分能力状态 | 详情读取正常、评论返回拒绝 | 查看平台页 | 详情可用而评论受限，不显示全平台成功 |
| AC-004-003 | 探测与验收 | 只有诊断响应成功 | 查看状态并尝试启用 | 仍待持久化验收，不能标自动监控已交付 |
| AC-004-004 | 跨入口 | 手动支持搜索而定时配置未支持 | 从两个入口查看能力 | 范围差异被明确呈现，不误导相同能力 |
| AC-004-005 | 更换连接 | 旧连接有成功记录 | 更新会话并启用 | 重新验证，旧数据保留来源版本 |
| AC-004-006 | 停用秘密 | 连接已停用 | 请求新任务或读取秘密 | 新任务不发出且秘密不可读 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
