# 首管理员数据库指定

## 范围

- 删除两个 bootstrap 管理员环境变量、配置字段、加载键、示例和 README 指引，并从 `.env.prod`、部署环境及 Secret Store 清理历史值。
- 删除 `user bootstrap-admin` 命令、专用 Repository 方法、错误和测试。
- 普通注册不再为已删除的 bootstrap 竞争保留全局 advisory lock。
- 以 Operations 文档提供受锁、单行、可核对的数据库首管理员提升事务。
- 增加防回流门禁，禁止生产代码、活动配置和 README 再出现 `BOOTSTRAP_ADMIN` 或 `bootstrap-admin`。

## 非目标

- 不允许注册请求自行选择角色，不新增公开管理员创建接口。
- 不改变 Schema、OpenAPI、密码、验证码、会话和最后活动管理员保护。
- 不改写记录旧实现事实的 archive 文档。

## 验收条件

1. `.env`、`.env.example`、`.env.prod`、部署环境、Secret Store 和配置结构中无管理员邮箱或密码字段。
2. `hotkey user bootstrap-admin` 不再存在，未知 `user` 命令按统一 CLI 规则失败。
3. shared/identity Repository 不再包含 bootstrap 专用错误、方法或全局首用户创建锁。
4. 正常注册仍创建 viewer；数据库事务只能在零 active admin 时把一个已注册 active 用户提升为 admin，并记录数据库主体和变更单号。
5. 角色生命周期、最后管理员保护、lint、build、validate、Schema/OpenAPI 零差异通过。
6. 不依赖错误用户凭据的 break-glass 纠正流程能在同一事务先提升正确用户、再降级错误管理员，并保证始终至少一个 active admin。
