# 容量与部署可重复性 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-016，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/042-容量与部署可重复性计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

自建监控同时执行抓取、保存、分析、清理和备份，资源紧张时最容易牺牲已有资料读取。依赖某个人临时环境的部署也无法支撑后续恢复和交接。

总纲原始要求：在声明的数据规模与自有资源预算内运行；备份、清理和分析后台任务不能压垮核心读取；部署、配置、数据导出及回滚可复现。

B0 数据规模下磁盘接近配置上限，系统先暂停历史回填并提示容量压力，用户仍能查看事件；维护者按文档在干净环境启动并恢复资料。

## 2. 目标与成功指标

**BR-042-001：**在声明的资源和数据规模内维持核心可用，并让部署、配置、恢复及回滚过程可重复。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| B0 资源峰值与增长|固定负载下 CPU、内存、磁盘、临时空间、后台任务用量及每日增长|完整记录且不超过配置预算；读取同时满足 030 |
| 容量保护|触发高水位后新增非必要工作与已有资料可读性|非必要工作有界延期，不静默丢数据或虚假确认写入 |
| 部署可重复性|在两个隔离干净环境按同一说明完成启动和核心核对|均成功；实际使用配置和版本一致，差异有记录 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**B0 容量声明、增长评估、高水位处理、前后台资源分配、部署材料、配置校验和可重复升级/回滚。
- **明确不包括：**无限扩展、首版建设复杂集群、保证任意硬件都满足目标、为容量测试向真实平台施压、把单机部署成功视为真实来源接入通过。
- **与相邻能力的边界：**030 规定读取时延，032 规定恢复结果，037 限制请求及资源消耗。本文件验证它们在同一环境中能共同成立；不重新锁定尚未设计的技术组件。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 记录目标主机、固定软件版本、部署配置和 B0 数据规模。
2. 在受控来源和声明并发下测量读取及采集、分析、备份、清理的共同负载。
3. 根据实际单条大小和每日增量估算保留期内增长及临时空间需求。
4. 达到容量阈值后预警并暂停低优先工作，保留必要读取、清理和可靠写入。
5. 在干净环境重复部署与回滚，验证配置、资料和运维说明可用。

完成后用户获得：明确适用规模的容量报告和可由他人重复执行的部署说明。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| B0 环境|总计 4 vCPU、8 GiB 内存、SSD；记录系统、版本、网络及浏览器|不能把单个服务配额冒充整套资源消耗 |
| B0 数据与负载|10 主题、20 账号、5 并发读取；10 万作品、50 万评论、100 万指标快照|记录文本长度、事件分布、附件大小和数据生成方式 |
| 容量阈值|按实际可用容量与必要保留空间配置|候选 80% 预警、90% 暂停非必要工作；更早的预算或系统阈值优先 |
| 部署材料|固定版本、配置样例、秘密引用说明、启动/校验/升级/回滚步骤|示例无秘密，无需复制某人的本地临时文件 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-042-001 | 基线完整声明 | 记录整套服务资源与数据、前后台负载和运行时长；B0 只规定配置容量，不承诺全部主题/账号可按任意频率采集。偏离基线必须标明，不能把小样本结果外推达标。 | AC-042-002 |
| NFR-042-002 | 容量测量与增长 | 测量正文、索引、快照、附件、日志、备份及临时空间占用，并依据实测日增量和保留规则估计增长；公布假设与峰值，不能仅按正文长度估算全部空间。 | AC-042-002 |
| NFR-042-003 | 高水位保护 | 达到阈值先预警、暂停回填与昂贵非必要分析；已有资料继续可查，清理与恢复所需资源有保留。无法持久写入时拒绝或延期受理，不能已确认后静默丢弃。 | AC-042-003 |
| NFR-042-004 | 并行负载隔离 | 采集、分析、备份和清理与核心读取同时运行时遵守资源上限与 030；低优先任务有界让出资源，不能只在所有后台停用时测出漂亮性能。 | AC-042-004 |
| NFR-042-005 | 可重复部署与配置 | 从声明前置条件和固定版本完成全新部署，启动时校验必要配置与依赖；缺失或错误配置明确失败，普通日志不打印秘密。健康状态区分进程、依赖和业务可读。 | AC-042-005 |
| NFR-042-006 | 升级回滚与交接 | 部署材料包含数据兼容边界、备份前置条件和恢复/回滚步骤；在隔离环境按文档实际执行，非原作者可理解并核对结果，不依赖隐藏手工修改。 | AC-042-006 |

**DEC-042-001：**以声明规模下前后台共同运行和干净环境重复部署为证据；系统达容量上限时明确延期，优先保住已有资料和确认语义。

以上规则解释 NFR-001-016，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 容量正常或接近上限|显示用量、阈值、增长依据和需要用户关注的资源 |
| 保护性延期|明确哪些任务暂停、哪些能力继续及恢复条件 |
| 部署或配置不满足|停止宣称整体健康，指出可修正依赖或配置，不泄漏秘密 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

维护者可调整容量与部署配置；用户不能通过新任务绕过全局上限。容量测试只用受控来源和合法样本，隔离环境不自动启动生产采集与外部通知。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**B0 下热身后至少 15 分钟且不少于 1000 次有效读请求，并行运行代表性采集/分析/清理/备份负载；记录冷启动及失败请求。通过受控容量阈值触发验证保护；在两个独立干净环境重复说明，不触碰当前生产数据。

总纲质量目标：B0 验证 CPU/内存/磁盘峰值和持续增长；超过配置容量预警/暂停非必要回填，不静默丢数据；新环境按文档可恢复配置和读取资料，不依赖某个人的临时环境。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

AC-001-040 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-042-001 | 总纲场景继承 | 存储接近限额且正在历史回填 | 继续正常浏览和调度 | 回填有界延期、已有资料可查，资源压力和处理记录可见。 |
| AC-042-002 | 声明与实测 | B0 数据集和整套 4 vCPU/8 GiB 资源已配置 | 运行负载并核对占用 | 环境、数据分布、全部服务与临时空间计入，增长假设可核查 |
| AC-042-003 | 磁盘高水位 | 存储达到预警和暂停阈值且回填运行中 | 继续调度并浏览资料 | 回填有界延期，已有资料可读，无法保存时不虚假确认，清理仍可执行 |
| AC-042-004 | 后台共同负载 | 采集、分析、备份与清理产生代表性负载 | 执行规定读取窗口 | 读取符合 030 且资源不超预算，不能隐藏失败或停后台后替代结果 |
| AC-042-005 | 干净环境配置 | 两个隔离环境仅具备声明前置条件 | 按同一说明部署，并分别测试缺少必要配置 | 配置正确时核心可读；缺失时明确失败，日志无秘密，版本可核对 |
| AC-042-006 | 升级与交接 | 已备份合法样本且存在兼容性变化 | 按文档升级并执行回退/恢复核对 | 历史资料与配置可读，步骤和限制完整，不依赖作者临时手工修复 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
