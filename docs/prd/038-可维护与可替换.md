# 可维护与可替换 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-012，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/038-可维护与可替换计划.md) 已进入 `in_progress`，[Design](../design/038-可维护与可替换设计.md) v1.0 已接受 S00—S01；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

社交平台字段和第三方采集器会变化。若业务页面直接依赖某个库的内部返回格式，更换组件就会改变作品、评论和统计含义，使历史资料难以继续使用。

总纲原始要求：平台能力契约与业务需求分离，固定组件版本和许可证记录；更换采集器不应改变事件、作品、评论的含义。

X 采集器升级后回复字段变化，兼容性验证先发现父评论关系错误；维护者可以停用新版本并恢复旧版本，而事件资料不需要整体重建。

## 2. 目标与成功指标

**BR-038-001：**使采集组件可以有证据地升级、替换或停用，同时保持业务语义和历史资料可读。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 启用来源契约覆盖|通过基础语义及状态契约验证的启用能力 / 全部启用能力|100%；不支持的能力明确拒绝 |
| 变更可回退性|规定升级失败场景中恢复可用版本及资料读取的结果|全部通过，无法回退须在变更前明确阻止或安排迁移方案 |
| 维护投入|按来源记录调查、修复、验证与升级耗时|持续记录实际值，用于判断保留或替换，不预设虚假低成本 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**稳定业务语义、来源能力契约、版本与许可证记录、回归样本、升级回退和维护信息。
- **明确不包括：**重新编写已有成熟爬虫、首版支持所有平台、为了可扩展提前建立复杂插件市场、承诺上游任意变更无需维护。
- **与相邻能力的边界：**004 描述用户可见能力，027 规定数据正确性；本文件规定更换实现时两者不能变。技术选型和模块实现留待 Design。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 为拟接入组件记录版本、许可、维护状态及能力限制。
2. 用相同业务契约检查对象标识、评论关系、时间、指标、分页及错误状态。
3. 升级在隔离环境对固定样本和有限真实来源探针执行回归。
4. 确认差异、迁移影响和回退路径后才启用新版本。
5. 失败时暂停受影响能力并回退，保留历史资料及维护记录。

完成后用户获得：可比较、可替换且有回退证据的来源组件清单。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 组件清单|名称、固定版本/提交、许可证、上游链接、核对日期与用途|不以 star 数或 README 宣称代替验证 |
| 能力契约|输入查询与输出字段、稳定 ID、分页/增量、缺失值及错误语义|平台不支持的能力显式标记 |
| 回归样本|合法保存的脱敏输入和预期业务结果，记录生成版本|包含空结果、部分数据、限流、删除和格式变化 |
| 变更记录|升级差异、数据迁移、配置变化、回退版本和维护耗时|重大语义变化必须联动相关 PRD 与指标口径 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-038-001 | 业务语义稳定 | 作品、回复、作者、事件及指标定义不由单个采集器决定；替换输出映射到统一语义，缺字段为未知而非零，采样方式不能静默改变。 | AC-038-002 |
| NFR-038-002 | 能力契约验证 | 所有启用来源能力验证查询语义、对象稳定标识、分页、增量、水位、取消及错误分类；空结果和受限结果严格区分，未支持能力明确拒绝。 | AC-038-002 |
| NFR-038-003 | 版本与许可可追踪 | 固定实际运行版本和依赖来源，核对适用许可证与用途；组件、模型和数据条件分别记录。不能把某子目录许可推定为整仓库可随意复用。 | AC-038-003 |
| NFR-038-004 | 回归与真实探针 | 固定样本验证产品规则，有限且获准的真实来源探针验证当前访问与解析；两种证据分开报告。只有样本回归通过不能宣称真实来源健康。 | AC-038-004 |
| NFR-038-005 | 升级回退与数据兼容 | 启用前说明配置/数据变化及逆向兼容边界；失败能恢复上一可用版本或明确迁移恢复路径，不能回退程序后读取不了新写入资料。停用适配器保留既有可读业务资料。 | AC-038-005 |
| NFR-038-006 | 维护与替换决策 | 记录来源故障、修复耗时和版本变更；长期无法满足能力或访问条件时可停用、替换并告知影响。替换须继承当前权限、预算、去重和删除约束，不重复采集全部历史。 | AC-038-006 |

**DEC-038-001：**复用成熟组件，但由产品定义稳定业务契约；版本固定和可回退优先于追逐最新依赖。

以上规则解释 NFR-001-012，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 候选未验证|记录声称能力，未通过契约和访问验证前不标正式可用 |
| 升级验证中|原可用版本继续承担已授权工作，测试结果与差异可见 |
| 已停用或已回退|历史资料可读，受影响能力和原因清晰，不显示仍在正常更新 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只有获授权维护者变更运行组件；普通用户配置监控不能加载任意代码。依赖验证使用隔离环境和合法样本，不把生产秘密提交到仓库。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

关联 [043 模型服务接入与模型配置](043-模型服务接入与模型配置.md)：模型适配器复用 ai/contracts 与 ai/adapters 的纯协议边界，目录和提供方差异有版本及契约测试；不为 OpenRouter/Vercel 新建第二后端。 本项先行能力不依赖 043 完成；扩展进入范围时追加验证。

- **依赖或关联 PRD：**[004 平台与连接管理](004-平台与连接管理.md)、[008 评论与回复采集](008-评论与回复采集.md)、[010 增量更新与历史回补](010-增量更新与历史回补.md)、[027 数据正确性](027-数据正确性.md)、[028 可追溯与可复现](028-可追溯与可复现.md)、[033 故障隔离与降级](033-故障隔离与降级.md)、[036 数据访问与生命周期](036-数据访问与生命周期.md)、[037 费用与资源约束](037-费用与资源约束.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**对至少一个启用来源构造字段变化、能力缺失和分页异常回归；执行版本升级与回退，核对历史对象、评论关系和指标口径。真实来源探针须注明日期和访问条件，避免以过期维护状态作为当前事实。

总纲质量目标：每个启用来源通过相同基础契约测试；升级可回滚；停用一个适配器不要求迁移全部业务数据。记录维护工时用于评估可持续性。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-036 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-038-001 | 总纲场景继承 | 一个来源版本升级后字段变化 | 执行兼容性验证并回滚 | 错误被发现且旧版本可恢复，来源变化不悄悄修改产品指标口径。 |
| AC-038-002 | 字段语义变化 | 新版本把缺失点赞数返回为空且父评论字段改名 | 执行统一契约回归 | 不能把空转零或丢失父子关系，阻止错误版本启用 |
| AC-038-003 | 许可与固定版本 | 候选组件只有部分目录声明许可证 | 登记选型与准备部署 | 记录实际版本及许可范围，未确认部分不能按已授权复用处理 |
| AC-038-004 | 样本与真实访问 | 固定样本通过但当前真实来源拒绝访问 | 汇总验证状态 | 规则回归通过与来源受限分别报告，不标整体接入通过 |
| AC-038-005 | 升级回退 | 新版本已写入少量合法资料后出现兼容问题 | 暂停并回退 | 旧版本或既定恢复路径可读取资料，无需删除全部历史 |
| AC-038-006 | 替换不重复 | 旧适配器已有去重与删除记录 | 接入兼容替代组件继续采集 | 沿用权限、预算和对象标识，不复活删除资料或重复全量导入，维护耗时可记录 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
