# 00 产品定位

面向个人非商业的关键词热点事件监测。用户配置主题、关键词与来源，系统持续发现相关公开帖子，识别具体事件和新进展，展示有依据的趋势并发出有用提醒。关键词由用户自行配置，AI 行业或 DeepSeek 只是示例。

## 用户与价值

首版服务于需要持续跟踪少量主题的个人用户；企业品牌协作和商业舆情采购不进入本期。用户目前需要反复在多个平台搜索、辨认重复信息、回看事件变化，目标是在一个主题下读到相关原文、具体事件和真正的新进展。系统通过关键词发现、材料关联和带证据的更新提醒减少重复搜索。平台原生搜索、热榜和 RSS 阅读器仍是可用替代；本产品的价值是持续跟踪具体事件并解释来源和缺口，而不是承诺全网完整覆盖。

成功以真实采集结果、两轮新增与去重、人工核对的事件质量、自然运行记录和实际提醒为依据。先测精确率、可见集合覆盖、误合并/漏合并、发现延迟和告警噪声的基线，再确定质量阈值；不预先编造准确率、吞吐量或秒级发现承诺。
