# 分析有效性与不确定性 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-015，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/041-分析有效性与不确定性计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

关键词相关性、事件归并、热度、情绪和立场是不同任务。一个总体准确率无法说明哪个结论可信，少量样本的情绪更不能代表全网意见或事件事实。

总纲原始要求：相关性、事件归并、情绪/立场和热度排序分别评估；不把样本情绪说成全网民意，不把热度或身份标识说成事实可信度。

同一主体的两起事件、讽刺评论和转述内容出现在监控中，系统应分别评估归并与分类，允许不判断，并让用户查看依据及样本缺口。

## 2. 目标与成功指标

**BR-041-001：**以独立、可复核的评估判断分析是否可用，并在产品结果中保留样本范围和不确定性。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| Top-10 相关率|Q0 中每组至少 10 个结果的前 10 项人工相关标注占比，再按组报告均值和分布|候选 ≥80%；不足 10 项分组单列，不补空或选择性剔除难组 |
| 自动归并精确率|自动判为同事件的受评估作品对中，人工确认同事件的比例|候选 ≥90%；同时报告错误拆分、召回及自动覆盖，不能全弃判取巧 |
| 结论可追溯率|报告中可回到获授权证据和规则/模型版本的分析结论占比|100%；情绪/立场另报分类质量、弃判率、语言和样本量 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**P0 相关性排序、事件归并、热度解释与分析证据质量；后续自动情绪、立场和问答启用时的独立效果门槛。
- **明确不包括：**以热度判断事实真假、以账号认证判断信息真实性、全网民意和全量召回保证、用模型自评替代人工参考标签。
- **与相邻能力的边界：**013 定义评分行为，015 定义讨论分析输出，022 定义自动分析增强；本文件给出评估方法和启用门槛，不因质量约束提前交付 P1/P2。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 冻结合法取得的 Q0 样本、任务定义、标注说明和评估分组。
2. 由人工独立标注并处理分歧，区分调参样本与最终评估样本。
3. 分别运行关键词排序、归并及已纳入范围的其他分析。
4. 按任务、语言、困难样本和弃判情况公布完整结果。
5. 未达标能力保留人工或明确实验状态，修正后使用未被污染的评估集复验。

完成后用户获得：分任务的质量报告及有证据、有限定范围的分析结果。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| Q0 样本|至少 200 篇作品、300 条评论、10 个事件、20 组检索结果；至少 X 和一个中文来源|覆盖讽刺、转述、否定、同主体不同事件、重复及缺失上下文 |
| 标签与分歧|相关性、事件一致性、情绪和针对对象的立场分别定义|标注者可选无法判断，保留分歧及裁决依据 |
| 评估切分|调参与最终验收样本分离，固定样本版本与规则版本|不反复对同一验收集调参再声称独立效果 |
| 结果说明|样本量、时间范围、语言、采样方式、缺失和弃判率|没有全体分母时不输出全网覆盖或民意百分比 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-041-001 | 任务独立评估 | 相关性、归并、热度排序和分类分别出报告，不能用摘要流畅度替代准确性；热度检查公式与解释及人工排序偏好，不把热度等同真实性。 | AC-041-003 |
| NFR-041-002 | 样本与人工参考 | Q0 记录来源权利、样本版本、困难样本和分组；人工标注规则一致，关键分歧裁决可追踪。候选分析模型不能单独生成并判定自身验收真值。 | AC-041-002 |
| NFR-041-003 | 指标与反取巧 | Top-10 按固定组统计并单列短结果；归并精确率同时报告召回、错误拆分、覆盖和自动决定数量。没有自动正例时指标为不可估计，不能按 100% 通过。 | AC-041-003、AC-041-004 |
| NFR-041-004 | 不确定与样本边界 | 低置信、缺上下文、模型失败允许弃判，页面和报告显示原因、样本量及实际分母；情绪与针对明确对象的立场分开，不能将收集样本推广为全网民意。 | AC-041-005 |
| NFR-041-005 | 证据与人工修订 | 结论可追溯到原文、时间、规则/模型版本及引用；人工修订保留理由和原版本。证据删除或不可用后结论失效处理遵守 016/036，模型新输出不静默覆盖人工判断。 | AC-041-006 |
| NFR-041-006 | 启用与回退 | 只有对应阶段的效果门槛和证据要求满足才启用正式自动能力；未达标维持人工/规则方式并明确限制。按语言、来源变化或模型升级重新评估，不把未验证语言默认为同等可靠。 | AC-041-005、AC-041-006 |

**DEC-041-001：**用独立人工参考集和完整分母决定自动分析是否可发布；达不到目标就缩小适用范围或保留人工，不隐藏困难样本。

以上规则解释 NFR-001-015，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 有效但有限定范围|展示样本、时间、适用语言和已验证任务 |
| 无法判断或证据不足|说明缺少什么，不强制输出正负情绪或事件真伪 |
| 未达门槛或版本待验证|自动结论不作为正式通过能力，仍可人工复核原始资料 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

评估只使用合法获授权资料；标注与查看受相同数据权限控制。用户修订其可访问资料，评估报告公开前脱敏，不能包含连接秘密或不必要个人信息。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

- **依赖或关联 PRD：**[011 事件识别与归并](011-事件识别与归并.md)、[013 相关性与热度排序](013-相关性与热度排序.md)、[015 讨论分析与趋势](015-讨论分析与趋势.md)、[016 证据引用与分析修订](016-证据引用与分析修订.md)、[019 人工整理与反馈](019-人工整理与反馈.md)、[022 自动分析增强](022-自动分析增强.md)、[025 基于资料的问答与高级比较](025-基于资料的问答与高级比较.md)、[027 数据正确性](027-数据正确性.md)、[028 可追溯与可复现](028-可追溯与可复现.md)、[036 数据访问与生命周期](036-数据访问与生命周期.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**严格沿用总纲 Q0；报告实际样本数、来源/语言分层、标注分歧、独立评估切分和每项指标分母。短结果、弃判、未产生自动归并以及模型故障均单列；本轮只写标准，没有执行质量实验。

总纲质量目标：Q0 冻结标注集：候选 P0 排序 Top-10 相关率 ≥80%、自动归并精确率 ≥90%；全部报告结论可溯源。阈值是待校准目标；自动情绪/立场另测分类效果、弃判率及各语言结果，未达标保留人工模式。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-039 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-041-001 | 总纲场景继承 | 测试集含讽刺、转述、否定、同主体不同事件与分析服务失败 | 评估并生成报告 | 各任务独立报告结果与样本量，低置信允许不判断；失败回退不将事实真实性默认标真，原始资料仍可复核；未达到目标不能称分析验收通过。 |
| AC-041-002 | 独立样本与标签 | Q0 已收集且含困难样本 | 标注、裁决并冻结评估集 | 样本规模和分组可核对，调参集隔离，标签不由被测模型自行判真 |
| AC-041-003 | Top-10 与短结果 | 固定检索组中存在少于 10 条的结果 | 计算相关率并评价热度 | 完整组按既定口径统计，短组另列；热度不被当事实可信度 |
| AC-041-004 | 归并拒绝全部 | 算法为提高精确率而拒绝全部自动归并 | 运行事件评估 | 精确率不可估计且不能通过，召回、拆分和覆盖暴露问题 |
| AC-041-005 | 困难语义和服务故障 | 评论含讽刺、转述、否定且部分缺上下文 | 运行已纳入范围的分类并生成报告 | 情绪/立场分开，允许弃判，显示样本边界；未达标回人工，不宣称全网民意 |
| AC-041-006 | 修订与证据删除 | 结论有人工修订且某条依据被删除 | 升级分析版本或重新生成结果 | 保留修订历史和依据版本，不静默覆盖；失效依据不继续支撑有效结论 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
