# 备份与恢复 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-006，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/032-备份与恢复计划.md) 已进入 `in_progress`，[Design](../design/032-备份与恢复设计.md) v1.0 已接受 S00—S01；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

备份文件存在并不意味着发生故障后资料能使用。监控配置、作品评论关系、证据附件和删除记录之间缺少任何一项，都可能导致恢复后的事件结论失真。

总纲原始要求：备份监控配置、业务资料及必要证据清单；可以恢复并验证，而不只是生成备份文件。删除要求应覆盖备份生命周期。

自建主机存储损坏后，维护者在隔离的新环境恢复资料，并确认先前删除的评论不会因旧备份再次向用户展示。

## 2. 目标与成功指标

**BR-032-001：**在明确的数据损失窗口和恢复时限内恢复可核对的监控资料，并保持权限与删除约束。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 恢复点目标 RPO|故障时刻与可恢复的最后业务一致性时间点之差|B0 初始建议 ≤24 小时 |
| 恢复时间目标 RTO|从启动故障恢复处置到核心资料读写可用且核对通过的时间|B0 初始建议 ≤2 小时，包含准备、还原及必要校验 |
| 恢复完整性|必需对象、关系、配置和证据清单核对通过率|必需检查全部通过；缺失附件明确列出，不能报完整恢复 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**备份范围、计划与失败提示、备份权限、隔离恢复、完整性核对和删除约束重放。
- **明确不包括：**多地域自动容灾、零数据损失、仅靠备份任务返回成功就宣称可恢复、未经授权改动当前生产数据。
- **与相邻能力的边界：**036 决定数据保留及删除；本文件规定恢复时如何执行。042 负责可重复部署，恢复演练须覆盖配置与运行环境衔接。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 维护者确认备份范围、保存位置、频率、保留期和恢复所需凭据清单。
2. 按计划生成具有一致性时间点的备份，校验可读取性和内容清单。
3. 失败立即留下可操作记录，保留上一份已验证备份。
4. 在隔离环境恢复服务、配置、业务数据与必要证据，应用最新删除记录和权限约束。
5. 完成计数、关系、抽样及核心流程检查后记录 RPO/RTO 和剩余缺口。

完成后用户获得：可定位、可验证的备份及实际恢复报告。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 备份内容清单|包含主题/账号配置、业务数据、关联关系、必要证据清单和删除记录|凭据采用受保护的独立恢复方式，不作为普通业务导出 |
| 频率与保留|按 RPO 推导实际调度与失败补偿，不能只写每天一次|保留期服从 036；到期自动清理 |
| 恢复时钟|记录一致性时间点、故障时间、处置开始和可读核对通过时间|所有时刻注明时区和来源 |
| 验证抽样|必需结构全检，正文与证据分层抽样|覆盖 X、另一来源、评论关系、已删除对象及不同配置版本 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-032-001 | 完整范围与一致性 | 每份备份具有范围、版本、一致性时间点、校验信息及依赖清单；数据库和附件清单的时间关系明确，不能把缺少评论关系的文件包称完整备份。 | AC-032-002 |
| NFR-032-002 | 安全存取 | 备份传输与存储访问受控；凭据和解密材料与备份分离管理，普通阅读者不可下载。日志不包含秘密或完整敏感正文。 | AC-032-003 |
| NFR-032-003 | 计划与失败 | 备份失败、过期或不可读可见，并提示距离最近可恢复点的风险；新备份校验失败不能覆盖最后一份已验证备份，重试有界。 | AC-032-003 |
| NFR-032-004 | 真实恢复与计时 | 在独立目录/存储和隔离环境真实还原，核心读取及受控本地写入核对通过后才停止 RTO 计时；本地写入不包含外部采集。不得排除下载、准备或修复时间以达标。演练不写入原环境。 | AC-032-004 |
| NFR-032-005 | 删除与权限重放 | 恢复资料对用户开放前，应用恢复点后仍有效的删除记录、到期规则和权限撤销；删除记录的保留必须覆盖可恢复备份最长周期，缺少记录时不能直接开放相关资料。 | AC-032-005 |
| NFR-032-006 | 恢复结果核对 | 核对对象总数、关系完整性、权限、证据链接及抽样正文，列出恢复点后数据损失；恢复后的调度默认暂停，确认当前连接与预算后再恢复采集。 | AC-032-002、AC-032-004、AC-032-006 |

**DEC-032-001：**以隔离环境实际恢复且业务核对通过为验收证据，备份生成成功仅是中间状态。

以上规则解释 NFR-001-006，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 备份健康或过期|显示最近一致性时间点、校验状态和下一计划，过期提示实际风险 |
| 恢复进行中或失败|展示阶段与原因，失败保留原环境和可重试材料 |
| 可读待恢复采集|资料核对通过但调度暂停，避免恢复副本重复访问来源 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

仅所有者或明确授权维护者操作恢复和下载备份；恢复环境默认限制访问，不能自动继承旧的公开分享或已撤销权限。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

- **依赖或关联 PRD：**[020 数据与使用设置](020-数据与使用设置.md)、[031 可靠执行与幂等](031-可靠执行与幂等.md)、[035 权限与数据隔离](035-权限与数据隔离.md)、[036 数据访问与生命周期](036-数据访问与生命周期.md)、[039 可观测与可运维](039-可观测与可运维.md)、[042 容量与部署可重复性](042-容量与部署可重复性.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**使用 B0 规模或注明差异的真实备份在全新隔离环境演练，验证至少一种损坏备份和一次删除记录重放；提供耗时、对象计数、证据抽样及失败日志。少量样本还原不能证明 B0 的 RTO。

总纲质量目标：B0 初始建议 RPO ≤24 小时、RTO ≤2 小时；以隔离环境实际恢复和抽检报告为准，包含配置、关系和证据链接检查；不视为已承诺 SLA。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-030 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-032-001 | 总纲场景继承 | 隔离环境丢失业务存储 | 使用已保存备份恢复 | 在目标范围内恢复；已到期删除数据不会因恢复长期重新出现。 |
| AC-032-002 | 备份范围完整 | 数据含主题、事件、评论关系与外部证据附件 | 生成并核查备份清单 | 一致性时间点、各类对象及缺失附件均可核对 |
| AC-032-003 | 坏备份与权限 | 新备份损坏且普通读者尝试下载 | 执行校验与访问 | 拒绝未授权下载，坏备份不覆盖上一有效备份，风险提示可见 |
| AC-032-004 | 完整恢复计时 | B0 数据备份和隔离的新环境已指定 | 从恢复处置开始直到核心读取、受控本地写入及核对完成 | 包含准备和校验的 RTO 与真实 RPO 有记录，达到目标才判通过；外部采集仍按恢复启用规则暂停 |
| AC-032-005 | 删除重放 | 备份含后来已删除的对象或已撤销分享 | 恢复并准备开放读取 | 先应用删除和撤权；缺少必要记录时阻止开放相关资料 |
| AC-032-006 | 恢复后调度 | 恢复数据包含原来的运行中监控 | 启动恢复环境 | 用户可核对资料，采集保持暂停直到连接、权限和预算确认有效 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
