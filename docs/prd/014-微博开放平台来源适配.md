# 微博开放平台来源适配

## 用户问题

当前仓库没有微博连接器；参考项目提供微博关键词结果。

## 产品目标

在微博开放平台批准的权限范围内采集关键词或授权账号信号，并映射为可追溯内容和指标。

## 范围

- 微博应用授权与健康检查
- 关键词/账号能力档案
- 内容、转发关系和指标映射
- 配额、权限与删除同步

## 用户故事

- 作为编辑者，我能选择真实可用的来源能力并预览查询结果。
- 作为管理员，我能配置授权、健康、配额和失败处理，而看不到明文密钥。
- 作为阅读者，我能识别原始事实、派生内容和不可用来源。

## 功能要求

- FR-014-1：使用 OAuth2 和官方批准接口，凭据只通过 env 引用；不得抓取搜索页、热搜页或移动接口。
- FR-014-2：将关键词搜索与账号时间线作为不同 capability，发布 Monitor 时只允许连接实际获批的能力。
- FR-014-3：以微博 ID、created_at 和分页游标去重，保留转发关系、作者、正文、链接和官方公开指标。
- FR-014-4：接口权限不足、审核未通过或配额过低时连接保持 degraded/disabled，并给出替代 RSS 来源。

## 非功能要求

- 外部请求必须具备固定端点、DNS/重定向复验、超时、限流和最大响应限制。
- 凭据只保存 `env:NAME` 引用；日志、错误、证据和前端不得暴露 Token。
- 采集、重试和人工触发保持幂等，可在 CollectionRun 中追踪。

## 非目标

不保证第三方未授权或已退役能力与参考项目保持表面一致。

## 验收标准

- AC-014-1：无批准 scope 无法启用对应能力
- AC-014-2：分页重试不重复内容
- AC-014-3：删除或不可见内容按授权条款执行同步
