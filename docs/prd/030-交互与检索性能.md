# 交互与检索性能 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-004，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/030-交互与检索性能计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

外部采集可能缓慢或失败，但用户仍应快速浏览已有资料。性能要求必须说明数据规模、并发与缓存状态，不能只写一个秒数。

总纲原始要求：核心页面读取与外部采集解耦；列表、筛选、事件详情在既定数据规模可用；长任务有即时受理反馈和进度。

后台正在抓评论和导出报告，研究者打开事件、筛选历史和提交新任务，已有资料读取不应被阻塞。

## 2. 目标与成功指标

**BR-030-001：**在明确资源与负载条件下保持核心交互可用，对耗时操作快速受理并清晰反馈进度。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 列表/详情本地 API|B0 热缓存有效请求 P95|≤2 秒 |
| 检索/趋势本地 API|B0 热缓存有效请求 P95|≤3 秒 |
| 任务受理/冷缓存|任务受理 P95；冷缓存同类读取独立记录|≤1 秒；冷读取目标 ≤5 秒 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**本地接口响应、长任务异步受理、并发读、分页上限、前端加载状态与性能报告。
- **明确不包括：**以上游接口耗时背书本地性能、无界全库返回、不同硬件轻量测试冒充 B0。
- **与相邻能力的边界：**采集整体时延由 029 衡量；本模块不从受理速度推断采集完成速度，也不要求在 HTTP 内执行采集。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 冻结 B0 数据集、硬件、版本及测试请求分布。
2. 分别测试预热与冷缓存/重启后场景。
3. 同时运行代表性的采集、导出或分析后台负载。
4. 记录接口耗时、失败、超时及用户可见页面状态。
5. 定位未达标场景，调整后在相同基线复测并保留结果。

完成后用户获得：可重现的性能基线、阶段耗时与核心交互体验证据。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| B0 数据|10 主题、20 账号、10万作品、50万评论、100万指标快照|记录文本长度与事件大小分布 |
| B0 资源|总服务预算 4 vCPU、8 GiB RAM、SSD|版本与实际配置不可省略 |
| 负载|5 个并发读取会话，热测 15 分钟且≥1,000 请求|冷测独立，不混平均 |
| 请求范围|列表、详情、检索、趋势、任务受理|分页参数和过滤复杂度冻结 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-030-001 | 测量边界 | 本地 API 从请求到响应完成计时；用户首屏另记录浏览器/网络，不能把两者混为同一指标。 | AC-030-002 |
| NFR-030-002 | 异步长操作 | 采集、分析、导出先持久受理并返回任务记录；受理目标不等待来源、推理或文件生成。 | AC-030-002 |
| NFR-030-003 | 负载真实 | 使用 B0 规模和代表性过滤，后台任务同时存在；不在微小样本或全缓存命中上替代整体测试。 | AC-030-003 |
| NFR-030-004 | 结果完整 | 报告 P50/P95/最大值、请求量、错误/超时；有效请求指符合身份、参数和声明负载的请求，包含执行失败与超时。成功样本分位数与全体耗时分布分别报告，超时以实际等待及未完成状态保留；不能删慢请求或用快速报错达标，未解决的内部失败不得仅凭 P95 达标判通过。 | AC-030-004 |
| NFR-030-005 | 资源有界 | 分页、批量读取与排序有边界；用户超限查询应明确拒绝或转异步，不能拖垮其他阅读。 | AC-030-005 |
| NFR-030-006 | 用户反馈 | 加载、排队、失败和取消可识别；慢任务仍可查看已持久资料，不用永久转圈掩盖故障。 | AC-030-006 |

**DEC-030-001：**把外部任务与本地阅读解耦，以固定 B0 和完整请求记录验证响应目标。

以上规则解释 NFR-001-004，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 可响应/加载|保留现有资料并展示实际加载阶段。 |
| 超限/长任务|说明异步处理或缩小范围，不静默截断结果。 |
| 超时/降级|明确错误与重试范围，不能无限加载。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

性能测试使用隔离数据和授权环境，不对真实平台压测；真实私有资料不可写入公开测试报告。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

- **依赖或关联 PRD：**[009 采集任务控制](009-采集任务控制.md)、[014 历史内容检索与筛选](014-历史内容检索与筛选.md)、[018 基础报告与数据导出](018-基础报告与数据导出.md)、[022 自动分析增强](022-自动分析增强.md)、[042 容量与部署可重复性](042-容量与部署可重复性.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**严格 B0：4 vCPU/8 GiB/SSD，固定数据规模与 5 并发；预热后 15 分钟≥1,000 有效请求，冷缓存独立测；后台负载和失败一并报告。

总纲质量目标：B0 热缓存下本地 API：列表/详情 P95 ≤2 秒，检索/趋势 P95 ≤3 秒，提交任务 P95 ≤1 秒；冷缓存分别记录，目标 ≤5 秒；外部网络不计入本地接口耗时，但在任务时延中完整呈现。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-028 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-030-001 | 总纲场景继承 | B0 规模已有数据且外部来源超时 | 并发读取页面与提交任务 | 本地操作满足目标，采集不阻塞浏览；不隐藏失败任务。 |
| AC-030-002 | 外部慢 | 来源请求持续超时 | 本地读详情并提交任务 | 读与受理仍满足独立目标，采集状态显示失败/延期 |
| AC-030-003 | 真实规模 | 加载 B0 且运行导出 | 执行混合读取 | 按实际负载报告，不切换小库声称通过 |
| AC-030-004 | 慢与失败 | 测试含慢请求和超时 | 汇总结果 | 保留它们的记录、失败率和尾延迟 |
| AC-030-005 | 大查询 | 用户请求超出分页上限 | 访问接口 | 明确限制或异步，不拖垮其他用户读取 |
| AC-030-006 | 界面等待 | 后台任务耗时较长 | 查看页面并取消 | 有阶段和操作反馈，不无限转圈或假完成 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
