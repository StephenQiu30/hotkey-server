# 凭据与应用安全 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-008，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/034-凭据与应用安全计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

来源连接、公开正文和导出文件都是安全边界。连接凭据泄漏会影响用户账号，恶意正文和目标 URL 可能把阅读或采集变成非预期操作。

总纲原始要求：连接秘密不出现在前端响应、日志、代码库或普通导出中；控制存储和传输权限；外来正文按不可信内容处理，采集 URL 与导出内容有安全边界。

使用者保存 X 会话后只能看到连接状态；采集到包含脚本或表格公式的评论时，页面和导出都只把它当作文本。

## 2. 目标与成功指标

**BR-034-001：**使核心流程在身份、秘密处理、外来内容和网络目标四个边界上可验证地安全。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 秘密泄漏数|受测响应、日志、错误、页面及普通导出中出现可用秘密的次数|0，凭据设置后不可通过普通查询回读 |
| 未授权操作数|未登录、无权限或伪造请求获得受保护结果的次数|0 |
| 恶意数据执行数|受控脚本、公式和未授权网络目标样本导致执行或访问的次数|0，覆盖正常显示、导出和重定向路径 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**登录与会话保护、连接秘密管理、传输和存储访问、正文展示、导出安全及采集/通知目标校验。
- **明确不包括：**宣称通过渗透认证、提供平台访问绕过、在 PRD 阶段开展真实攻击、用安全功能替代来源授权条件。
- **与相邻能力的边界：**035 管资源级授权，036 管数据来源与保留。本文件限制技术暴露面；用户明确配置的自建通知目标需独立可信配置流程，不能等同于任意采集 URL。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 用户完成身份验证，在受保护界面配置来源凭据或可信连接。
2. 系统只保存受控秘密引用并返回脱敏状态，错误提示不回显秘密。
3. 接收内容和 URL 时按用途验证来源、目标、格式及大小。
4. 页面、导出和分析将正文视为不可信数据，不执行其中指令。
5. 验证失败时拒绝相关动作，保留脱敏原因并允许安全修正。

完成后用户获得：可正常使用的受保护连接和不会执行外来内容的资料。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 秘密字段|会话、令牌、密码及解密材料均标敏感；不可进入 URL 查询参数或普通日志|输入后掩码，只展示是否配置和更新时间 |
| 身份会话|过期、注销和撤权后拒绝后续受保护操作|会话策略在 Design 明确，错误避免账户枚举 |
| 网络目标|区分平台采集地址、用户原文链接和管理员可信通知地址|默认仅允许所需协议与来源；拒绝用户控制的未授权内部目标 |
| 正文与导出|文本、链接、媒体和公式前缀分别处理|展示原意，安全处理结果可说明但不执行 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-034-001 | 身份与会话保护 | 未登录请求不能获取业务正文、任务结果或连接；修改类操作须校验有效身份并防止非预期跨站请求，注销/过期后旧会话不可继续操作。 | AC-034-002 |
| NFR-034-002 | 秘密全链路保护 | 秘密仅由必要执行路径使用，前端只收脱敏状态或引用；日志、追踪、异常堆栈、数据库普通查询视图、仓库和导出不暴露明文。存储及传输使用适当保护，密钥与密文分开管理。 | AC-034-003 |
| NFR-034-003 | 外来内容仅作数据 | HTML、脚本、危险链接及嵌入内容不能在正文、摘要、通知预览中执行；模型不能因正文中的指令读取凭据、调用工具或改变监控配置。 | AC-034-004 |
| NFR-034-004 | 安全导出 | CSV 等表格格式对公式触发字符及其空白/控制字符变体作安全处理，引用和 JSON 保持内容含义；文件名、下载响应及路径不允许目录穿越或主动内容执行。 | AC-034-005 |
| NFR-034-005 | 网络目标边界 | 采集目标按平台域名、协议、解析地址及重定向逐跳校验，拒绝未授权内网、回环和元数据地址。用户配置自建通知目标须经管理员独立许可，不能通过通用 URL 输入借道访问。 | AC-034-006 |
| NFR-034-006 | 最小权限与失效处置 | 执行组件只得到所需秘密和数据权限；凭据撤销后停止新请求并清理可用缓存引用，泄漏处置可撤销和更换。安全错误脱敏且不泄漏资源是否存在。 | AC-034-002、AC-034-003 |

**DEC-034-001：**把公开正文视为不可信数据，把用户输入的采集 URL 与受控自建连接分开验证；便利性不扩大执行权限。

以上规则解释 NFR-001-008，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 身份无效|引导重新登录，不把未授权结果缓存为正常页面 |
| 连接秘密失效|暂停对应来源并提示更新，不能显示原秘密供复制 |
| 内容或目标被拒绝|说明被拒绝的类别和可修正项，错误不回显秘密或内部地址细节 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只有连接所有者或明确授权维护者可创建、替换和撤销秘密；普通读取、分析和导出权限不包含读取秘密。安全验证使用受控样本与测试地址。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

关联 [043 模型服务接入与模型配置](043-模型服务接入与模型配置.md)：M6 追加模型密钥、目录/推理端点及出站白名单验证；保存设置不推理，模型测试显式受理，密钥不回读且不交给浏览器。 本项先行能力不依赖 043 完成；扩展进入范围时追加验证。

- **依赖或关联 PRD：**[004 平台与连接管理](004-平台与连接管理.md)、[007 作品资料与上下文](007-作品资料与上下文.md)、[018 基础报告与数据导出](018-基础报告与数据导出.md)、[022 自动分析增强](022-自动分析增强.md)、[024 离线可达提醒](024-离线可达提醒.md)、[035 权限与数据隔离](035-权限与数据隔离.md)、[036 数据访问与生命周期](036-数据访问与生命周期.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**在隔离环境覆盖登录/注销、秘密不可回读、HTML/Markdown 恶意正文、CSV 公式变体、URL 重定向与内部地址拒绝等受控样本；同时验证合法平台 URL 与明确获准的自建通知目标不被误伤。运行日志和浏览器实测为证，文档不构成已通过安全测试。

总纲质量目标：验证未登录访问被拒绝、秘密字段不可回读、恶意正文不执行脚本、导出不执行表格公式、用户输入不能使服务访问未授权内部地址。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-032 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-034-001 | 总纲场景继承 | 输入含脚本或公式内容并存在已配置凭据 | 显示、导出并检查访问日志 | 内容仅作数据处理；凭据不泄漏；未授权请求被拒绝。 |
| AC-034-002 | 会话失效 | 受保护资料和有效登录会话存在 | 注销后复用旧请求或发起未授权修改 | 读取和修改均拒绝，不泄漏资料及存在性细节 |
| AC-034-003 | 秘密不回读 | 已保存测试凭据并模拟带秘密的上游异常 | 查看连接、任务日志、普通导出和错误响应 | 只见脱敏信息；撤销后新请求无法继续使用旧秘密 |
| AC-034-004 | 恶意正文 | 正文含脚本、危险链接及要求读取凭据的指令 | 在页面、摘要和通知预览展示 | 没有脚本执行或工具操作，正常文字可读 |
| AC-034-005 | 表格与文件边界 | 导出文本含公式、前置控制符和危险文件名 | 生成并在目标表格工具检查导出 | 内容作文本处理，不执行公式，不产生越界文件路径 |
| AC-034-006 | 重定向与自建目标 | 普通采集 URL 跳转内部地址，另有已授权自建通知连接 | 分别执行目标验证 | 普通采集被拒绝；自建连接仅在明确许可范围工作，不能扩大为任意网络访问 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
