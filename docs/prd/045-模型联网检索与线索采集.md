# 模型联网检索与线索采集 PRD

日期：2026-09-17。依据用户“两种都需要，分别设计采集入口”的澄清，新增 FR-001-027。本文件 draft，[调研](../research/045-模型联网检索与线索采集调研.md)、[设计](../design/045-模型联网检索与线索采集设计.md) 和 [Plan](../plans/045-模型联网检索与线索采集计划.md) 分别为 draft / proposed / planned，未实现或验收。

## 1. 背景和用户目标

模型网关还可接入搜索工具获取当前网页和部分社交信息。需要把搜索调用、摘录、原文及模型归纳分别保存，并与既有关键词/评论链路衔接。

**BR-045-001：**通过 OpenRouter、Vercel 支持的联网检索组合发现有引用的线索，按成本与覆盖边界补充热点研究。

## 2. 成功指标

| 指标 | 口径 | 目标 |
|---|---|---|
| 证据可追溯 | 展示为已检索线索的条目 | 全部有真实搜索来源和 URL，缺失不发布 |
| 越权和收费派发 | 费用/工具/域名/撤权故障矩阵 | 被禁止的派发数为 0 |
| 检索质量 | 冻结中文主题集的相关率、引用可达率和重复率 | 由 041 在 S00 冻结阈值，单列无法确认/无结果 |
| 覆盖真实性 | 声明全量评论/账号轨迹的线索 | 0 项未经平台验证的覆盖声明 |

以上是待验证目标；当前公开资料读取不计产品验收，数值目标在实施前冻结。

## 3. 范围、优先级和非目标

本期建议 **P1 / M6**：独立的模型联网入口、模型/API/引擎能力矩阵、主题查询、只读搜索工具、引用与原文状态、事件关联、次数/费用/活动到期控制。

明确不包括：默认付费推理或搜索、无限 Agent 循环、通用工具执行、登录/发帖/私密信息、以摘要代替完整评论树、承诺全量账号作品或 X 已接入。

与相邻功能的分工：043 管模型调用配置，044 管平台官方信息，045 管模型联网线索；021 负责通用热榜/Feed，005/006/008 仍分别负责原生搜索、作者作品及评论。不同入口均可关联同一事件，但保留来源与覆盖差异。首次补充信息源不改变 P0 34 项的发布门槛。

## 4. 用户流程

1. 在主题中选择“联网检索补充”，查看候选网关/模型/搜索引擎的能力、覆盖和完整费用。
2. 选择日期/域名或支持的账号范围，预览最小外发查询；条件不满足时显示不可用原因。
3. 显式发起有界检索，记录实际搜索步骤和用量；定时运行须单独启用并受同一预算约束。
4. 查看引用线索、摘录与模型归纳；无搜索证据的回答不显示为检索成功。
5. 按需获取已验证安全 URL 的原文并关联事件；社交作品交给原平台连接器补充评论/账号资料。

打开页面、保存配置或预览缓存不自动发生采集/推理；显式启用的定时任务按同一规则执行。

## 5. 输入和展示信息

| 信息 | 规则 |
|---|---|
| 组合能力 | 网关、模型 ID、API 格式、搜索工具/引擎、支持的域名/日期/账号过滤及硬上限；声明与实测分开 |
| 查询与外发 | 关键词、时间/域名/账号范围、外发上下文白名单与配置版本；不发密钥、会话和内部备注 |
| 预算和资格 | 模型 token、每次搜索/额外结果/媒体/重试费用分别核查；活动到期、最大搜索次数/结果/耗时 |
| 结果 | 运行/搜索步骤 ID、引擎、引用 URL/标题/摘录、原文状态、模型归纳、发布时间与检索时间、失败/部分标识 |

配置留版本、操作者和生效时间；当前权限、停用和更紧预算优先于旧配置。空字符串、重复项和超长输入校验规则于 G2 冻结，拒绝静默改变用户范围。

## 6. 详细业务规则

| ID | 规则 | 行为 | 验收 |
|---|---|---|---|
| FR-045-001 | 入口与能力准入 | 独立标识模型联网来源；按网关＋模型＋API＋工具/引擎验证能力；不得把 SDK 支持当网关可用；不支持的筛选或硬上限明确拒绝，不静默忽略 | AC-045-002 |
| FR-045-002 | 全链费用与预算 | 复用 043/037，推理和工具/附加项均须为已核查零付费；固定引擎，不用 auto 隐式收费回退；限制搜索次数/结果/时长，记录活动截止并到期停止，禁止充值 | AC-045-003 |
| FR-045-003 | 查询与工具安全 | 外发前展示并授权必要查询/范围；只允许白名单只读搜索与受控抓取，正文/搜索结果不能更改工具、扩大域名范围或获取秘密；每次派发检查当前权限 | AC-045-004 |
| FR-045-004 | 结果证据分层 | 保留真实搜索调用、引用、摘录与原文状态；模型归纳单独标注；无引用/无搜索调用、流中失败或结构不符不得报完整采集成功；缺日期不伪造 | AC-045-005 |
| FR-045-005 | 事件与补采 | 规范化来源 URL 去重并保留发现链；关联事件及人工修订；引用安全可达时才补原文；X 等评论/账号需求交给平台连接器，不能由摘要伪造帖子/回复 | AC-045-005 |
| FR-045-006 | 恢复与可观测 | 记录各搜索步骤/费用和部分结果；超时结果未知不盲重试，取消不抹账；全部模型搜索停用时免费直接来源/爬虫和已有资料可用；质量按真实引用可核查性评估 | AC-045-006 |

**DEC-045-001：**模型联网作为有证据的补充发现入口；按查询授权只读工具，调用和结果有界，不能替代平台评论与作者采集。

## 7. 非功能约束、状态与权限

复用 027/028 的证据与未知字段、031/033 的幂等降级、034—037 的授权/外发/预算、039 的观测与 041 的效果评估；模型回答流畅度不作为质量指标。不得用真实平台压测；受控引擎故障与真实小样本检索分别记录。

未配置、组合未验证、无零付费方案、待启用、排队/检索中、有结果、无结果、无搜索证据、部分、次数上限、活动到期、结果未知、已取消、无权限分别显示；不通过伪造结果隐藏不可用。

所有者仅查询自己的主题并使用获授权连接；维护者管理组合白名单和费用政策，无自动正文权限；其他身份默认拒绝。模型/搜索返回不能授予任何新权限。

删除、撤权、原文失效及保留期传播至缓存、证据和导出；不能因公开入口而绕过个人研究资料权限。受控测试不包含生产密钥/账号会话或付费请求。

## 9. 验收标准

第一项完整继承 AC-001-043；其余覆盖具体边界。所有场景待执行，复合前提须拆成可独立失败的用例。

| AC | 场景 | Given | When | Then |
|---|---|---|---|---|
| AC-045-001 | 总纲场景继承 | 已选择具备联网能力的模型与检索工具组合 | 以主题关键词发起有界检索 | 返回可追溯线索与引用并区分摘录、原文和模型归纳；费用不满足时不派发，不把结果当作全量评论或账号作品 |
| AC-045-002 | 组合验证 | SDK 声称支持某工具，但目标网关/API 不支持日期过滤或次数硬上限 | 尝试启用并提交检索 | 显示组合能力未验证/不支持并阻止执行；支持的组合保留真实工具调用证据，不能只凭回答文字报联网成功 |
| AC-045-003 | 搜索费用 | 模型零价但搜索收费、促销临近到期、并发任务竞争预算和模型尝试重复搜索 | 派发、执行下一搜索步骤、跨活动到期或重试 | 任一费用未知/收费均拒绝；到期停用，次数/结果/资源不超本地硬上限；不切付费引擎、不充值；每步计量 |
| AC-045-004 | 外发及越界 | 查询含内部备注、返回内容要求调用任意工具，引用指向内网或用户撤权 | 生成查询、执行工具或补抓 URL | 只外发授权字段；拒绝额外工具和危险网络目标，撤权停止新派发；密钥/社交会话不泄漏 |
| AC-045-005 | 结果与评论边界 | 结果含重复 URL、摘录、无引用回答、缺日期以及 X 帖子线索 | 保存、关联事件并请求评论 | 线索/原文/归纳分层，去重保留来源；无引用回答不冒充资料，未知日期保留；评论只经有能力的平台连接器补采，不伪造回复树 |
| AC-045-006 | 部分与降级 | 搜索流中错误、超时结果未知、取消或服务停用，存在历史结果 | 查看运行记录、恢复及继续基础监控 | 保留部分/未知与每步消耗，不自动重发结果未知请求；历史可查、人工可整理、直接来源不受阻，不将失败结果发布为完整 |

证据须含输入/配置版本、执行时间和环境、实际持久结果、用户界面与故障判定；必要真实接口、数据库/消息、浏览器验证各自保留，不用一个绿测摘要代替。
