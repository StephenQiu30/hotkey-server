# 作品资料与上下文 PRD

日期：2026-09-22。状态：需求已接受；承接既定范围 FR-001-005，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [Design](../design/007-作品资料与上下文设计.md) 已接受 S00—S01，[执行计划](../plans/007-作品资料与上下文计划.md) 为 in_progress；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

只有标题或互动数不足以支撑事件判断。平台字段不同、缺失与真实零混淆、引用作者归属错误都会污染后续分析。

总纲原始要求：保存原生 ID、链接、作者、标题/正文、作品类型、发布与观测时间、可用互动指标；缺失项明确；区分原创、转载、引用、回复及删除/不可见状态。

研究者打开同一作品由两个关键词发现的记录，要确认正文是否完整、作者是谁、互动数据何时观察，以及原文是否仍可访问。

## 2. 目标与成功指标

**BR-007-001：**将作品资料规范为可核对的证据，同时保留平台语义、版本变化和缺失信息。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 身份与关系正确性|已标注样本的原生 ID、作者、引用关系|100% 一致 |
| 来源完整性|作品可定位来源任务与原始链接|100% |
| 缺失表达|缺失字段被误写为 0 或编造正文的次数|0 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**作品详情、原文标识、作者公开信息、内容完整度、引用/转帖关系、指标快照及可见性状态。
- **明确不包括：**默认下载媒体、识别真实身份、平台内容真实性裁决、把搜索摘要补写成完整正文。
- **与相邻能力的边界：**作品是证据对象；事件负责组织作品，评论是独立关系，媒体补充属于 023。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 接收来源返回的作品与获取范围。
2. 以平台原生 ID 识别实体并保留发现入口。
3. 展示正文/摘要、作者、发布和观测时间及内容关系。
4. 新采样追加指标，内容变化保存版本而不覆盖原观察。
5. 原文不可访问时显示最后可见记录与当前可用性。

完成后用户获得：可追溯作品详情、发现关系、内容版本和带时间的互动快照。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 作品身份|平台+原生 ID 必需，JSON 按字符串表达|没有可信 ID 时只保留为线索，不创建完整作品实体 |
| 正文范围|全文、摘要、截断、仅媒体分别标记|不可自行补全文 |
| 时间与指标|发布时间、采集时间、指标观测时间分开|缺失为未知；0 原样保留 |
| 关系与作者|原作者、引用者、被引用作品、转帖关系分别记录|未获得原文时保留引用标识 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-007-001 | 实体唯一 | 同平台同 ID 复用作品，发现入口与主题关系可多条；跨平台同内容不合成同一个原生作品。 | AC-007-002 |
| FR-007-002 | 字段口径 | 评论、回复、弹幕、播放、点赞分别保存含义；不可获取为 null/未知，不用 0 补齐。 | AC-007-003 |
| FR-007-003 | 正文完整度 | 摘要与完整正文有标签；截断说明边界；机器提取内容有独立来源，不冒充平台原文。 | AC-007-004 |
| FR-007-004 | 时间与快照 | 每次观察记录时间；有效重复采样可以追加快照，但相同观察的重投不得重复计算。 | AC-007-005 |
| FR-007-005 | 内容变更 | 正文编辑生成新版本，旧分析指向当时版本；未实采不能伪造变更历史。 | AC-007-006 |
| FR-007-006 | 可见性 | 删除、受限、临时获取失败与未知状态区分；来源暂时失败不立即认定作品删除。 | AC-007-006 |

**DEC-007-001：**保留平台原生语义和采集范围，规范化不意味着填补未知或抹平不同内容类型。

以上规则解释 FR-001-005，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 完整/部分正文|展示完整度与原文入口；部分内容仍可研究但需提示。 |
| 关系缺失|显示被引用或父作品未获取，不制造占位正文。 |
| 不可见/暂时失败|保留状态及观测时间，按照生命周期规则处理可保留内容。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

作品读取、导出与变更历史仅对有权用户开放；公开来源内容也不能越过本系统资源授权。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

信息获取补充：044 模型资料/官方公告、045 搜索线索采用独立类型并保留来源，不能伪造成完整社交作品；摘录、原文和模型归纳区分。 详见 [044 PRD](044-模型平台信息采集与变更监控.md)、[045 PRD](045-模型联网检索与线索采集.md)。这些是后续接入关系，不将本项 P0/先行能力改为依赖它们。

- **依赖或关联 PRD：**[005 关键词主动发现](005-关键词主动发现.md)、[006 指定用户作品追踪](006-指定用户作品追踪.md)、[008 评论与回复采集](008-评论与回复采集.md)、[012 事件详情与发展时间线](012-事件详情与发展时间线.md)、[016 证据引用与分析修订](016-证据引用与分析修订.md)。

- **验证口径：**使用正文编辑、跨主题重复、零互动、缺指标、引用原文不可见及删除/网络失败样本做逐字段核对。

来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-005 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-007-001 | 总纲场景继承 | 同一作品被多个入口发现，且部分字段不可用 | 写入和展示详情 | 同一平台 ID 只有一个作品实体、多条发现依据；缺失不显示为零，原文可追溯。 |
| AC-007-002 | 跨主题 | 两主题发现同一个原生 ID | 合并保存 | 一个作品实体保留两个发现关系 |
| AC-007-003 | 零与缺失 | 点赞为 0、浏览量缺失 | 展示与导出 | 分别为 0 和未知，不混同 |
| AC-007-004 | 摘要展示 | 来源只返回摘要 | 查看详情 | 明确摘要且不声称已理解完整媒体 |
| AC-007-005 | 重复观测 | 同一观察被重复投递，随后获得新快照 | 更新指标 | 重投不重复计数，新快照保留独立观测时间 |
| AC-007-006 | 编辑与失败 | 正文变化后来源短暂超时 | 再次查看 | 编辑历史可追溯，临时失败不变成已删除 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
