# 评论会话采集与采集运行时边界

## 用户目标

在多源 AI 热点已经发现并判定相关后，用户可按需获取受支持来源的评论/回复会话，用于观察讨论热度、立场、情绪与纠正线索，同时保留可引用的父子关系、原始证据、权限依据和失败原因。

本 PRD 是 035 之后的候选增强，当前为 `draft`，不属于正在交付的首版。

## 功能要求

- FR-036-1：只有 Accepted Match 或达到配置阈值的根内容才能创建会话增强任务，任务不得阻塞根 Document/MicroEvent 主链。
- FR-036-2：每个来源必须在采集前返回可审计的 Rights 与 Capability 决策；只允许官方 API/Feed/Webhook 或有书面授权的爬取。
- FR-036-3：首批只使用 X Conversation API 和 Hacker News 官方 item API 获取评论/回复，不引入浏览器运行时。
- FR-036-4：会话项必须保存内容类型、直接父 ID、根会话 ID、关系类型、来源和证明关系的 Evidence Reference；`comment` 不得被改为 `post`。
- FR-036-5：父项尚未入库时仍可保存外部 ID，后续只通过追加事实解析，不改写历史 Observation 或证据。
- FR-036-6：每任务必须限制时间窗口、项数、页数、深度、字节数、墙钟时间和上游配额，并保存游标与幂等键。
- FR-036-7：单个来源的无权、不支持、配额、限流、解析或运行时失败必须独立呈现，不允许隐式 HTML/浏览器回退。
- FR-036-8：评论可用于热度、立场、情绪和纠正线索分析，但同一根内容的多条评论不计为多个独立真实性来源。
- FR-036-9：删除、撤回、更正、授权撤销和保留期复用现有 Rights/Evidence 生命周期，无权后不得继续展示或使用评论正文。
- FR-036-10：非 Go Worker 只能在单独 Design/PRD/Plan 批准后作为 `ConversationFetcher` 适配器接入，任务、凭据授权、Rights、预算、证据入库和状态机仍由 Go 核心服务管理。

## 非功能要求

- 任务必须可重试、可续传、可停止且幂等，不依赖内存游标。
- 关系与正文必须可追溯到不可变 Observation/Evidence，不从日志或模型输出重建原始事实。
- 不在持久任务、日志、审计或 Worker 输出中保存用户 Cookie、长期 Bearer Token 或原始凭据。
- 不使用图数据库、新消息总线或第二套 Document/Event 事实链。

## 不在本范围

- 035 首版中的评论正文抓取、评论树 UI 和评论通知。
- 未经书面授权的 Bilibili 评论/弹幕爬虫。
- 绕过登录、验证码、设备指纹、反爬、配额或平台权限。
- 从 Bing/Google 搜索结果页隐式转为目标站爬虫。
- 通用爬虫平台、动态插件系统、图数据库、Python/Scrapy 服务或默认 Playwright 集群。
- 将评论数量或模型情感分数宣称为事件真假。

## 验收标准

- AC-036-1：X 和 HN 官方 API 能为指定根项返回有界的评论/回复，并保存 parent、root、relation 和 Evidence Reference。
- AC-036-2：多级回复、父项晚到、删除评论、重复页、断点续传和重试均不产生重复或被改写的关系事实。
- AC-036-3：非 Accepted/非热点根项不会排队；到达数量、深度、时间、字节或配额上限时可预期停止并保存游标。
- AC-036-4：未授权 Bilibili 任务在任何 HTTP/浏览器请求之前返回 `policy_blocked`；微博权限不足时返回明确 capability/authorization 错误。
- AC-036-5：同一根项下的多条评论不会增加独立 origin 数量，不得单独将 EvidenceState 提升为 `multiple_origins`。
- AC-036-6：关闭会话增强消费者后，035 的多源发现、相关性、MicroEvent、WebSocket 和邮件主链仍可独立运行。
- AC-036-7：未批准单独运行时设计时，生产启动图中不存在 Playwright、Scrapy 或通用爬虫服务。

## 待评审项

- 是否接受“Go 核心 + 按需会话增强 + 可选隔离浏览器 Worker”边界。
- 是否将第一批实现限定为 X 和 Hacker News，微博只做权限探测，Bilibili 保持 `policy_blocked`。
- 产品是否确实需要保存评论正文，还是只需要统计指标和短期分析结果；该决定会影响保留、删除和成本边界。
