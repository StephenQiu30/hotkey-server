# 数据与使用设置 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-018，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/020-数据与使用设置计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

用户需要控制账户会话、研究资料的保留以及停止监控和删除的不同后果。模糊的删除按钮可能使任务继续产生数据或误删共享证据。

总纲原始要求：登录/退出、当前使用者的配置与结果访问；可设置数据保留期、删除主题/数据、导出备份；区分停止监控、归档和彻底删除的影响。

用户暂停一个主题但保留历史，随后决定删除自己的研究资料，并要求备份恢复后不会再次出现已删除内容。

## 2. 目标与成功指标

**BR-020-001：**提供清晰的使用与数据控制，使身份访问、监控生命周期和资料删除按用户意图执行。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 生命周期语义|暂停/归档/删除的预期行为对照|全部场景通过 |
| 删除一致性|删除范围内数据仍可查询/导出的次数|0 |
| 设置留痕|关键配置修改可定位操作者与版本|100% |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**登录退出及会话状态、个人偏好、保留期、停止/归档/删除、数据范围预览和备份/导出入口。
- **明确不包括：**企业组织与计费管理、静默删除其他用户资料、借退出删除业务数据、恢复旧实现数据库。
- **与相邻能力的边界：**本模块提供控制入口与业务承诺；凭据安全、隔离、生命周期和恢复分别由 034/035/036/032 约束。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 登录后查看当前身份、连接和个人设置。
2. 修改偏好或保留规则，预览将影响的资料范围。
3. 对主题选择暂停、归档或删除，显示三个动作区别。
4. 执行高影响删除前确认对象与范围，立即停止相关新任务并收回读取。
5. 查看清理进度和结果，备份恢复时继续应用删除要求。

完成后用户获得：可核查的个人设置、访问状态和数据处理记录。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 身份与会话|只能操作自己授权范围；退出使会话失效|不回显秘密 |
| 偏好|时区、展示语言、通知设置|时间存储语义不随展示时区改变 |
| 保留期|建议结构化资料 30 天、临时证据 7 天；需来源条件许可|缩短时预览影响，不静默即时物理删除 |
| 删除范围|主题关联、指定资料、整套个人资料分别选择|默认最小范围，说明跨主题影响 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-020-001 | 会话控制 | 退出后新请求需重新认证，未完成任务依部署策略显式继续或暂停，不靠关闭页面取消。 | AC-020-003 |
| FR-020-002 | 动作区分 | 暂停停新调度但保留数据；归档隐藏活跃入口并保留历史；删除按选定范围停止采集并收回资料。 | AC-020-002 |
| FR-020-003 | 保留变更 | 缩短期限展示将到期对象与处理时间，延长期限不能恢复已经删除的内容。 | AC-020-004 |
| FR-020-004 | 删除关系 | 跨主题共用作品时明确删除关联还是证据；要求删除证据则处理全部受影响派生结果。 | AC-020-005 |
| FR-020-005 | 异步清理 | 逻辑拒绝读取立即生效，物理清理按 036 时限执行，结果与失败可查询；不会显示虚假清理完成。 | AC-020-006 |
| FR-020-006 | 备份一致 | 导出/备份入口遵守权限，恢复必须重放删除记录，临时下载有期限。 | AC-020-006 |

**DEC-020-001：**将暂停、归档、删除和退出明确分开，数据控制以用户确认的范围为准。

以上规则解释 FR-001-018，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 已登录/会话过期|过期返回登录入口，输入草稿可保留但不泄漏资料。 |
| 删除处理中/完成/失败|显示范围、已经不可读的状态和剩余步骤。 |
| 设置冲突|来源保留条件更严格或权限不足时明确拒绝，不静默扩大。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

所有者可操作自己的资料；维护者按授权清理，但不因系统权限自动获得内容阅读或导出权。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-018 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-020-001 | 总纲场景继承 | 用户暂停主题后再发起删除数据 | 查看任务与存储结果 | 暂停保留历史，删除按明确范围清理并停止后续采集；两个动作语义不混淆。 |
| AC-020-002 | 动作区别 | 主题已有资料和在途任务 | 依次测试暂停、归档、删除 | 分别保持明确语义，删除后不继续生成受影响资料 |
| AC-020-003 | 退出会话 | 浏览器持有已登录会话 | 退出后重试请求 | 新请求被拒绝，业务资料不因退出被删除 |
| AC-020-004 | 保留缩短 | 现有资料超出新保留期 | 保存期限 | 先展示影响和处理记录，不恢复已删除数据 |
| AC-020-005 | 共享关联 | 一个作品属于两主题 | 选择删除单个关联 | 另一关联保留；若删证据须明确全面影响 |
| AC-020-006 | 恢复一致 | 数据已删除且备份含旧副本 | 恢复并检索导出 | 继续拒绝旧内容，清理状态可追踪 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
