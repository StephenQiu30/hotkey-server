# 权限与数据隔离 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-009，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/035-权限与数据隔离计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

即使首版面向单人自建，也不能允许未授权访问或因猜到资源编号而读到其他身份的数据。主题、搜索、导出和后台任务需要遵守同一授权规则。

总纲原始要求：默认只有所有者访问其主题、会话、资料和导出；单人使用也有访问边界；多人共享须显式开启且按角色授权。

用户甲知道用户乙的事件或导出任务 ID，直接访问详情、搜索统计或下载接口时仍应被拒绝；后续团队成员被移除后，旧链接也不能继续访问。

## 2. 目标与成功指标

**BR-035-001：**把资料、连接和派生结果限制在明确授权范围内，所有读取与修改入口保持一致。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 越权成功数|两个隔离身份对读取、修改、检索、导出和异步结果的越权尝试|0 |
| 撤权生效|撤权成功后新发起的受保护请求是否仍成功|0 次越权成功；已在途任务须在输出前重新校验 |
| 权限覆盖率|实际暴露的资源与操作入口中有明确授权规则者占比|100%，不能只验证界面隐藏 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**P0 所有者边界、身份隔离、资源关联授权、异步结果与导出保护；为 P2 显式共享保留一致约束。
- **明确不包括：**在 P0 承诺团队角色界面、企业组织架构或单点登录；通过共享连接凭据实现资料共享。
- **与相邻能力的边界：**026 决定后续团队角色与协作流程，本文件是当前基础隔离要求；034 决定身份与秘密保护，018 和 024 也必须遵守本文件的输出授权。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 为新建主题、任务和资料关联确定所有者，默认不共享。
2. 每次请求根据当前身份核对资源归属、关联对象和操作权限。
3. 后台执行在任务启动及输出时检查当前有效权限。
4. 撤权或删除后使缓存、下载和待发送内容失效。
5. 以隔离身份检查全部入口并记录拒绝结果，不展示他人正文。

完成后用户获得：明确归属、默认私有且在全部访问入口一致生效的资料。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 资源归属|主题、事件、任务、导出和连接拥有明确归属或授权上下文|无有效归属不得创建可公开读取的孤立资源 |
| 操作权限|区分读取、修改、删除、导出、连接管理和后续共享|默认拒绝，显示按钮不作为授权依据 |
| 共享配置|仅在团队功能正式启用后支持明确授权|P0 不存在默认团队可见；未来角色按 026 |
| 撤权时间|记录操作者、对象、时间和生效范围|后续读取立即按当前权限判断 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-035-001 | 默认私有 | 新资源默认只有所有者可访问；公开来源内容被采集后不意味着用户的主题、标注和分析可对其他身份公开。全局去重不能泄漏他人是否采集过。 | AC-035-002、AC-035-006 |
| NFR-035-002 | 入口一致授权 | 详情、列表、搜索命中、数量统计、关系展开、导出与重试均校验权限；不能只过滤页面数据而泄漏总数、片段或存在性。 | AC-035-002 |
| NFR-035-003 | 关联对象校验 | 对批量操作与跨对象关联逐项校验，不能把他人作品 ID 关联到自己的事件后读取，也不能通过父子评论或原文引用越过边界。 | AC-035-003 |
| NFR-035-004 | 后台与缓存保护 | 任务携带授权上下文，执行和发布结果前复核；缓存按权限范围隔离，下载地址受保护且可撤销。权限不符时结果不发布也不发送外部提醒。 | AC-035-004、AC-035-005 |
| NFR-035-005 | 撤权与在途处理 | 撤权后新请求立即拒绝，进行中任务在安全检查点停止或转为不可发布，既有下载入口失效；已经由用户合法下载的离线文件无法技术回收，必须明确这一边界。 | AC-035-005 |
| NFR-035-006 | 共享与审计 | 未来共享须明确对象和角色，角色变更可追踪；连接秘密不因共享主题被共享。拒绝记录只含必要脱敏信息，不暴露他人正文。 | AC-035-006 |

**DEC-035-001：**P0 先落实所有者隔离；P2 共享只能在此边界上显式放行，不能用未来团队功能推迟基础授权。

以上规则解释 NFR-001-009，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 无权限或资源不可见|统一表达不可访问，不透露是否存在他人数据 |
| 权限已变化|提示刷新当前权限，未发布结果保持不可读 |
| 批量部分无权限|拒绝越权对象，按产品约定返回可操作范围且不泄漏对象详情 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

自身资料权限不扩展为跨所有者权限；运维诊断身份也不自动拥有正文或秘密读取权限。后续只读角色的能力在 026 上线时才可宣称支持。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

- **依赖或关联 PRD：**[003 监控主题管理](003-监控主题管理.md)、[014 历史内容检索与筛选](014-历史内容检索与筛选.md)、[018 基础报告与数据导出](018-基础报告与数据导出.md)、[024 离线可达提醒](024-离线可达提醒.md)、[026 团队协作](026-团队协作.md)、[034 凭据与应用安全](034-凭据与应用安全.md)、[036 数据访问与生命周期](036-数据访问与生命周期.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**准备两个独立身份及各自主题、评论、事件、任务、导出；逐项验证直接 ID、批量请求、搜索片段和计数、关系展开、缓存命中及撤权中的异步任务。未来角色未实现时只列待测，不能用模拟角色宣称协作已交付。

总纲质量目标：以两个隔离身份逐项验证读取、修改、导出和异步任务结果，越权成功数为 0；只读角色属后续功能，未实现前不宣称支持。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

AC-001-033 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-035-001 | 总纲场景继承 | 用户甲知道用户乙的资源 ID | 访问详情、导出或重试任务 | 全部拒绝且不暴露资源内容。 |
| AC-035-002 | 猜测编号 | 甲持有乙的作品、事件和任务 ID | 请求详情、重试、统计及导出 | 所有越权访问被拒绝，不泄漏正文、片段或数量 |
| AC-035-003 | 跨对象关联 | 甲可编辑自己的事件但无权读乙的评论 | 批量关联或展开父子关系 | 越权对象不能被借关联读取，合法对象处理结果明确 |
| AC-035-004 | 缓存与任务结果 | 乙的结果已缓存，甲使用同样查询或下载地址 | 请求缓存数据或异步结果 | 缓存和下载遵守甲当前权限，不能复用乙的授权 |
| AC-035-005 | 撤权在途 | 未来共享测试场景中导出正在生成或通知待发送 | 撤销授权后继续执行 | 不发布或发送越权结果，旧下载入口失效，已下载离线文件边界明确 |
| AC-035-006 | 默认与共享边界 | 新主题已创建且后续共享功能启用 | 检查默认权限并共享给只读成员 | 默认私有；显式共享有记录，连接秘密不可读；未实现角色标待验收 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
