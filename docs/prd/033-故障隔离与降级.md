# 故障隔离与降级 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-007，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。[同编号 Design](../design/033-故障隔离与降级设计.md) 只接受 S00 与内部状态分项，[执行计划](../plans/033-故障隔离与降级计划.md) 为 in_progress；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

跨平台监控的故障通常只影响某个来源、账号或能力。若全局队列和页面共用一个成功状态，局部失败会造成整个产品停滞，或掩盖实际缺失。

总纲原始要求：一个平台、某个能力或分析模型故障不阻断其他来源和已有资料读取；故障时保留原始证据与人工处理路径。

X 回复解析失败时，使用者仍能看到 X 已采作品、其他平台的新内容及历史事件，并明确知道当前缺的是哪一部分讨论。

## 2. 目标与成功指标

**BR-033-001：**把故障限制在真实影响范围内，保留资料读取、其他来源运行和人工处理能力。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 故障影响范围|故障注入期间被阻断的正常来源和历史读取能力|单一来源/能力故障不导致无关能力不可用 |
| 降级状态准确率|注入故障与界面、任务记录、报告缺口的一致性|验收样本全部一致，不显示虚假完整成功 |
| 恢复行为可控性|恢复探测、重试和补采是否遵守权限及预算|越权或超预算请求为 0，无付费切换 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**来源、连接、能力和分析阶段的局部隔离，熔断、受限运行、恢复探测和缺口展示。
- **明确不包括：**绕过平台访问限制、更换付费接口自动兜底、以旧数据冒充当前成功、保证任意整机故障仍在线。
- **与相邻能力的边界：**031 保证任务不丢失；本文件保证错误不扩散。039 记录原因与影响，029 定义新鲜度，分析增强失败不能阻止原始资料使用。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 识别错误所属来源、连接和能力，保留已保存结果。
2. 限制失败范围并停止无意义重试，释放无关任务需要的资源。
3. 用户继续浏览历史资料和正常来源，故障部分展示缺口与最后成功时间。
4. 在访问条件允许时执行有界恢复探测；授权失效由用户更新连接后再验证。
5. 恢复后逐步处理有界欠账，并把恢复及仍缺失的数据记录在事件中。

完成后用户获得：仍可工作的核心流程及准确标明受限范围的资料。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 故障作用域|来源、连接、能力、任务阶段和错误类别分开记录|同平台作品成功不自动代表评论成功 |
| 熔断条件|按连续错误或明确永久错误触发，阈值可配置|候选连续三次暂时性错误后暂停该能力；永久访问错误立即停止 |
| 恢复条件|区分自动探测许可与必须人工处理|凭据失效不进行无意义自动登录尝试 |
| 历史结果|保留采集时间、最后成功时间和缺口|只读使用时显示陈旧或部分状态 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-033-001 | 按能力隔离 | 错误传播边界以事实确定：评论失败不标作品失败；连接整体失效才影响该连接全部能力。全局任务汇总必须保留每个子任务结果。 | AC-033-002 |
| NFR-033-002 | 资源隔离与公平 | 失败来源的等待、重试和解析不能占满所有执行资源；其他可运行来源继续取得执行机会，历史浏览满足相关性能目标。 | AC-033-003 |
| NFR-033-003 | 降级展示 | 保留历史证据与已完成部分，显示缺失内容、最后成功时间和原因；没有新结果与无法获取新结果分别表达，报告继承相同缺口。 | AC-033-002 |
| NFR-033-004 | 分析与人工路径 | 模型、聚类或摘要不可用时仍可检索正文、查看计数、手工归并和标注；不生成伪造摘要、零情绪占比或默认事实可信结论。 | AC-033-004 |
| NFR-033-005 | 熔断与恢复 | 故障到达阈值后暂停对应能力，探测有限且计预算；访问条件不允许时等待人工处理。恢复后渐进恢复队列，不能一次性冲击来源。 | AC-033-005 |
| NFR-033-006 | 替换边界 | 可切换的免费适配器也须满足同一访问条件和能力契约，并留下切换记录；不得自动换账号规避限制、采购数据或降低质量要求来隐藏故障。 | AC-033-006 |

**DEC-033-001：**让用户看见真实的部分可用状态，并保留手工处理路径；降级不改变来源条件，也不自动转入付费路径。

以上规则解释 NFR-001-007，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 局部受限|具体指出作品、评论或分析哪项不可用；正常部分保留 |
| 暂停待处理|展示明确原因及更新凭据、等待恢复或停用来源等适用动作 |
| 恢复观察中|显示探测结果与欠账范围，未补齐前仍标部分 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只有连接所有者可修改凭据；运维恢复操作不能扩展原监控范围。来源拒绝访问时不引导绕过限制，改为暂停和保留历史资料。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

- **依赖或关联 PRD：**[004 平台与连接管理](004-平台与连接管理.md)、[009 采集任务控制](009-采集任务控制.md)、[015 讨论分析与趋势](015-讨论分析与趋势.md)、[022 自动分析增强](022-自动分析增强.md)、[029 时效与数据新鲜度](029-时效与数据新鲜度.md)、[031 可靠执行与幂等](031-可靠执行与幂等.md)、[037 费用与资源约束](037-费用与资源约束.md)、[039 可观测与可运维](039-可观测与可运维.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**分别注入单平台超时、单评论解析错误和分析服务不可用，同时保留另一正常来源与历史查询负载；检查结果、资源占用、状态与恢复轨迹，真实平台不承受故障压力测试。

总纲质量目标：分别注入单平台超时、评论解析错误、分析不可用，其他来源可继续，已有资料可读；错误能力明确暂停/受限，不能自动转付费。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-031 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-033-001 | 总纲场景继承 | X 评论能力故障而其他来源正常 | 执行全局监控 | 其他任务正常进行；X 作品和评论按各自状态显示，不把整个系统标成功。 |
| AC-033-002 | 评论单能力失败 | X 作品正常但评论解析持续报错 | 执行跨来源监控 | X 评论受限，X 作品及其他来源继续；汇总保留各能力状态 |
| AC-033-003 | 失败来源占用资源 | 一个来源持续超时，另一个来源可用 | 运行监控并查看已有事件 | 正常来源仍被调度且历史读取达标，重试不占满资源 |
| AC-033-004 | 模型失败 | 事件已有可读正文但分析服务中断 | 查看事件并人工整理 | 正文、计数和人工操作可用，未生成摘要明确标记 |
| AC-033-005 | 恢复节流 | 某能力已熔断且排队多批任务 | 满足恢复条件后探测 | 探测与回补受预算约束，欠账有界释放；凭据失效需人工处理 |
| AC-033-006 | 禁止付费兜底 | 免费来源失败且存在付费连接配置 | 触发降级流程 | 不调用付费服务，不轮换账号规避限制；替换适配器须显式满足同一契约 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
