# 数据访问与生命周期 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-010，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/036-数据访问与生命周期计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

长期积累评论会同时产生原始数据、索引、摘要、报告和备份。只删除一张作品表既不能达到用户的删除意图，也可能让过期资料通过恢复再次出现。

总纲原始要求：仅处理公开或获授权且满足来源条件的数据；最小化字段，保留/删除可配置；删除作品同步影响派生分析；原文暂不可见不得自动猜测已删除。

使用者删除某个主题的全部资料后，旧报告不再引用已删除正文；从旧备份恢复时仍执行相同删除要求，而来源一次访问失败不会被误当作作品已经删除。

## 2. 目标与成功指标

**BR-036-001：**使每份资料的取得条件、使用范围、保留时长和删除传播可解释、可执行、可核查。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 来源条件可核查率|启用来源和组件具备访问条件、许可证及检查记录的比例|100%；条件不明的能力不进入正式采集 |
| 删除可见性|删除确认后经详情、搜索、缓存、报告或问答仍读到被删除正文的次数|0；界面逻辑不可用立即生效 |
| 物理清理及时性|到期或删除指令触发至在线副本物理清理完成的时间|候选 ≤24 小时；备份按明确上限到期，保留清理证据 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**公开或获授权资料的来源条件记录、最小化采集、保留配置、删除传播、备份处理和可见性区分。
- **明确不包括：**凭公开可见就推定任意用途许可、收集私密资料或不必要敏感字段、对未知来源状态做删除事实断言、把本 PRD 当作法律意见。
- **与相邻能力的边界：**020 提供用户设置；本文件决定所有派生数据如何遵守设置。032 保证恢复重放删除；019 人工排除不等于物理删除，用户操作应区分。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 启用来源前核对访问条件、用途、组件与模型许可及采样限制。
2. 只采集核心监控所需字段，记录来源、采集时间和有效保留规则。
3. 用户查看保留设置并明确选择暂停、移除关联或删除资料。
4. 删除或到期后立即禁止继续读取与引用，传播到在线副本和派生结果。
5. 按期限完成物理清理及备份到期，恢复前重放删除记录并留下核验凭证。

完成后用户获得：有明确保留规则、能够完整删除且不会误判来源状态的资料。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 取得条件|记录平台访问方式、授权范围、适用条款/许可链接和核对日期|条件未确认显示待确认并停用对应能力 |
| 保留配置|结构化资料与原始响应分别设置，来源更严格条件优先|初始建议结构化 30 天、原始响应 7 天，均待冻结 |
| 删除范围|区分一个关联、一个对象、一个主题及所有资料|提交前显示范围和对报告/分析的影响 |
| 删除凭证|保留最小必要对象标识、范围、时间和执行结果|不在删除记录中保留已删正文；保留到受影响备份全部过期 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-036-001 | 访问条件与许可 | 每项采集能力启用前记录其公开/授权范围、访问限制和组件许可；代码可免费使用不等于数据可任意采集。条件变化暂停相关能力并复核，不以免费约束绕过限制。 | AC-036-002 |
| NFR-036-002 | 字段与用途最小化 | 仅存事件监控、证据核对所需字段，不主动扩充敏感个人档案；原始响应和媒体另设用途及保留期，排除不必要秘密，派生处理不得超出授权范围。 | AC-036-003 |
| NFR-036-003 | 保留与到期 | 显示实际生效期限和规则来源，来源限制更严格时采用更短期限；缩短保留期先提示受影响范围，再按同一到期流程执行。备份最长保留初始建议 30 天，具体不得超过允许范围。 | AC-036-003 |
| NFR-036-004 | 删除传播 | 删除确认后立即从正常读取、搜索、下载和问答上下文中排除；候选 24 小时内清理在线原文、索引、缓存、派生片段和托管导出。依赖正文的结论移除或标不可验证，不保留正文副本冒充历史。 | AC-036-004 |
| NFR-036-005 | 备份与重新采集约束 | 无法逐条删除的备份在限定周期到期销毁且禁止普通访问；恢复前重放删除记录。主动删除对象不能被自动回补重新引入，重新采集须明确用户意图并再次满足访问条件。 | AC-036-005 |
| NFR-036-006 | 来源状态与清理证明 | 不可达、无权限、明确删除和本地到期分别记录；来源超时不能推断作品已删除。清理任务保留脱敏数量、范围、时间和失败项，未清理完不显示彻底删除。 | AC-036-006 |

**DEC-036-001：**逻辑不可用立即生效，在线物理清理与备份到期分别承诺并展示；派生结论不能继续引用已不可用的正文。

以上规则解释 NFR-001-010，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 待确认访问条件|不启动正式采集，显示需核对的能力和依据 |
| 已停止使用、清理中|正文不可继续访问，显示清理范围与预计期限 |
| 来源状态未知|保留最后取得资料及时间，按保留规则处理，不声称来源已删除 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

所有者可在权限范围内删除；关联删除不误删其他获授权范围的独立资料。跨范围共享对象需按实际授权与数据保留设计处理，不能借全局去重阻止一方撤回其资料访问。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**构造包含正文、父子评论、事件、索引、摘要、报告、导出、备份及待回补任务的资料集，验证逻辑拒绝、在线清理和恢复重放；记录尚无法撤回的用户离线副本。来源条款核对为真实上线前条件，不用测试数据替代。

总纲质量目标：来源访问条件、项目/模型许可证、采样限制可核查；删除范围覆盖索引、报告缓存及证据，并处理备份到期清理；恢复后复用删除记录。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-034 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-036-001 | 总纲场景继承 | 删除一组资料且稍后恢复备份 | 查询原文、搜索和旧分析 | 正文不可继续使用，关联结论标过期或移除，备份恢复后重新应用删除。 |
| AC-036-002 | 条件不明 | 某来源或组件许可与访问用途尚未确认 | 尝试启用对应能力 | 保持待确认，不进行正式采集；允许记录后续核查依据 |
| AC-036-003 | 最小化与到期 | 原始响应含非必要字段且已设置不同保留期限 | 保存并运行到期清理 | 不保留非必要字段，实际期限取适用更严格值，结果可核对 |
| AC-036-004 | 删除影响派生结果 | 一个评论被多个摘要、索引和导出引用 | 确认删除并查看所有在线入口 | 立即不可继续读取正文，候选 24 小时内物理清理；结论移除或标不可验证 |
| AC-036-005 | 备份与自动回补 | 旧备份和回补任务包含主动删除对象 | 恢复备份或继续回补 | 先应用删除约束，不自动复活对象；备份到期可证明 |
| AC-036-006 | 来源不可达 | 原文访问超时且另一对象已被来源明确删除 | 刷新状态并执行本地清理 | 区分未知与已删除，清理未完成有失败项而非虚假成功 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
