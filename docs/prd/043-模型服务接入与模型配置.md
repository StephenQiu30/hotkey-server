# 模型服务接入与模型配置 PRD

日期：2026-09-17。状态：draft。依据 [调研](../research/043-模型服务接入与模型配置调研.md)，对应 [设计](../design/043-模型服务接入与模型配置设计.md)（proposed）和 [计划](../plans/043-模型服务接入与模型配置计划.md)（planned）。本项新增 FR-001-025，不调整既有需求编号。


用户已确认两种信息获取入口都需要：044 采集平台自身公开信息，045 通过模型联网工具检索外部线索。本项仅提供模型连接/配置基础；044 不依赖模型推理，045 显式复用本项能力。详见 [044 PRD](../prd/044-模型平台信息采集与变更监控.md)、[045 PRD](../prd/045-模型联网检索与线索采集.md)。

## 1. 用户问题与目标

用户需要知道哪些模型能处理中文评论、摘要、图片与资料问答，如何接入 OpenRouter 或 Vercel，调用会不会产生费用，以及结果究竟由哪个模型生成。只有一个 API Key 输入框无法回答这些问题。

**BR-043-001：**让用户在可核查能力、零付费执行和受控资料范围内选择可替换的模型服务，并能解释每次分析使用的配置、结果与资源。

| 指标 | 口径 | 验收目标 |
|---|---|---|
| 非预期付费 | 计费边界、并发、重试和回退故障矩阵 | 被策略禁止的上游请求数为 0；不以没有账单回传冒充零费用 |
| 运行可追溯 | 已受理探测及分析尝试 | 全部关联配置版本、模型请求 ID、状态及使用量状态；供应商不返回的字段明确未知 |
| 配置可理解 | 在 040 的体验验证中完成模型选择 | 能指出用途、外发范围、费用类别和失败后行为；不把模型总数作为成功指标 |
| 基础可用 | 关闭全部模型连接 | P0 原文、统计、人工整理和历史报告仍可用 |

指标均未测量。模型任务效果归 041 / 022 / 023 / 025 独立验收，配置成功不代表分析质量达标。

## 2. 范围、优先级与非目标

- **P1 范围：**本地服务、OpenRouter、Vercel AI Gateway 的连接档案、模型目录与费用/能力卡、任务配置版本、受控测试、请求与资源记录、停用和回退。
- **默认执行范围：**本地；外部零单价服务须另满足资料外发、隐私、实际能力和无收费路径条件。未满足时可展示档案和原因，不能显示已可用。
- **只展示、不执行：**付费模型、有限赠送额度、付费层 BYOK 及收费附加功能；后续启用必须有明确范围决定与独立验证。
- **非目标：**模型训练/微调、算力采购、自动充值、通用 Agent 平台、任意用户自定义网络代理、执行未登记或具有写入副作用的模型工具、自动下载全部权重、媒体生成。
- 与 004 社交平台连接分开；043 管理模型配置，022/023/025 拥有分析业务，037 拥有共用预算约束。P0 发布不依赖本项。

## 3. 用户故事和流程

1. 所有者进入“设置—模型服务”，选择本地、OpenRouter 或 Vercel，看到费用与数据处理说明。
2. 保存端点/密钥引用；保存不发推理请求。同步只读目录，空目录与连接失败区分。
3. 按任务筛选模型，查看来源、能力、上下文、价格、许可、数据政策和更新时间；不符合条件的项显示不可选原因。
4. 显式执行小规模合成文本测试，先展示是否外发及预算。测试结果只覆盖该端点、模型和用途。
5. 为摘要、主题标签等用途建立配置草案，经质量验证后启用；实际资料分析另由业务流程触发。
6. 查看模型运行记录；额度或能力失效时暂停，切换已验证本地配置或继续人工整理。停用不会自动重跑历史分析。

## 4. 信息与配置规则

| 对象 | 必备信息与校验 |
|---|---|
| 服务连接 | 类型、名称、所有者、端点策略、密钥引用/版本、启停、最近验证时间与结果；密钥仅可替换/撤销，不可回读 |
| 模型卡 | 接入口、完整 ID、显示名、上游/端点范围、来源链接、更新时间、上下文和输出上限、输入输出模态、工具/结构化输出/推理等声明及实测状态 |
| 费用与许可 | local / zero_price / free_credit / paid / unknown；币种、单位、输入/输出/缓存/推理/媒体/工具等适用维度、档位与失效时间；运行时许可、权重许可、托管条款分列 |
| 任务配置 | 用途、连接与模型、所需能力、提示模板/Schema 版本、参数、最大输入输出、超时、请求/资源预算、外发字段白名单、路由/回退范围；生成不可变版本 |
| 使用量 | 估算与实际、来源和可信状态、输入/输出/缓存等去重计量规则、失败尝试、计费未知、实际模型/上游（若返回）；不能以 null 显示 0 |

目录过期建议阈值 24 小时，仅作 S00 待冻结默认值；零付费/隐私资格在每次派发前复核。配置页不要求用户填写提供方内部术语，复杂路由仅在详情展示。embedding、rerank、OCR、ASR 各自按类型选择；语言模型不能默认承担全部任务。

## 5. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-043-001 | 连接与凭据 | 预设服务端点，维护者审核本地端点白名单；保存不调用推理；只有所有者可换钥、同步、显式测试和停用；测试持久受理、有界且使用合成文本；拒绝秘密回读与任意 URL 转发 | AC-043-002 |
| FR-043-002 | 目录与能力 | 以连接＋完整模型 ID＋目录版本识别；支持同步、变化提示、失效/撤架；未提供字段未知，不推断为零/不支持；公开声明与已验证分列；价格或隐私资格不明禁止启用 | AC-043-003 |
| FR-043-003 | 用途与配置版本 | 每类任务独立绑定能力及经过评估的模型；激活需通过本用途门槛；限制总上下文及输出；配置变更只影响新任务，历史可追踪；动态自动路由默认不用于正式结果 | AC-043-004 |
| FR-043-004 | 零付费与预算 | 执行仅 local 或已核查 zero_price；paid / free_credit / unknown 阻止派发。控制账户级和用途级请求/并发/资源，探测和重试同计；当前更严格限额即时生效；禁止充值、收费附加项、隐式收费路由和通过换钥绕限额 | AC-043-005 |
| FR-043-005 | 数据与路由约束 | 外部默认关闭；启用须明确主题/用途/字段范围，剔除账号标识、秘密和内部备注等非必要信息；每次派发核对当前权限与保留政策，正文只能作数据。默认要求上游零保留；无法确认则不发；不自动放松或扩大上游范围 | AC-043-004 |
| FR-043-006 | 运行记录与降级 | 分开记录业务任务与所有上游尝试、估算/实际/未知消耗，关联真实返回的模型信息与证据；中断输出不发布为完整。失效/限流/超时/停用可恢复但不自动重试结果未知请求；本地回退也需兼容和预算验证；基础流程独立 | AC-043-006 |

**DEC-043-001：**本地优先，外部受控且默认关闭；费用、隐私、能力三者同时满足才可执行。043 不承担业务分析质量判断，也不授权付费。

## 6. 非功能约束

复用 027—042 的现有 NFR，不新增重复的预算、任务或权限实现。模型特有的执行要求为：密钥不进浏览器/日志/Git；HTTP/流式超时有界；目录异常不能清空历史；计量未知不作为零费用；并发预算原子预留；删除/撤权阻止新的派发并使派生分析按 036 失效；模型故障不阻断核心读取。

B0 不包含本轮新增 GPU 或额外采购；本地推理若无法与核心服务共存就保持未启用。样本和效果用 Q0 的独立验证划分，不能用供应商榜单替代。外部零保留声明不等于 HotKey 能远程证明删除，界面需保留能力边界。

## 7. 状态、权限与异常

| 状态 | 用户可见结果 |
|---|---|
| 未配置/已停用 | 无可执行模型；仍能读历史及用基础分析 |
| 加载目录/目录为空 | 同步进度或“未发现符合条件的模型”，不冒充连接失败 |
| 待验证/部分能力可用 | 显示已测任务、未测范围和最近验证时间 |
| 凭据失效/网络不可达 | 清晰原因和可执行的重试/换钥；不将请求失败计作模型不存在 |
| 额度受限/费用或隐私不符/目录陈旧 | 指出限制维度，阻止新任务；不引导必须购买才能继续核心功能 |
| 运行中/已取消/结果未知 | 有尝试记录；在途请求可能无法撤回，取消不承诺已发生消耗归零 |
| 无权限 | 不返回其他所有者的连接、用量、目录私有条目或凭据 |

| 身份 | 允许操作 |
|---|---|
| 所有者 | 管理自己的连接/用途配置及授权范围内的资料；不绕过部署级费用与网络策略 |
| 获授权维护者 | 维护网络白名单和运行策略，查看脱敏诊断；不自动获得正文或可回读密钥 |
| 其他用户 | 默认拒绝，026 未启用前不假设团队共享模型连接 |

## 8. 依赖与验证准备

043 在 M6 先于 022。先行输出：042 S02 的运行环境，034/035 S03 的身份秘密保护，036 S03 的生命周期规则，037 S03 的预算和 039 S03 的审计。这些为 P0 输出，不依赖 043，避免循环。022 的效果验证不是 043 通用连接测试的前置；反过来，连接测试也不放行正式分析。

提供目录/费用变化、越权、限流、网络中断、并发预算和流式失败的受控 fixtures；使用真实隔离数据库/消息验证状态。真实提供方验证仅在访问和无收费条件具备时执行，证据不足保持待验证。

## 9. 验收标准

首项继承 AC-001-041，其余为新增边界；全部待执行。每个组合条件应拆成可独立失败的用例，不能只测一次正常路径。

| 验收 ID | 场景 | Given | When | Then |
|---|---|---|---|---|
| AC-043-001 | 总纲场景继承 | 本地与外部模型均已登记，外部额度或条件失效 | 选择模型并运行同一用途 | 展示能力、价格和外发范围；不产生被禁止的调用；历史配置可追踪，基础分析仍可用 |
| AC-043-002 | 凭据与连接 | 两个隔离身份、保存的新密钥和恶意端点 | 保存/换钥/显式测试/停用并跨身份读取 | 保存零推理请求；秘密不回读且无日志泄漏；拒绝越权及未批准端点；测试只含合成输入，有界并计预算 |
| AC-043-003 | 目录变化 | 同名跨入口模型、缺失价格、能力声明未测和已撤架条目 | 同步目录并查看/选择模型 | 不混淆 ID/限制；未知不填零；陈旧/撤架/资格不明阻止新任务，旧结果与目录版本仍可查 |
| AC-043-004 | 用途和外发 | 文本模型被用于图像或严格 Schema；资料含内部备注；授权撤销或上游不满足保留要求 | 激活配置及派发；另执行符合条件的合法样本 | 不满足时零派发；合法请求仅含白名单字段；模板、Schema、输入与模型版本可查；旧任务不得绕过当前权限；评论指令不能执行工具 |
| AC-043-005 | 费用与并发 | 零单价变收费、免费额度耗尽、收费 BYOK 回退、两个任务竞争最后额度、429 或超时 | 派发、重试或回退 | 拦截收费/未知/赠送额度路线；原子预算无超额派发，每次尝试计数；限流延期，结果未知不盲重试；无充值或付费切换 |
| AC-043-006 | 追溯和停用 | 已有人工结果，流中错误、用量缺失、模型停用及本地回退不兼容 | 查看记录、取消、恢复和关闭全部连接 | 不发布部分流；标记未知用量、请求/实际模型及尝试关系；不覆盖人工结果；不合格回退停止；关闭模型后原文/统计/人工与历史仍可用 |
