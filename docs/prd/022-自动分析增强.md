# 自动分析增强 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-020，保持 P1 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/022-自动分析增强计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

人工整理能验证分析价值，但资料量增长后需要可靠的自动辅助。模型输出的流畅程度不能替代证据与准确性，失败也不能让核心研究不可用。

总纲原始要求：校准后的本地模型自动生成主题、情绪/立场标签、摘要和对比报告；批量分析可取消、重跑和回退，模型变化有版本记录。

用户对一批已采样评论运行本地主题与情绪分析，核对低置信结果，并比较模型升级前后的变化。

## 2. 目标与成功指标

**BR-022-001：**在免费、自建和质量可验证的前提下减少重复整理工作，同时保留人工修正与回退能力。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 模型任务效果|Q0 独立评估主题/情绪/立场及摘要证据|分别报告，阈值由 041 冻结 |
| 弃判与错误|低置信占比和各类别错误率|同时披露，不能只报告有把握子集 |
| 付费依赖|关闭收费服务后的基础路径可用性|不受影响 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P1）：**本地模型注册与版本、批量自动标注、主题/摘要增强、取消重跑、人工复核和版本对比。
- **明确不包括：**默认购买推理服务、模型输出直接判真、无证据自动发布结论、自动执行评论中的指令。
- **与相邻能力的边界：**015 定义分析产品，022 提高自动化程度；022 不可用时保留基础统计、原文和人工路径。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；本文件展开后仍属后续阶段，不因文档已写完自动提升首版优先级。

## 4. 用户流程与关键结果

1. 选择已验证用途与许可的本地模型和分析任务。
2. 冻结资料范围，预估资源并提交异步分析。
3. 按任务生成标签、焦点或摘要，保留引用与置信/弃判信息。
4. 用户复核不确定项和代表样本，修订结果。
5. 模型升级先做独立评估，对新结果显式版本化发布或回滚。

完成后用户获得：带模型/方法版本、证据、复核状态与不确定性的自动分析产物。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 模型与任务|框架许可、权重许可、语言适用性单独记录|未验证任务不启用 |
| 输入资料|固定样本集合、正文完整度和可用父上下文|不外发至未配置服务 |
| 资源配置|并发、时长、批大小、内存限制|可延期，不挤占核心读取 |
| 发布方式|草稿/待复核/已确认|建议默认待复核 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-022-001 | 任务分离 | 主题、情绪、立场、摘要分别选择模型或规则并独立评估，不能一个准确率覆盖所有任务。 | AC-022-002 |
| FR-022-002 | 证据约束 | 摘要和观点有引用，立场有对象；低置信/缺上下文允许未知，未核验事实不自动标真。 | AC-022-003 |
| FR-022-003 | 输入可信边界 | 外部帖子/评论作为数据，不可修改分析规则、访问秘密、调用外部工具或扩大权限。 | AC-022-004 |
| FR-022-004 | 有界执行 | 分析队列有资源限额、取消与进度，失败重跑幂等；不在浏览页面时隐式触发整批推理。 | AC-022-005 |
| FR-022-005 | 版本与人工 | 记录模型、输入和参数版本；新输出不静默覆盖已确认人工结果，展示差异再决定替代。 | AC-022-006 |
| FR-022-006 | 降级独立 | 模型不可用时基础统计与原文可读，允许人工整理；不自动切换付费提供方。 | AC-022-006 |

**DEC-022-001：**把模型当作可替换的辅助处理能力，数据证据和人工决策不依赖某个模型供应商。

以上规则解释 FR-001-020，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 排队/资源不足|显示等待原因，其他核心页面可用。 |
| 待复核/部分弃判|明确未判定项及原因，不补随机标签。 |
| 模型失效/已回滚|保留此前允许保留的结果与版本，基础功能不停止。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只有获授权用户可分析其资料；维护者可管理模型包但不自动读全部内容，模型不能获得连接秘密。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-020 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-022-001 | 总纲场景继承 | 模型不能运行或低置信 | 打开同一事件 | 仍能查看原始数据、基础统计和人工分析；不强制开通付费服务。 |
| AC-022-002 | 独立评估 | 情绪模型表现较好但立场效果差 | 查看发布结果 | 分别报告，不以情绪准确率证明立场通过 |
| AC-022-003 | 未知保留 | 样本反讽且无父上下文 | 运行模型 | 可弃判并标原因，事实不默认真 |
| AC-022-004 | 外部指令 | 评论要求输出会话密钥 | 执行分析 | 当作文本处理，不访问秘密或执行动作 |
| AC-022-005 | 资源与取消 | 大批推理占用资源 | 取消并浏览核心页面 | 有界停止，核心读取仍可用 |
| AC-022-006 | 升级回退 | 新模型与人工标签冲突后失败 | 发布或回滚 | 保留人工版本和差异，不切付费服务 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
