# 费用与资源约束 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-011，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/037-费用与资源约束计划.md) 已进入 `in_progress`，[Design](../design/037-费用与资源约束设计.md) v1.0 已接受 S00—S01；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

软件免费不代表请求无限或运行无成本。翻页、失败重试、初始化和最终被过滤的数据都消耗资源，若只统计最终保存结果会持续超预算。

总纲原始要求：生产核心采集与基础分析不得依赖付费订阅、按量数据接口或付费云推理；使用开源免费组件；限制每来源/账号/任务的请求、并发、时长和存储。

监控某关键词时大多数结果被排除，预算却已接近耗尽；系统应按实际请求停止，而不是继续抓取或自动切到付费服务。

## 2. 目标与成功指标

**BR-037-001：**在不依赖付费数据和推理服务的前提下，使请求、分析、存储和并发消耗有界且可解释。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 付费依赖调用|生产核心采集和基础分析执行的付费服务调用次数|0，包括订阅、按量接口和付费推理 |
| 预算漏记|实际发生的请求/重试/分析工作中未计入相应预算的数量|0；结果为空或被过滤仍计入 |
| 超限新增工作|预算耗尽后无预留额度仍启动的新增工作数|0；运行中的已预留工作按明确边界结束 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**零付费核心路径、分层资源预算、请求与模型消耗计数、限额后的延期、资源可见性及重启后预算连续性。
- **明确不包括：**购买代理池、账号、第三方数据接口或云模型兜底；保证自建硬件、电力、运维完全零成本；借账号轮换突破平台限额。
- **与相邻能力的边界：**平台限制是外部上限，应用预算只能更严格。009 显示任务延期，033 处理故障降级，042 处理全机容量。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 维护者定义各来源、连接、主题、任务和分析阶段的资源上限。
2. 任务启动前核对访问条件及剩余额度，为即将执行的工作预留预算。
3. 按实际网络或分析尝试计数，包括初始化、重试、翻页和过滤掉的数据。
4. 额度不足时停止新增工作，保留已保存结果，显示延期原因和可恢复条件。
5. 查看时间窗口内消耗与自建成本，调整范围或频率后按新版本执行。

完成后用户获得：能够解释每次消耗和每次延期的免费自建运行方式。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 允许组件清单|核心路径只允许满足免费与许可条件的组件及服务|收费配置即使存在也不能被核心路径调用 |
| 分层预算|来源、账号连接、任务和全局均有请求/并发/时长/存储限制|实际生效为适用限制中的最严格者 |
| 预算窗口|定义时区、开始结束时刻、重置及预留归还规则|重启不重置窗口，变更有版本与生效时间 |
| 使用明细|记录尝试次数、阶段、资源量和停止原因|不以保存条数代替请求数；查询词与秘密脱敏 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-037-001 | 零付费核心路径 | 关闭所有付费配置后，已获准的采集、资料管理和基础分析仍可运行；能力受限时如实显示，不自动调用付费 API、代理或云推理。 | AC-037-002 |
| NFR-037-002 | 全消耗计数 | 初始化、分页、重试、失败请求、被过滤结果和无输出模型尝试均进入对应预算；第三方库内部请求也须可计量，无法控制时该能力不能宣称预算受控。 | AC-037-003 |
| NFR-037-003 | 分层预留与并发 | 开始工作前按最严格预算原子预留或等效保证，多个任务并发不能分别看到同一额度后共同超限；实际消耗与未使用预留的释放均有记录。 | AC-037-004 |
| NFR-037-004 | 超限有界延期 | 额度不足停止新增请求与昂贵分析，保留已保存结果和游标；清楚显示额度、下一窗口或需要用户调整的条件。不能通过新任务、重启或换账号规避。 | AC-037-005 |
| NFR-037-005 | 资源与公平 | 为读取、必要写入和清理保留资源；历史回填、媒体分析等低优先工作先延期。任务占用时长与单批规模有上限，不能一项耗尽全部预算。 | AC-037-006 |
| NFR-037-006 | 成本与变更透明 | 显示实际请求、分析和存储消耗及自建资源成本边界；预算调整只在用户授权范围内生效并留版本，降低上限后不再新增超额工作，也不静默删除已有资料。 | AC-037-006 |

**DEC-037-001：**零付费是依赖约束，预算有界是运行约束，两者都需验证；减少最终输出不能抵扣已经发生的消耗。

以上规则解释 NFR-001-011，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 可运行|显示生效预算、当前使用量和统计窗口 |
| 额度耗尽或资源不足|任务延期并保留进度，说明恢复条件而非标正常空结果 |
| 计量不完整|明确无法证明预算，限制或停用相关能力直到补齐计量 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

只有所有者或明确授权维护者修改预算与允许组件；普通操作不能通过重试、新建或切换主题绕过全局与连接上限。此 PRD 不授权任何购买。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

关联 [043 模型服务接入与模型配置](043-模型服务接入与模型配置.md)：M6 模型费用分类为 local、zero_price、free_credit、paid、unknown；当前只有前两类经资格检查可执行，其余只展示。SDK 免费、赠送额度和托管零单价不混同；BYOK/附加费/失败重试分别计量；无法证明零付费即阻断。 本项先行能力不依赖 043 完成；扩展进入范围时追加验证。

- **依赖或关联 PRD：**[004 平台与连接管理](004-平台与连接管理.md)、[009 采集任务控制](009-采集任务控制.md)、[010 增量更新与历史回补](010-增量更新与历史回补.md)、[022 自动分析增强](022-自动分析增强.md)、[023 图片和视频上下文补充](023-图片和视频上下文补充.md)、[033 故障隔离与降级](033-故障隔离与降级.md)、[039 可观测与可运维](039-可观测与可运维.md)、[042 容量与部署可重复性](042-容量与部署可重复性.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**用受控来源验证过滤全部结果、内部重试、并发抢占最后额度、跨窗口和重启等场景，并关闭所有付费服务配置走通核心流程。计量包括组件真实发出的请求，模拟条数不能证明网络消耗。

总纲质量目标：核心路径在关闭全部付费服务配置时可运行；达到应用或来源限额停止新增请求、清楚延期；重试/翻页计入预算；记录自建资源用量，不能把免费软件说成零运维成本。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-035 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-037-001 | 总纲场景继承 | 预算接近耗尽且有分页、重试和最终被过滤的结果 | 继续执行 | 被过滤内容产生的请求与分析调用仍计入预算；停止原因明确，不自动购买或切收费服务。 |
| AC-037-002 | 免费路径可运行 | 全部付费配置关闭且免费来源访问条件满足 | 完成采集、查看与基础分析 | 不调用付费服务，受限能力明确降级而非暗中兜底 |
| AC-037-003 | 无输出仍计量 | 初始化及多页结果均被过滤，且发生失败重试 | 查看预算使用记录 | 每次实际尝试都有计数，使用量不因结果为零而减少 |
| AC-037-004 | 并发最后额度 | 两个任务同时争取仅剩的一次请求预算 | 并发启动 | 最多一个获得额度，另一个延期，无预算超发 |
| AC-037-005 | 重启与窗口 | 预算耗尽但任务未完成 | 重启、重复提交或切换主题 | 额度不被刷新，继续延期，显示真实重置条件与进度 |
| AC-037-006 | 存储紧张与调低上限 | 媒体回填消耗较大且维护者降低预算 | 继续浏览和调度 | 核心读取与必要清理保留资源，低优先工作延期；配置变化和成本边界可见 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
