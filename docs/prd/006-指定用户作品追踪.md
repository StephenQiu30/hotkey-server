# 指定用户作品追踪 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 FR-001-004，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/006-指定用户作品追踪计划.md) 已建立且为 planned；同编号 Design 与真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

按名称搜索很容易把同名用户或引用内容当作目标作者。作者追踪需要独立于关键词，才能持续回答这个人新发布了什么。

总纲原始要求：通过主页链接或账号标识添加关注用户，以稳定平台 ID 标识；提供初始回溯范围、更新频率、作品类型、可选关键词过滤和评论采集开关。

用户添加一个 X 主页和一位 B站创作者，期望改名、置顶或发不含关键词的作品时仍能正确识别。

## 2. 目标与成功指标

**BR-006-001：**以明确确认的稳定平台身份追踪新作品，避免同名误绑定、重复更新和遗漏未含关键词的作品。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 身份正确率|选定账号与采集作品作者 ID 对比|冻结样本全部正确 |
| 重复新作品提醒|相同平台作品重复被当成新作次数|0 |
| 更新延迟|发布时间至首次发现，分来源/任务等待报告|基线测量，遵循 029 不承诺统一实时 |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**主页解析、候选身份确认、作品类型与评论开关、有限回溯、启停、改名和不可见状态。
- **明确不包括：**私密账号访问、用粉丝量自动替换身份、自动关注/点赞、保证全历史作品。
- **与相邻能力的边界：**账号页保存目标作者作品，事件关联仍依赖相关性；评论采样属于 008。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 粘贴主页或账号标识，解析平台并显示候选身份。
2. 用户确认主页与稳定 ID，设置原创/引用等作品类型。
3. 选择回溯范围、频率及是否采评论；关键词过滤默认关闭。
4. 运行首次采集，区分历史回填与真正新增。
5. 周期更新并保留改名记录，失效/私密化时显示状态。

完成后用户获得：稳定的关注账号、作品时间线、增量更新记录及可选评论任务。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 身份输入|支持已接入平台的主页或明确账号标识|多个候选必须确认 |
| 作品类型|原创、引用、转帖、回复分别选择|建议原创+引用 |
| 关键词筛选|启用时需指定主题版本|默认关闭 |
| 回溯与周期|数量/时间双限；来源更严格限制优先|建议首轮最多 50 件、7 天，60 分钟目标周期 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| FR-006-001 | 身份绑定 | 保存平台与稳定 user ID，昵称只作展示别名；禁止仅凭高粉候选自动绑定。 | AC-006-002 |
| FR-006-002 | 作者归属 | 目标作者的引用帖属于目标作品，被引用原文保留原作者；转帖与原创不同类型。 | AC-006-003 |
| FR-006-003 | 独立跟踪 | 默认不要求命中主题词，作品先进入账号页，再按规则关联事件。 | AC-006-004 |
| FR-006-004 | 增量判定 | 按作品 ID 和发布时间去重；置顶、旧帖重排、改名不产生新作品通知，初次回填单独标记。 | AC-006-005 |
| FR-006-005 | 停用与权限变化 | 停用停止新调度并保留历史；账号转私密或失效时不越权追取，状态与最后成功时间可见。 | AC-006-005 |
| FR-006-006 | 变更配置 | 类型/过滤规则修改生成版本；是否重扫历史由用户显式选择，不默认无限回补。 | AC-006-006 |

**DEC-006-001：**账号身份与主题词分开管理，由用户明确确认目标，原文关系不能改变作者归属。

以上规则解释 FR-001-004，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 待确认|显示候选账号及公开身份信息，不开始持续采集。 |
| 正常但无新增|展示本轮成功检查范围与最近成功时间，不推断绝对无漏采。 |
| 改名/受限/不可见|稳定身份保留；记录别名或状态变化，禁止自动改绑。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

所有者管理自己的关注列表和评论开关；平台凭据使用权不等于可读取受限账号内容。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 9. 验收标准

AC-001-004 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-006-001 | 总纲场景继承 | 用户明确选择的关注账号发布一条不含主题关键词的新作品，同时存在同名候选 | 按默认不筛关键词的账号规则运行 | 新作品进入账号页；以已确认身份跟踪，不因同名候选粉丝多而替换；引用与转帖正确归属。 |
| AC-006-002 | 同名候选 | 两个账号同名且粉丝数差异大 | 选择较小账号并保存 | 固定所选 ID，不因粉丝数自动改绑 |
| AC-006-003 | 引用归属 | 目标账号引用另一人的作品 | 采集作品 | 引用作品属于目标，被引原文保留原作者 |
| AC-006-004 | 无词新作 | 新作不含任何主题词 | 执行默认账号监控 | 账号页可见，不强制塞入不相关事件 |
| AC-006-005 | 置顶与改名 | 旧作品被置顶且用户改名 | 再次运行 | 不重复新作提醒，保留稳定 ID 与别名 |
| AC-006-006 | 筛选回填 | 开启关键词或新增回复类型 | 保存设置 | 只影响新版本任务，历史重扫需显式选择 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
