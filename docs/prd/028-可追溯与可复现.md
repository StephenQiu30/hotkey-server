# 可追溯与可复现 PRD

日期：2026-09-17。状态：详细需求草案；承接既定范围 NFR-001-002，保持 P0 优先级。本文是独立评审和验收依据，不代表功能已实现。对应 [执行计划](../plans/028-可追溯与可复现计划.md) 已进入 `in_progress`，[Design](../design/028-可追溯与可复现设计.md) v1.0 已接受 S00—S01；真实 Acceptance 尚未建立。

入口：[逐项 PRD 索引](README.md) · [平台需求总纲](001-热点事件监控平台功能与非功能需求.md) · [鱼皮项目功能研究](../research/001-热点事件监控平台调研.md)。

## 1. 背景、问题与用户价值

研究结果需要回答“哪次采集、哪些资料、用什么规则得出”。缺少版本和输入范围，排序变化或分析争议无法复查。

总纲原始要求：每条采集数据具有来源标识、采集时间与任务关联；每项分析结论、热度分数有输入范围与方法版本；支持同版本复算。

研究者一周后打开同一报告，要求复算热度并确认某个观点引用的是当时版本而不是最新改写正文。

## 2. 目标与成功指标

**BR-028-001：**让保留期内的数据、分数和分析形成连续证据链，确定性结果可复算，非确定性输出有完整运行记录。

| 指标 | 统计口径 | 目标或判定 |
|---|---|---|
| 采集溯源字段齐全率|具备来源身份、观察时间、任务和版本的展示记录/全部展示记录|100% |
| 结论引用覆盖率|有证据的可核查结论/全部此类结论|抽检目标 100% |
| 确定性复算一致率|相同冻结输入与规则得到一致值和排序|100% |

指标用于评审和后续测量，尚未取得运行结果。涉及新增数量、时长和默认值的建议须在实施前冻结；不据此扩大既定平台范围或付费权限。质量目标不以“页面有按钮”替代。

## 3. 范围、优先级与边界

- **本期范围（P0）：**输入快照、采集/规则/方法版本、指标样本、结论引用、修改记录与有限保留期内复算。
- **明确不包括：**删除后继续保留受限正文、保证非确定性模型逐字相同、永久保存所有原始响应。
- **与相邻能力的边界：**028 定义系统证据链，016 定义用户修订体验；生命周期与权限始终优先于无限复现。
- **发布条件：**本文件全部适用验收通过，并满足关联质量要求；缺失该能力不能用演示或其他功能替代 P0 完成。

## 4. 用户流程与关键结果

1. 为采集记录、作品观察和方法配置建立可关联标识。
2. 计算时固定输入集合、比较范围和规则版本。
3. 结果中提供面向研究者的来源和版本说明。
4. 争议时在同条件下复算确定性指标，核对模型运行记录。
5. 资料到期或失效时标复现能力变化并保留允许的元数据。

完成后用户获得：可追溯证据关系、复算记录和有限保留范围的说明。取消、失败或权限拒绝时，不显示与实际不符的成功结果。

## 5. 输入、配置与信息展示

| 信息项 | 规则与校验 | 默认或展示要求 |
|---|---|---|
| 采集依据|来源、对象、时间、任务、排序、配置/组件版本|不能只有链接 |
| 计算依据|输入快照/集合、窗口、样本数、权重/模型版本|禁止动态读取未冻结“最新”作历史输入 |
| 人工变化|操作者、时间、原因和前后版本|不可静默覆盖 |
| 保留能力|可复算/部分可复核/已失效|到期后据实更新 |

配置变更记录操作者、时间和版本；正在执行的操作绑定启动时的业务规则版本。当前权限、连接停用、删除要求与更严格预算始终优先，不能以旧版本继续越权或超额执行。冲突的输入必须明确拒绝或延期，不能静默修改用户意图。

## 6. 详细需求与业务规则

| 需求 ID | 规则 | 详细行为 | 对应验收 |
|---|---|---|---|
| NFR-028-001 | 全链标识 | 展示数据可追溯到来源与采集记录，分析可追溯到输入集合和方法版本。 | AC-028-002 |
| NFR-028-002 | 确定性复算 | 固定同一组快照、比较样本和规则；归一化参考集也是输入，不能只保存单作品指标。 | AC-028-002 |
| NFR-028-003 | 非确定性记录 | 模型保留输入范围、模型/参数、输出和时间，必要时允许不逐字复现但能核查依据。 | AC-028-003 |
| NFR-028-004 | 证据版本 | 引用指向实际使用的内容版本，后续编辑与权限变化使旧结论状态更新。 | AC-028-004 |
| NFR-028-005 | 留痕与脱敏 | 审计不可只写“修改成功”，需有可解释对象与版本；一般日志不记录秘密或原始搜索词。 | AC-028-005 |
| NFR-028-006 | 保留限制 | 删除/到期后不为复现偷偷保存原文；说明哪些结果只能查元数据、哪些已无法复算。 | AC-028-006 |

**DEC-028-001：**复现必须包含比较样本与方法版本，并受合法保留和访问边界约束。

以上规则解释 NFR-001-002，不重编号或替换总纲条目。后续发现冲突应显式更新总纲及受影响文档，不由某一页面或适配器单独改变语义。

## 7. 状态、异常与权限

| 状态或场景 | 展示与处理 |
|---|---|
| 可复算|输入与方法完整且仍有权访问。 |
| 部分可复核|部分数据到期或外链不可见，说明缺失范围。 |
| 失效/已替代|不再宣称旧结果可完整复现，提供允许的版本关系。 |
| 加载或执行中 | 展示已知阶段和可用操作；未知进度不用虚假百分比，已持久化历史结果可以继续查看。 |
| 无权访问 | 显示稳定的权限提示，不通过错误内容泄露其他使用者的数据或凭据。 |

复算用户需要全部输入的当前读取权限；审计查看与内容阅读可分离，不能从审计绕过删除。

| 身份 | 访问与操作边界 |
|---|---|
| 资料或配置所有者 | 在本文件范围内处理自己的业务资料与配置；维护职责的动作仍须相应授权。 |
| 获授权维护者 | 仅诊断或维护明确授权的范围，不自动获得业务正文、规则修改或秘密回读权限。 |
| 其他身份 | 默认拒绝；仅在 026 团队协作正式启用且被显式授权后，按实际角色开放对应操作。 |

本项专门权限规则优先约束上述通用边界，后续角色设计不能扩大已有秘密或数据访问权限。

重复点击、刷新页面或网络重试不得重复产生同一业务结果；若本操作是有意新建的一次业务行为，必须有独立标识和清晰的版本/时间范围。

## 8. 依赖、质量与验证环境

- **依赖或关联 PRD：**[007 作品资料与上下文](007-作品资料与上下文.md)、[013 相关性与热度排序](013-相关性与热度排序.md)、[015 讨论分析与趋势](015-讨论分析与趋势.md)、[016 证据引用与分析修订](016-证据引用与分析修订.md)、[018 基础报告与数据导出](018-基础报告与数据导出.md)。
- **适用质量要求：**本文件即质量要求的细化，受总纲免费、数据边界和真实验收约束。
- **验证口径：**冻结至少两组不同参考样本的评分，复算排名；模拟模型非确定输出、正文更新和证据到期，检查状态。

总纲质量目标：被展示的来源记录追踪字段齐全率 100%；抽检报告结论引用覆盖率 100%；固定样本重算排序一致，无法复现项显式标记。
来源访问条件未满足时，使用受控样本验证内部规则，并单独记录真实来源验证未完成；不能用模拟成功冒充真实平台接入。涉及性能沿用总纲 B0，分析质量沿用 Q0；未采用相关基线时需注明适用样本和环境。

## 9. 验收标准

AC-001-026 是父级验收，本文件第一项完整保留其场景，其余补充边界、异常和业务细节。以下全部是待执行标准，不是已通过记录。

| 验收 ID | 场景 | Given：前提 | When：操作 | Then：可核查结果 |
|---|---|---|---|---|
| AC-028-001 | 总纲场景继承 | 固定同一组快照和规则版本 | 重复生成分数与分析记录 | 可回到输入证据；确定性计算一致，非确定性模型保留版本与输出。 |
| AC-028-002 | 比较样本 | 同一作品指标在两组参考集下得分不同 | 复算历史得分 | 使用当时参考集，结果一致 |
| AC-028-003 | 模型输出 | 同模型再次生成措辞不同 | 核查历史分析 | 历史输入与实际输出可得，不声称逐字复现 |
| AC-028-004 | 正文编辑 | 引用后原作者编辑正文 | 打开原分析 | 指向当时版本并提示当前变化 |
| AC-028-005 | 审计安全 | 修改规则含敏感搜索词 | 查看一般日志 | 仅对象与版本标识，敏感内容只在有权业务视图 |
| AC-028-006 | 保留到期 | 部分输入依法/按规则删除 | 申请复算 | 明确不可完整复算，不从隐蔽缓存恢复原文 |

交付证据应包含输入/规则版本、执行记录、实际结果和人工核对结论。界面能力须有真实浏览器证据；运行、恢复与来源能力按相应环境验证，纯文档检查不计作产品验收。
