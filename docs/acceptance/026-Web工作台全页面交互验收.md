# Web工作台全页面交互验收

## 验收结论

026 于 2026-08-08 通过验收。工作台八个产品入口对 Viewer、Editor 与 Admin 均可发现，Profile 留在账户菜单，用户与治理只向 Admin 展示；旧 `topics`/`favorites` 终点已删除，事件与报告通知进入真实页面。共享路由 fallback、五类页面读取恢复、客户端导航、三档响应式与具名宽表滚动区域组成完整前端闭环，未修改 Schema、后端 API 或业务状态机。

## 浏览器验收

按用户指定的 `$agent-browser` 连接隔离的真实 Next.js、Go、PostgreSQL、Redis 与 MinIO，完成以下验收：

- Admin 桌面主导航显示八个产品入口，账户菜单和移动 Sheet 只额外展示用户与权限、配额与审计；Viewer 两处均无 Admin 入口。
- 连续点击八个主导航终点均进入真实页面，页面内标记跨导航保留，证明 Next.js 客户端跳转未触发文档级重载；全局事件搜索保留中文 `q` 查询。
- 合成 Viewer 通知验证报告进入 `/dashboard/reports`，事件进入 `/dashboard/events?event=88`；`/dashboard/topics` 与 `/dashboard/favorites` 显示“页面不存在”。
- 网络拦截验证 Profile、内容、事件、告警与报告订阅的错误状态；解除拦截并点击重试后均恢复为真实零值或空态，没有把失败数据冒充为成功空数据。
- 360×800、768×1024、1280×800 均无页面级横向溢出；Sheet 的 Tab、Escape、焦点恢复以及宽表键盘聚焦通过。
- 桌面、平板与移动稳定页使用 axe-core 4.12.1 按 WCAG 2 A/AA 检查，均为 0 violations、0 incomplete；浏览器控制台与页面错误为空。

验收中发现并修复四个问题：全局搜索误写为“事件或监控”、Viewer 首页误显“创建监控”、Viewer Profile 误显“管理监控”、内容错误态仍同时显示空态。问题前后截图和稳定页截图保存在 `/tmp/hotkey-026/`，不进入仓库。

## 安全与产品边界

- 026 只组合现有生成 Client、Next.js App Router、shadcn/ui 与 Radix 原语；没有新增手写 DTO、API、Schema、权限或第二套组件系统。
- 路由错误边界不展示内部异常文本；页面恢复只重放幂等 GET。外链保持新窗口安全属性，同页锚点保持原生行为。
- Viewer 的只读入口保持可发现，但页面文案不暗示其具有创建或管理权限；后端继续作为最终鉴权边界。

## 回滚

回退 026 前端提交即可恢复旧导航与页面组合；数据库事实、通知、报告、审计和 OpenAPI 不需要迁移或回滚。旧重定向路由若被恢复，必须同时恢复对应链接测试，避免再次产生死终点。
