# 关键词规则与多语言查询扩展验收

## 验收结论

006 通过验收。编辑者可组合关键词、短语、别名/实体与排除词，同时选择中英文；管理员可导入与审批不绑定外部供应商的 AI 候选。按来源预览给出稳定查询、语言、能力模式、2048 UTF-8 字节上限和签名；本地粗筛只提前执行硬排除，不降低来源范围召回率。

| 标准 | 结果 | 证据 |
|---|---|---|
| AC-006-1 | passed | 领域测试验证排序、空白归一、短语引用和 2048 字节上限；预览与发布共用同一编译器和签名输入。真实浏览器显示 `OpenAI 开放人工智能 -招聘`、`local_filter`、`en / zh` 与完整 `query_signature`。 |

| AC-006-3 | passed | 现有领域测试验证发布资格仅依赖已批准人工核心规则；真实浏览器在导入 AI 候选前已显示配置可发布，候选初始为待审批且不会自动发布。 |

## 功能与权限证据

- 规则编辑使用 shadcn/ui 的 Dialog、Select、Input、Checkbox、Button、Badge 和 Card 组合，未引入第二套表单或状态容器。
- editor 可编辑人工规则并预览，不显示 AI 候选、发布或生命周期操作；viewer 只读已发布规则，页面不请求来源管理接口；admin 可导入、批准/拒绝候选并发布。
- AI 候选是服务端保留的独立草稿事实；人工编辑不把 AI 来源规则冒充为人工规则，候选只有批准后才能进入发布配置。

## 浏览器验收

使用 `agent-browser` 连接真实 Next.js、Go、PostgreSQL 与 Redis：

- 管理员完成中英文关键词/实体/排除词草稿、按来源预览、AI 候选导入、审批与发布；editor 只显示人工编辑与配置预览；viewer 只显示已发布规则。
- 1440 × 1000 与 390 × 844 视口下列表、规则草稿、候选、详情与预览可用，无水平溢出；草稿对话框保持头部和底部操作可见，正文独立滚动。
- 列表、详情、草稿、AI 候选和发布预览的 axe 4.12.1 WCAG A/AA 审计均为 0 violations；无应用 JavaScript 异常。Radix 模态焦点守卫和没有可判定背景的重叠文本被 axe 列为 `incomplete`，不是确认违规。

## 失败、降级与回滚

- 查询编译超过 2048 UTF-8 字节时预览不可发布，发布用例会再次执行同一校验。
- RSS 与 Hacker News 的 MVP 查询能力明确标识为 `local_filter`，不伪造上游运算符支持；外部 AI 不可用不影响人工规则运行。
- 本条未修改 Schema，回滚查询编译和新界面后，已发布配置、历史事件与审计事实保持不变。
