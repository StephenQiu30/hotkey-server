# 通知与订阅页面拆分验收

## 结果

030 于 2026-08-09 通过验收。通知与报告订阅保持两个独立路由；主导航只保留订阅，通知统一由右上角铃铛进入。通知实时流、已读同步、订阅管理、错误重试与新建订阅对话框保持可用。

## 证据

- 测试先行：新增路由缺失、混合页面仍渲染订阅、组合导航标签三类失败均先被保存，再由最小实现修复。
- `npm run openapi:check`：通过。
- `npm run typecheck`：通过。
- `npm run test:unit`：48 个测试文件、201 个测试通过。
- `npm run build`：通过；21 个路由包含两个独立页面。
- v1.1 导航回归：主导航配置测试确认不再包含通知项，TopNav 测试确认铃铛仍携带未读状态并进入通知页。
- 浏览器：1686px 桌面与 390px 移动布局、独立路由内容隔离、新建订阅对话框和控制台检查通过。
- 视觉证据与 React 质量检查见 `frontend/design-qa.md`，最终结果为 `passed`。

## 影响与回滚

无 Schema、OpenAPI、配置或部署变化。回滚本次导航精简只需将通知项重新加入主导航配置；回滚完整拆分仍需删除订阅路由，并将报告订阅组件重新组合到通知页。
