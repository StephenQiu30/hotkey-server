# X官方搜索连接器验收

## 验收结论

010 通过验收。连接器只访问 X 官方 Recent Search，运行时读取 Bearer `env:NAME`，支持确定性查询、官方当前字段与兼容字段映射、版本化分页检查点、公开指标、媒体、父项和安全诊断。新 X 来源默认停用，健康探测成功前不可启用；凭据缺失、撤销、限流、上游失败和不安全目的地均按稳定类型处理，不使用网页抓取回退。

## 验收标准

| 标准 | 结果 | 证据 |
|---|---|---|
| AC-010-1 | passed | 连接器回归确认所有 `next_token` 分页保持原 `since_id`，只在末页把首屏 `newest_id` 写入下一轮 checkpoint；既有采集流水线以外部 ID 幂等去重。 |
| AC-010-2 | passed | 回归与应用集成测试确认禁用、删除和凭据缺失不请求上游；新建 X 来源强制停用，未探测或健康失败时启用返回冲突，健康后才可启用。 |
| AC-010-3 | passed | 回归确认敏感、withheld 与不可用帖子只形成稳定诊断；作者、正文、时间、语言、父项、媒体，以及浏览、点赞、回复、repost/retweet 与 quote 指标正确映射。 |

## 浏览器验收

使用用户指定的 `$agent-browser` 连接真实 Next.js、Go、PostgreSQL 与 Redis：

- 未认证访问来源页跳转到带安全 redirect 的登录页；管理员可选择 X Recent Search，官方地址固定且只读，授权方式固定为 Bearer，凭据说明只允许 `env:NAME`。
- 创建结果默认为“已停用”；探测前启用返回 409 并显示安全提示。服务端未配置目标环境变量时，探测显示“来源凭据不可用，请检查服务端环境变量”，不回显 Token 或上游原文，来源保持停用。
- 查看者只能读取来源目录，新增、探测、启用和删除操作均不可见。
- 发现并修复一项中优先级文案问题：来源页支持范围曾遗漏 X；修复后真实页面与单元测试均显示 RSS、Atom、Hacker News 与 X。
- 1440×1000 桌面和 390×844 移动视口均无水平溢出；移动对话框初始焦点位于可滚动配置区，Escape 可关闭。
- axe-core 4.12.1 对来源页和 X 对话框执行 WCAG 2 A/AA 审计均为 0 violations、0 incomplete；页面错误为空，控制台只有 React 开发提示、HMR 和本次修复的 Fast Refresh 信息。

## 失败、降级与回滚

- 查询使用 512 字符保守上限，语言使用官方代码白名单，地区要求大写两位国家代码；非法查询和游标在网络请求前拒绝。
- 每次拨号复验公开 DNS，跨主机/路径重定向、私网地址、超过三次重定向和超过 4 MiB 响应均拒绝；错误信息不包含响应正文或凭据。
- 401/403、429、5xx、解析、超时和目的地违规保持稳定分类；429 保留官方 reset 时间作为重试时间。
- 本条只扩展既有来源枚举与约束，不增加数据库表或列。回滚时先停用 X 来源并等待运行结束，再回退应用；保留来源、CollectionRun、内容与 checkpoint 历史。
