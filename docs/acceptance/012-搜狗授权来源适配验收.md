# 搜狗授权来源适配验收

## 验收结论

012 通过验收，“搜狗关键词采集能力”继续保持 blocked。2026-08-07 核验到的搜狗官方资料只证明站方向搜狗提交结构化资源、Sitemap 或嵌入站内搜索代码，没有提供可验证的服务端搜索结果读取契约。本条交付不可调度的授权能力卡片、完整准入清单和禁止网页抓取的架构门禁；没有增加 `SourceType`、数据库枚举、Connector、创建 API 或调度路径。

## 浏览器验收

使用用户指定的 `$agent-browser` 连接真实 Next.js、Go、PostgreSQL 与 Redis：

- 未认证访问来源页跳转到带安全 redirect 的登录页。
- 管理员看到标准 shadcn/ui Card、Badge 与 Button 组合的授权能力卡片；卡片说明官方开放平台是站方向搜狗提交资源，不是读取 API，并列出四项准入条件。
- 管理员打开新增来源清单，只包含 RSS / Atom、Hacker News、X Recent Search 与 Microsoft Foundry Web Search，没有搜狗选项。
- viewer 看到只读来源目录和相同的事实说明，看不到新增来源；搜狗卡片只有官方说明链接和禁用状态，没有创建、探测或启用操作。
- 1440×1000 与 390×844 下卡片、清单和操作区均无横向溢出；管理员与 viewer 页面 axe-core 4.12.1 WCAG 2 A/AA 均为 0 violations、0 incomplete。
- 页面错误为空，控制台只有 React 开发提示和 HMR 连接信息；目视检查未发现需要修复的问题。

## 官方依据与已知限制

- [搜狗数据开放平台帮助](https://data.open.sogou.com/data-resource/help.html?type=1)描述提交 XML 结构化资源并由搜狗抓取更新。
- [搜狗数据开放平台](https://data.open.sogou.com/data-resource/index.html)展示资质提交、数据提交、审核和上线流程。
- [搜狗站内搜索代码](https://help.sogou.com/code.html)提供嵌入网页的搜索代码，不是服务端结果读取 API。
- “未发现公开读取契约”不代表不存在非公开商业合作。获得合同和测试凭据后必须新增设计版本，不得直接删除门禁或复用网页搜索页。

## 回滚

本条没有数据库或调度迁移。回滚只移除静态能力卡片与对应架构测试，不影响现有来源、检查点、采集运行或历史证据；搜狗采集能力在回滚前后都不可用。
