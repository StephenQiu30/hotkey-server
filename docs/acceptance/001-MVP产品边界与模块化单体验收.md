## 自动化验证

以可丢弃 PostgreSQL 16 + pgvector 和独立 Redis 库执行：

```bash
cd backend
make ci
make openapi-check

cd ../frontend
npm run openapi:check
npm run typecheck
npm run test:unit
npm run build
npm audit --omit=dev --audit-level=high

cd ..
docker compose -f docker-compose.yml -f docker-compose-env.yml config --quiet
docker compose --env-file .env.prod \
  -f docker-compose.yml -f docker-compose-prod.yml config --quiet
git diff --check
```

后端数据库运行时回归覆盖 Schema 空库初始化、升级兼容、指纹校验、分页执行计划与 1000 行容量 fixture。前端单元测试共 33 个文件、104 个用例，Next.js 16.3.0 生产构建产出 19 个路由；生产依赖审计为 0 vulnerabilities。
