## 来源、权利与正文链

- RSS/Atom/RDF、Hacker News、X、Bing Grounding、Bilibili、Weibo 和 Google Agent Search 的 Connector 均通过 raw EvidenceSnapshot、locator、collector profile 和显式 party mapping 契约测试。Sogou 和 DuckDuckGo 页面明确显示无可用官方/授权 API 时的能力边界，不使用 HTML 爬取补齐。
- 验收环境为七类 Connector 逐一保存九个单动作 RightsDecision。RSS 允许 fetch/raw/derived/private display/quote/local embed/retain，拒绝 redistribute/external model；其余未批准来源全部停用且 deny，证明 fail-closed。
- raw master 保存在 Source-owned MinIO，正文使用 exact DocumentVersion 与 Vault Markdown/plaintext；PostgreSQL 只保存不可变元数据、词法/结构化检索投影和引用锚点，不保存正文。
- 浏览器实测 DocumentVersion 6 和 18：完整性、正文类型、来源记录/原站/讨论 URL、未知 publisher 降级、不可变 artifact 和 UTF-8 TextQuoteSelector 均按契约展示。带 `evidence` 和 hash 的深链会滚动到稳定 Markdown block ID，并用可见背景/轮廓高亮目标。

## 真实用户旅程

使用 `agent-browser` 连接真实 Next.js 生产构建和 Go 应用，完成如下验收：

1. 以自然语言目标、MUST/MUST_NOT、实体别名和正反例创建“032 浏览器端到端验收”监控。本地 Ollama 扩词返回真实 model/prompt/input provenance，人工审批后才进入 profile。
2. Preview 返回 20 个候选及 lexical/structured RRF 解释；没有合法 semantic corpus、reranker 或结构抽取能力时显式展示 degraded reason，决策保持 review，不伪造语义分或概率。通过后发布 exact CompiledProfile 并运行 Monitor。
3. 从事件查看 MicroEvent、Storyline、Heat v2 和 `single_origin` 证据覆盖；证据卡返回 exact quote、来源/讨论链接和归档正文，“一个独立内容起源”不被解释为事实证实。
4. 通知页从持久 Outbox/UserNotification 加载安全摘要，SSE 在 heartbeat 后显示“实时”，支持 Last-Event-ID 回放。Web Push 只在用户操作下请求权限；验收浏览器拒绝后显式降级，不重复打扰。
5. 390×844 事件页与通知页没有水平溢出；通知页和移动事件页的 axe-core WCAG 2A/2AA 违规均为 0。
6. Service Worker/Manifest 已激活；CacheStorage 仅包含 offline shell、SVG 和 PWA icons，不缓存 `/api`、Authorization 响应、通知或正文。离线/导航失败返回安全登录 shell，不泄露私有数据。

## 安全降级与已知边界

- 验收运行时外部 RSS 请求曾被本机代理的 fake-IP 映射为保留网段，SSRF 校验正确拒绝；启用受控 DoH 后使用已归档验收数据完成其余旅程。这是安全边界生效，不是绕过保护。
- 没有来源明示主体时，publisher/content origin/distributor 保持“信息未提供”，不从域名、来源名、作者或模型猜测。
- 相关性、RRF、Heat 与 EvidenceState 均不是事实真假或媒体可信度指标；旧 Radar/Claim 兼容模型只保留在内部隔离路径，不进入 032 OpenAPI、页面、通知或报告投影。

## 回滚

回滚时停止受影响 v2 producer 和新 allowlist，切回上一个已审计 profile/Decision/读路径；保留 Observation、Snapshot、DocumentVersion、Decision、MinIO 对象和 Vault 文件并按原权利/保留策略管理。不通过删表、覆盖归档、放宽 RightsDecision 或将未知资产自动标记可读来回滚。
