# AI 真伪、相关性、重要性与摘要验收

## 验收结论

019 于 2026-08-07 通过验收。事件页现在把“真伪”明确表达为可追溯的证据确认状态，而不是事实真假概率；用户可在具体 Monitor 上下文中查看相关性，使用真实 Radar 字段理解重要性，并从低置信度声明回到支持或反驳 Content。AI 研判失败只降级自身区域，不影响事件摘要、Radar 与最新变化。

## 安全与产品边界

- confirmation 与 claim confidence 只描述证据状态，不是事实为真的概率；相关性只描述事件与所选 Monitor 是否匹配。
- 页面只使用生成 Client，不暴露 Provider payload、prompt、对象键、凭据、成本明细或内部错误。
- Intelligence/Update 使用并行独立读取；任一失败不会清空 Radar 主列表。本条不调用第三方模型、不增加模型成本。

## 回滚

回滚只移除事件页 Monitor 选择、研判面板和展示辅助函数，恢复原 Radar 参数。既有 AI Run、声明证据、Monitor relevance、Heat、Summary、数据库结构与 API 契约均无需回填。
