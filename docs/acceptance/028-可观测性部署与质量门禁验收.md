## 浏览器与运行环境验收

按用户指定的 `$agent-browser` 在独立全栈环境完成：

- 公共首页、匿名治理页登录重定向、管理员登录与会话硬刷新均通过；非默认 Web 端口的 Origin 配置可注入 API 容器，刷新接口返回 200。
- 治理页展示事实驱动的运行总览、队列滞后和任务安全投影。重试与取消均写入审计；旧原始错误只显示为空，新增失败只显示 `retryable`、`permanent` 或 `cancelled`。
- 任务筛选、空态、网络错误、重试恢复、取消确认、Escape 后焦点回到原操作按钮、成功后焦点移到刷新按钮均通过。
- Viewer 界面显示管理员权限提示，使用 Viewer 会话调用治理 API 返回 403；Admin 可完成允许的读取、重试和取消。
- 概览、监控、来源、内容、事件、告警、报告和通知主导航均可到达；360、768、1280 宽度无页面级溢出，治理页与登录页 WCAG 2 A/AA 为 0 violations，控制台和页面错误为空。

验收创建的浏览器会话、Compose 容器、网络、数据卷、测试 PostgreSQL 与 Redis 均已删除，未进入仓库。

## 安全、限制与回滚

- Prometheus 指标只提供应用端安全投影；MVP 不内置 Prometheus Server、可视化平台或通用告警规则引擎，外部采集与通知按 Operations 手册配置。
- 任务重试/取消继续要求 Admin、版本约束和审计；任务参数与原始错误不通过治理 API 暴露。
- 回滚先停止新任务生产者并等待或取消可重试任务，再回退应用；现有事实表、审计、采集运行和稳定失败码可安全保留。
