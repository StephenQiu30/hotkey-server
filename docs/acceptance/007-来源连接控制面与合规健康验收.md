# 来源连接控制面与合规健康验收

## 验收结论

007 通过验收。管理员可在来源页创建 RSS/Atom 与 Hacker News 连接，并配置授权引用、条款、正文保存、归属/删除义务、语言地区、保留期、请求配额、超时和分页上限；页面支持健康探测、启停和停用后删除。viewer/editor 只读取公共来源事实，不获得端点、白名单配置或凭据引用。

## 验收标准

| 标准 | 结果 | 证据 |
|---|---|---|
| AC-007-1 | passed | Transport DTO 只允许 `rss`、`hacker_news`，领域与连接器注册表再次拒绝未知类型；创建表单只暴露这两类已实现来源。 |
| AC-007-2 | passed | RSS 连接器测试覆盖静态 SSRF、私网/保留地址 DNS、同源跳转与分页、含凭据形态跳转，以及每次新连接重新解析并拒绝 DNS 重绑定；HTTP 测试覆盖所有角色均不回显 `credential_ref`、明文或秘密形态日志。 |
| AC-007-3 | passed | 来源运行使用按目标隔离的失败事实和错误分类；全量应用/仓储回归验证失败目标不修改其他来源或历史内容。真实浏览器中外网不可达被归类并显示可执行诊断，目录与历史读取保持可用。 |
| AC-007-4 | passed | admin 完成完整配置、探测、停用、启用入口和删除保护；viewer/editor 均无新增与管理动作，且看不到端点或凭据引用。1440×1000 与 390×844 无水平溢出，axe 4.13.0 WCAG A/AA 为 0 violations。 |

## 浏览器验收

使用用户指定的 `$agent-browser` 连接真实 Next.js、Go、PostgreSQL 与 Redis：

- admin 创建带 `env:VERCEL_FEED_TOKEN` 引用的 RSS 连接，保存 HTTPS 条款、归属/删除义务、`zh-CN/en`、`CN/US`、90/180 天保留、30 req/min、15 秒超时与 2 页上限；提交后只显示“凭据已配置”，DOM 不含引用。
- admin 创建 Hacker News 官方连接，完成健康失败诊断、停用与启用入口验证；启用来源的删除按钮禁用，停用后才展示确认对话框。
- viewer/editor 页面只显示公共名称、类型、健康、条款和凭据是否配置，端点与配置未下发，新增、探测、启停和删除操作数量为 0。
- 桌面与 390×844 移动端列表无水平溢出；移动端对话框保持标题与底部操作可见，配置区独立滚动且可获得键盘焦点。
- axe 4.13.0 对管理员列表、移动端对话框和 viewer 列表执行 WCAG 2 A/AA 审计，均为 0 violations；页面无应用 JavaScript 异常。移动端模态背景焦点和无法判定背景的对比度只列为 `incomplete`，不是确认违规。

## 失败、降级与回滚

- 未配置凭据、网络不可达、限流、解析错误和永久拒绝分别形成安全诊断；单个来源故障不影响目录、其他来源或历史事实。
- 本条不增加 Schema，也不新增供应商类型；指标能力档案继续使用既有不可变管理员 API。
- 回滚新表单和来源列表展示不会删除来源、内容、运行或审计记录；后端既有安全投影与连接器约束保持兼容。
