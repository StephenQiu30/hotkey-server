# 实时热点监控 MVP 功能基线验收

## 结果

037 于 2026-08-13 通过验收。默认产品主线现为“简单 Monitor → 自动/手动多来源 Scan → 统一 Hotspot 卡片 → 持久热点雷达 → 实时铃铛/站内通知 → high/urgent 邮件”，即时搜索复用同一来源状态、规范化、相关性、热度和卡片投影。默认工作台不再通过 legacy Event 投影展示热点，也不把 Agent Skill 纳入本功能范围；通知只保留顶栏右侧铃铛，桌面与移动一级菜单均不展示重复入口。

本轮实现按简单对象边界收敛为 `Monitor`、`Scan`、`Hotspot`、`SourceStatus`、`Notification`，没有新增第二套热点事实、微服务或消息基础设施。旧不可变事实和历史 Schema 保留用于兼容与审计，已无默认产品调用方的投影和前端入口被移除。仓库根构建只使用原生命令，`backend/Makefile` 已删除。

## 参考功能基线

对标固定提交 [`liyupi/yupi-hot-monitor@cd48b08`](https://github.com/liyupi/yupi-hot-monitor/tree/cd48b0885bfa8ae9c8043cf78ef6cfd045530bdb) 的实际 Web 闭环，而非 README 宣传或独立 Agent Skill：监控词 CRUD、30 分钟轮询与手动扫描、多来源发现、统一热点列表/筛选/排序、即时搜索、页面实时通知和 high/urgent 邮件。HotKey 保留官方 API、RSS/Atom 或明确授权 Feed 的合规边界；未配置来源明确返回 `unavailable`，不使用 HTML 抓取或 Cookie 绕过补齐数量。

## 浏览器真实数据验收

使用用户指定的 `agent-browser` 访问新建、空库、隔离 Docker Compose 生产构建，没有注入前端或 API Mock。注册验证码和通知邮件投递到只存在于验收网络的 Mailpit，避免向真实邮箱外发；来源数据来自 Hacker News 官方公开 API。

1. 通过邮箱验证码完成注册和登录，将隔离测试账号设置为 Admin 后创建 `Hacker News 实时榜单`，探测状态从“未探测”变为“健康”。
2. 即时搜索 `AI` 返回 5 条当前真实榜单结果，展示来源状态、标题、作者、发布时间、点赞、评论、热度、重要性、相关性和原文 URL；`Tailscale`、`Mathematica`、`available` 等短词内部误报不再出现。
3. 创建 `AI 实时热点` Monitor，保留 30 分钟周期、HN 来源和邮件开关；手动扫描由“已排队”进入“成功”，结果为候选 9 / 接受 9。
4. PostgreSQL 核对 `collection_run_items` 为 succeeded 9 / pending 0，`contents` 为 9，`user_notifications` 为 9。热点雷达、铃铛和通知收件箱均显示对应 9 条，通知深链进入 `/dashboard/contents/{id}`。
5. 同轮五条 urgent、两条 high 进入 Mailpit，两条 low 不发邮件，符合 high/urgent 门槛。
6. 390×844 下热点卡片、筛选和原文链接可操作；移动抽屉包含概览、监控、来源、即时搜索、热点雷达及 Admin 项，不含“通知”；顶栏铃铛仍可达。

验收过程中发现并修复两项缺陷：ASCII 短词任意子串匹配，以及热度刷新 SQL 使用已删除的 `merged_into_event_id` 导致规范化任务首条后中止。提交 `9efacec` 增加词边界过滤和真实 PostgreSQL 当前 MicroEvent 查询回归，空库重建后的浏览器复验全部通过。

## 已知限制

- 本轮真实外部来源冒烟仅使用无需凭据的 Hacker News 官方 API。X、Bing Grounding、Bilibili、Weibo、Google 和授权中文搜索仍需在各自合规测试账号下单独配置后冒烟；未配置时产品如实显示不可用，不计入当前可用来源数。
- 当前未配置 Web Push 的隔离服务明确显示“服务端尚未启用 Web Push”；站内实时通知和邮件正常。MVP 不依赖浏览器 Push 达成对标基线。
- AI Provider 未配置时卡片显示“AI 未分析”，不宣称事实核验；本轮 high/urgent 来自唯一服务端热度/重要性计算和确定性直接提词，不伪造 AI 分析状态。
- 监控归档代替破坏性删除以保留历史热点和通知，符合 MVP 历史保留要求。

## 回滚与清理

- 可暂停 Monitor、禁用单一来源或停止自动调度，不删除已持久热点。
- WebSocket 可关闭并使用 REST 补拉；SMTP 可关闭且不影响站内通知和热点事实。
- 即时搜索不写业务事实，无需数据回滚。
- 验收使用的 Compose 项目、Mailpit、临时证书/覆盖文件、数据库卷和对象存储卷在验收结束后全部销毁；测试账号与真实 HN 数据不进入开发数据库。
