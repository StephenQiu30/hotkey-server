# 内容标准化、去重、时效与原始证据验收

## 验收结论

018 于 2026-08-07 通过验收。Content 去重现在只折叠同一 SourceConnection 内的重复事实，跨来源同 URL/Hash 保留独立 active Content 与来源隔离证据；Worker 使用包含边界的 7 天 UTC 新鲜度门禁，旧内容保留可查但不创建 Cluster 任务；文档 API 与工作台可明确区分 `ready`、`not_captured` 和 `unavailable`，且任何读取或完整性失败都不返回伪造正文。

## 安全与数据边界

- 跨来源 Content 与证据不合并；对象键继续使用来源命名空间，API 不暴露对象键、MinIO 端点或 SDK 错误。
- 证据读取失败和完整性失败均 fail closed，不使用标题或摘要回退成正文。
- 7 天门禁只影响新事件候选，不删除 Content、不修改 `expired` 生命周期，也不改变历史事件。
- 测试账号、凭据、临时端口、浏览器状态、截图和验收数据库均未进入提交。

## 回滚

先回退前端 `unavailable` 状态和扩展契约，再回退文档安全投影与 7 天 Worker 门禁，最后回退跨源去重规则。本条不涉及 Schema 迁移；既有 Content、资产和任务事实均可保留。
