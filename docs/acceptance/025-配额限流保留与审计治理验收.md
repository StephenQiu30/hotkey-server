# 配额限流保留与审计治理验收

## 验收结论

025 于 2026-08-08 通过验收。工作区活跃监控与用户每日手动搜索具备事务内硬配额，超额统一返回 HTTP 429、产品错误码 `10005` 和结构化配额数据；现有 AI 预算 reserve/settle 继续作为唯一成本事实。管理员可查看五类用量、预览并有界执行保留批次、按安全字段筛选审计记录；Editor 仅能查看和消费自己的手动搜索配额，Viewer 不暴露治理能力。

## 安全与产品边界

- 配额检查和事实写入位于同一数据库事务；并发请求不能超卖，冷却复用不能重复计费。
- 保留执行只能使用仓储白名单 SQL、服务端截止时间和有界批次；调用方不能提交表名、条件 SQL 或删除审计事实。
- 审计 DTO 不返回请求体、响应体、凭证或 Token；查询仅支持枚举化精确过滤与不透明游标。
- 治理页只组合现有 shadcn/ui 与 Radix 原语，没有引入第二套账本、后台规则编辑器或自定义组件体系。

## 回滚

先关闭治理入口并停止新的硬配额消费，再回退应用。`quota_usage_ledgers`、已执行删除结果和审计记录作为已发生事实保留；不伪造恢复记录，也不自动删除账本或审计。
