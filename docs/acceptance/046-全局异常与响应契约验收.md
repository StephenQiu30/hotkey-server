# 全局异常与响应契约验收

验收日期：2026-09-21。代码版本为本文所在交付提交，实施基线为 `37064d2a`。验收使用本机隔离 ASGI 应用、Node.js 24.19.0、Next.js 16.3.5 与受控本地 HTTP 上游；未读写旧 PostgreSQL 业务数据。

回退时必须将后端错误契约、生成客户端、Web 传输层和同源代理作为一个版本整体回退；本切片无 DDL 或业务数据迁移。本结论不代表认证、持久任务恢复、真实 PostgreSQL/Redis/Kafka、Flutter 或产品功能已验收；它们仍归后续 Plan。本轮未推送远端，因此无 GitHub Actions run URL；首次推送必须观察新增 contract workflow。
