# 采集批次原子重试验收

## 实施前标准

- Queue 测试覆盖允许与拒绝的任务状态、attempt 历史保留和事务复用。
- Source 集成测试覆盖配置锁、source/query claim 锁、最新窗口约束、checkpoint CAS、批次/targets/job 同步变化、任意较新 run/较新成功/失效 target/任务缺失回滚、Retry 与尚未创建 run 的较新 Worker 确定性竞态、并发冲突和 Worker 领取。
- Published Target Reader 测试证明读取调用者事务中的 checkpoint 恢复值；Operations job retry 回归固定两类重试的刻意差异。
- HTTP 契约、Schema、OpenAPI 和安全 DTO 不变。
- 完整 Server 质量门禁通过后才可形成最终结论；跨仓浏览器复验作为产品验收补充，不阻塞 Server 任务归档。

## 当前结论

pending。已通过浏览器与数据库复现：重试接口返回 queued，但原任务终态且唯一键阻止重新入队；即使单独激活原任务，failure checkpoint 已推进也会让 Worker 无法解析旧窗口 target。
