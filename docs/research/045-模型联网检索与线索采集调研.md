# 模型联网检索与线索采集调研

核查日期：2026-09-17。用户确认通过 OpenRouter / Vercel 接入具备联网搜索能力的模型，作为信息获取入口。本文件定义这条入口；[044](044-模型平台信息采集与变更监控调研.md) 管理平台本身的公开信息，[043](043-模型服务接入与模型配置调研.md) 管理模型连接和费用/外发基础。

## 1. 可行能力与产品判断

两平台官方均提供联网搜索路径，可以返回带 URL、标题或摘录的线索以及基于来源生成的回答。建议纳入 P1 的补充发现：主题关键词进入检索，提取引用、规范化 URL、去重、按需获取原文，再进入事件和证据流程。不能仅保存一段模型回答就宣称完成信息采集。

网页搜索不等于平台原生搜索，不保证获取登录内容、全部评论、回复树或指定账号的完整作品。X 专用搜索是可评估的补充路径，仍不替代 002 的免费来源验证与 006/008 的时间线、评论验收。

## 3. 零付费条件下的实际排期

可以现在设计并实现适配契约、调度、证据落库、预算及禁用状态；不能因此宣称联网路线已可运行。公开目录/公告入口 044 不需要推理费用，可先交付。

联网路线只有在“模型推理＋搜索工具＋附加项”均经核查为零付费，且资料/查询外发与上游范围符合条件时，才可显式启用。限时零价要记录到期时间，到期或条件未知自动停止；如果截止时区无法确认，采用提前停止的保守本地期限，不延长活动。赠送额度、已购 credits、BYOK 账单不自动视为免费方案。

因此，当前没有已验证的、可长期零付费运行的 OpenRouter/Vercel 联网组合；Tako 活动只是可验证候选，模型 token 和账号资格仍需核查。若所有候选均收费，界面显示费用条件不满足，保留免费公开源/爬虫/人工资料流程，不取消本功能的设计，也不自动购买。

## 4. 搜索控制及证据边界

OpenRouter 文档提供搜索次数、总结果量和 server-tool 预算，但部分 native 搜索忽略某些参数；不能只传 `max_results` 就宣称所有路线都受控。必须按模型＋API＋引擎做能力测试；无法强制次数/费用上限的组合保持不可用。`auto` 可能改变引擎及费用，首期固定已验证引擎和路由。[参数和工具次数依据](https://openrouter.ai/docs/guides/features/server-tools/web-search)

保存检索任务、规范化查询、日期/域名/账号约束、实际引擎、调用次数、模型和返回引用。原始搜索摘录、已抓取原文、模型归纳分开标识。没有引用、没有搜索调用证据的回答只作为未验证输出，不生成“已采集作品”；检索不到不等于事件不存在。

引用 URL 必须经过网络目标校验后才能抓取；禁止模型扩展为任意工具、登录、发帖或代码执行。模型只使用用户批准的关键词与最小必要上下文，默认不外发整批评论、内部备注或社交会话。

## 5. 开源复用与接入结构

沿用 Python 后端和官方 HTTP/成熟客户端；网关 server tools 是第三方托管能力，不是开源搜索引擎。AI SDK 是开源集成工具，可作为协议参考，不要求新建 Node 服务或部署到 Vercel。本次通过 GitHub 已核查 AI SDK 的 Apache-2.0 许可，见 043；SDK 许可不免除托管服务费用。

043 只持有模型用途配置；045 增加明确的只读检索用途和工具白名单，不放宽普通评论分析的“正文不能执行工具”规则。jobs 共用预算与任务，sources 适配结果进入 content/evidence，events 和 notifications 复用既有流程。必要引用原文由现有受控爬虫补取，不再造一套内容库。
