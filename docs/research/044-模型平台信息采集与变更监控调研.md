# 模型平台信息采集与变更监控调研

日期：2026-09-17。用户已确认两类入口均需要：本文件研究“把 OpenRouter / Vercel 当信息来源”，[045](045-模型联网检索与线索采集调研.md) 研究“通过模型联网工具获取信息”。[043](043-模型服务接入与模型配置调研.md) 只提供后者所需的模型接入基础；本文件的公开目录采集不依赖模型推理或密钥。

## 1. 可直接接入的信息源

通过 Firecrawl 读取官方说明，Context7 核对 Vercel 目录协议，并用无认证 HTTP GET 核查以下公开入口。结果只是一次公开读取证据，尚无定时任务、数据库落库、快照对比、浏览器或通知验收。

| 来源 | 实际入口 | 可获取的信息 | 本次读取结果与边界 |
|---|---|---|---|
| OpenRouter 全模态目录 | [Models API：all](https://openrouter.ai/api/v1/models?output_modalities=all) | 模型 ID、名称、说明、模态、上下文、价格、参数、部分日期和提供方信息 | HTTP 200，599 条；默认不加参数的目录本次 444 条，官方说明默认筛选文本输出，不能把默认列表当全部模型 |
| OpenRouter 模型 RSS | [模型 RSS](https://openrouter.ai/api/v1/models?use_rss=true) | 新模型条目与链接，适合补充发现 | HTTP 200、RSS/XML，444 条；不证明含全部模态，也不保证价格变化会发新条目 |
| OpenRouter 发布信息 | [Announcements](https://openrouter.ai/announcements) | 公告、教程、文章及时间，需区分内容类别 | Firecrawl 200；页面给出的 [博客 Feed](https://openrouter.ai/blog/feed.xml) 在本机直接 GET 返回 403，不能登记为已可用 Feed |
| Vercel AI Gateway 目录 | [Models API](https://ai-gateway.vercel.sh/v1/models) | ID、类型、上下文、输出上限、模态、参数、价格、部分日期/区域/数据政策 | 无认证 HTTP 200，374 条；模型类型与费用字段需保留，不推断账号可调用资格 |
| Vercel Changelog | [官方更新](https://vercel.com/changelog) | 模型接入、搜索工具、促销和服务变化 | Firecrawl 200；包含与模型无关的部署更新，需本地分类/过滤；本轮未验证官方 RSS |

上述数量仅为 2026-09-17 的核查快照，不是永久容量或覆盖承诺。目录模式依据 [OpenRouter Models 文档](https://openrouter.ai/docs/guides/overview/models) 与 [Vercel Models 文档](https://vercel.com/docs/ai-gateway/models-and-providers)。公开读取目前无需购买推理服务，但不承诺接口永久免费或没有限流。

## 2. 能形成的监控事件

| 事件 | 判断证据 | 不能直接推断 |
|---|---|---|
| 平台新增模型 | 同一目录范围的两个成功完整快照中新 ID | 模型在全球首次发布；目录创建时间不等于官方发布日期 |
| 价格变化 | 相同模型/计费单位/档位/提供方范围的字段差异 | 其他网关也改变价格，或实际账号账单一定改变 |
| 能力变化 | 上下文、输入模态、结构化参数等字段变化 | 实测能力提升；目录声明需要独立验证 |
| 暂未发现/下架声明 | 完整快照持续缺失，或官方明确公告 | 一轮缺失就是永久下架；失败/分页不完整不能生成删除事件 |
| 正式发布/促销到期 | 公告链接、文中时间与原文版本 | 首次采集时间等于事件发生时间；免费搜索等于免费模型推理 |

建议默认首次同步只建基线，不把几百条历史记录全部当“刚发布”。后续差异按关键词、模型/厂商关注列表、事件类型和影响阈值筛选；用户可打开前后值及依据，并将线索关联到已有事件。

## 3. 归一化与排序

以“来源平台＋完整模型 ID”确定平台内身份；模型厂商与承载服务商分开。跨网关的同模型建立可修订关系，不合并价格或能力事实。例如本次 Ling 3.0 Flash VL 的 OpenRouter 与 Vercel 免费条目分别声明不同上下文限制，见 [043 模型快照](043-模型服务接入与模型配置调研.md)。

金额保留币种、原单位、档位、有效时间和来源，再转换为可比较展示。零价转收费单列事件，旧值为零时不计算无穷增长率。未知字段保留未知；正文摘要和官方事实分层。

这类来源通常没有点赞/评论等互动指标。排序应展示关键词相关性、事件新鲜度、变更影响和关注命中；不能把目录顺序或“新接入”当作社交热度，不与社交互动分数直接混排。

## 4. 复用路径

优先官方 JSON，其次官方 RSS，再按需提取公开公告 HTML；复用项目锁定后的 HTTP/RSS/网页提取组件与 021 的订阅发现流程，不自建浏览器驱动框架，不为 JSON 启动浏览器，不要求付费 Firecrawl 托管服务作为生产前置。本次研究使用 Firecrawl 读取页面，不代表产品必须用其付费服务。

来源适配器放 `sources/adapters`，共用 monitors 配置、jobs 调度/预算、content 快照、events 事件及 notifications 提醒。043 的配置目录是推理能力管理视图；044 是外部信息证据，两者可以消费相同只读适配结果，但快照观察不自动启用模型。
