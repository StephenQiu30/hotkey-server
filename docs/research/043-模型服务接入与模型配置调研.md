# 模型服务接入与模型配置调研

核查日期：2026-09-17。承接用户补充的 OpenRouter、Vercel 模型信息需求。结论用于 [043 PRD](../prd/043-模型服务接入与模型配置.md)、[设计](../design/043-模型服务接入与模型配置设计.md) 和 [计划](../plans/043-模型服务接入与模型配置计划.md)，不表示已经接入或验证推理质量。


用户已确认两种信息获取入口都需要：044 采集平台自身公开信息，045 通过模型联网工具检索外部线索。本项仅提供模型连接/配置基础；044 不依赖模型推理，045 显式复用本项能力。详见 [044 PRD](../prd/044-模型平台信息采集与变更监控.md)、[045 PRD](../prd/045-模型联网检索与线索采集.md)。

## 1. 产品结论

缺少的不是几个模型名称，而是“连接服务—识别模型及能力—绑定分析用途—控制费用和数据外发—核对运行结果”的完整能力。建议补充 FR-001-025，P1；先于 022 自动分析增强交付。P0 的采集、统计、证据与人工整理继续独立运行。

默认方案为开源本地运行时与许可适合的模型。OpenRouter、Vercel AI Gateway 作为可选外部接入研究，不视为开源自建组件，也不因用户点名就取得付费或资料外发授权。无订阅不等于无费用：按量收费、预付额度、第三方 BYOK 账单与附加功能费用都需要识别。

## 4. 免费范围和用量控制

OpenRouter 官方限额页当前对购买额度不足 10 credits 的 `:free` 请求列出每分钟 20、每天 50 次；更高日限额涉及历史购买条件，本项目不通过充值提升限额。运行时应读取账户实际限额并处理 `402`、`429`，不是在代码永久写死表格。探测、重试和失败尝试都占本地请求预算；不能轮换账号规避限制。[限额依据](https://openrouter.ai/docs/api_reference/limits)

Vercel 必须区分三类费用：模型 token、可选网关功能、Vercel 其他服务账单。零加价不等于零费用；团队级 provider allowlist、团队级 ZDR、Custom Reporting、Trace Drains 等有自己的条件和费用。本项目不启用这些收费附加项，使用自身脱敏审计与请求级约束；如果必要隐私控制要求付费套餐，则该路线保持不可用。[定价依据](https://vercel.com/docs/ai-gateway/pricing)

建议产品有三种明确分类：`local` 自建计算、`zero_price` 已核查外部零单价、`free_credit` 有限赠送额度。`paid`、`unknown` 一律禁止当前执行；`free_credit` 默认仅展示，只有无需购买、无自动充值、无收费回退且可证明硬性停止时，才作为单独的可选实验提案。当前上线候选仅 local / zero_price，允许没有任何满足条件的外部模型。

## 5. 隐私、路由和能力声明

OpenRouter 的上游各有训练和保留政策；不训练不等于不保留。应分别核查网关自身及实际上游的数据政策。官方请求字段包括 `require_parameters`、`only`、`allow_fallbacks`、`data_collection`、`zdr` 和 `max_price`；默认路由可忽略不支持的参数，因此不能只看模型名就假定 Schema 约束有效。[提供方路由](https://openrouter.ai/docs/guides/routing/provider-selection)、[提供方数据政策](https://openrouter.ai/docs/guides/privacy/provider-logging)

建议首期外部路线要求受控提供方、支持所需参数、满足数据保留政策；默认关闭上游自动回退与模型自动选择。没有符合免费和隐私条件的端点时返回不可用，不能自动放松策略。模型虽“开源”也不能使外发的评论、账号和内部备注自动获得授权。

## 6. 复用与架构判断

保持 FastAPI 为唯一后端；Python 适配器调用官方 HTTP 协议或锁定后的成熟 SDK。AI SDK UI 只有在 025 流式问答确实需要时再采用，不为设置页面引入聊天架构。使用网关不等于必须把应用部署到 Vercel。

Context7 本次返回了 Python 后端接入实例，但其中包含旧 `0:` 数据流和旧响应头；实时官方文档是 SSE UI Message Stream，响应头 `x-vercel-ai-ui-message-stream: v1`。因此只采纳“Python 可接 UI 协议”的结论，具体版本与协议须在实施时锁定并做兼容测试，不照抄旧示例。[官方协议](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol)

暂不加独立 LiteLLM 服务或第二层自建网关：本轮仅三个接入类别，简单适配器足够表达差异。模型版本、任务配置、费用策略和分析记录属于 HotKey 业务状态，不能全托管到供应商控制台。
